### 복잡도 종류
| 복잡도 | 예시 |
| --- | --- |
| O(1) | 입력값 관계 X 한 단계, [[stack\|스택(Stack)]] 삽입([[push]]) · 삭제([[pop]]) |
| O($\log^n_2$) | [[이진 트리\|이진 트리(Binary Tree)]], [[Binary Search\|이진 검색(Binary Search)]] |
| O(n) | 필요 단계 : 입력값 = 1 : 1, [[for]] 문 |
| O($n\log^n_2$) | [[Heap Sort\|힙 정렬(Heap Sort)]], [[Merge Sort]] |
| O(n²) | [[Insertion Sort\|삽입 정렬]], [[Shell Sort\|쉘 정렬]], [[Selection Sort\|선택 정렬]], [[Bubble Sort\|버블 정렬]], [[Quick Sort\|퀵 정렬]] |
| O(2ⁿ) | 피보나치 수열 |
