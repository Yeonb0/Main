- 동일한 자료형의 [[데이터]]를 나열한 것
- 순서 존재
- 정적 [[Data Structure|자료구조]]
- 반복적 데이터 처리 Good
- index 이용해 접근

## [[ADT]]
### [[객체|Objects]]
`index` 의 각 값에 대해 집합 `item`에 속한 한 값이 존재하는 `<index, value>` 쌍의 집합
- `index` : 1차원 또는 다차원의 유한 순서 집합

### [[함수|Functions]]
$\forall A \in$ `Array`, $i \in$ `index`
$x \in$ `item`
$j, \text{size} \in$ `integer` 

- `Array` `Create(j, list)`
	- `return` j 차원의 [[배열]]
	- 여기서 `list` 는 i 번째 원소가 i 번째 차원의 크기인 j-tuple 이며 `item` 들은 정의되지 않았음.

- `Item` `Retrive(A, i)`
	- `if` ($i \in$ `index`)
		- `return` 배열 A 의 인덱스 i 값과 관련된 항목 (`A[i]`)
		- `else return` error

- `Array` `Store(A, i, x)`
	- `if` ($i \in$ `index`)
		- `return` 새로운 쌍 `<i, x>` 가 삽입된 배열 A
		- `else return` error

### 다차원 배열
- N차원으로 나열한 배열
- 행렬 (matrix) : 2차원 배열
	- 행 (row) : 배열의 가로 방향
	- 열 (column) : 배열의 세로 방향

![[신경망-10.png]]

- [[넘파이]] 확인 함수
	- `np.ndim(배열)` : 배열 차원 수 확인
	- `배열.shape` : 배열 형상 확인 -> 튜플 반환
- 2차원 배열끼리의 [[연산]] -> [[행렬의 곱]]
