## [[ADT]]
### [[객체|Objects]]
`index` 의 각 값에 대해 집합 `item`에 속한 한 값이 존재하는 `<index, value>` 쌍의 집합
- `index` : 1차원 또는 다차원의 유한 순서 집합

### [[함수|Functions]]
$\forall A \in$ `Array`, $i \in$ `index`
$x \in$ `item`
$j, \text{size} \in$ `integer` 

- `Array` `Create(j, list)`
	- `return` j 차원의 [[배열]]
	- 여기서 `list` 는 i 번째 원소가 i 번째 차원의 크기인 j-tuple 이며 `item` 들은 정의되지 않았음.

- `Item` `Retrive(A, i)`
	- `if` ($i \in$ `index`)
		- `return` 배열 A 의 인덱스 i 값과 관련된 항목 (`A[i]`)
		- `else return` error

- `Array` `Store(A, i, x)`
	- `if` ($i \in$ `index`)
		- `return` 새로운 쌍 `<i, x>` 가 삽입된 배열 A
		- `else return` error

### Design Issue
- index 로 가능한 [[데이터 타입]]
- 배열 size 결정 시점 -> subscript binding
- storage allocation 결정 시점 -> memory binding ([[저장소 바인딩]])
- slice 허용 여부

### index
- `배열이름[index]` 형태로 원소 접근
- 배열 -> 일종의 mapping [[함수]]
	- `[]` 대신 `()` 사용하는 언어 존재
- index type : int, boolean, enumeration, subrange
	- [[C]] -> `int` / `enum`
- index 시작 : 0 또는 1
	- [[C]] -> `0`

### 종류
|  | range binding | storage binding |
| --- | --- | --- |
| Static array | compile time | compile time |
| Fixed stack-dynamic array | compile time | run time |
| Fixed heap-dynamic array | run time ==(변화 X)== | run time |
| Heap dynamic array | run time ==(변화 可)== | run time |

- Static array : value range & storage 모두 compile time 결정 -> 빠름, ==ex)== FORTRAN ==(recursion X)==
- Fixed stack-dynamic array : storage 를 run time 에 [[stack|Stack]] 영역 할당 -> space efficiency, ==ex)== [[C]]의 일반 array
- Fixed heap-dynamic array : range & storage 모두 run time, [[Heap]] 영역 할당, 중간 크기 변경 X, ==ex)== C 의 `malloc`
- Heap dynamic array : range & storage 모두 run time, heap 영역 할당, 중간 크기 변경 O, ==ex)== C 의 `realloc`
- 언어마다 제공하는 array 종류 상이

### Heterogeneous Array
- 여러 [[데이터 타입]]을 모은 배열
- [[Record Type|record]] 와 차이 -> 배열은 index 접근, record 는 name 접근
- 대부분 heap dynamic 구현

### 차원
- 과거 -> 3차원까지만 표현 가능
- 현재 -> 차원 제한 X
- [[C]] -> 엄밀히 1차원, but 배열이 또 다른 배열을 요소로 보유 -> multidimensional array
	- orthogonal design

### 초기화
- [[C]] -> static array 초기화 O, dynamic array 초기화 X
``` c
int list_t[] = {4, 5, 7, 83};
char name[] = "Nang Jongho";
char *names[] = {"Mike", "Fred", "Mary Lou"};
```
- 초기화 불가능한 언어 / 독특한 초기화 방식 언어 존재
- [[Python]] -> list comprehension
	- compact, but [[Readability|가독성]]↓

### 배열 연산
- 가장 기본 [[연산]] -> 원소 가져오기
- 언어마다 구현된 연산 상이 : assignment, arithmetic, relation, logical
	- arithmetic -> 사칙연산이 [[오버로딩|overloading]] 되어 있음
- ==ex)== APL `+.*` -> inner product
- ==ex)== [[넘파이]]
``` python
a = np.array([1,2,3])
b = np.array([4,5,6])

# 각 요소 더하기
c = a + b
c = np.add(a, b)
# c = [5 7 9]

# 각 요소 빼기
c = b - a
c = np.subtract(a, b)
# c = [3 3 3]

# 각 요소 곱하기
c = a * b
c = np.multiply(a, b)
# c = [4 10 18]

# 각 요소 나누기
c = a / b
c = np.divide(a, b)
# c = [0.25 0.4 0.5]
```
``` python
list1 = [
	[1, 2],
	[3, 4]
]

list2 = [
	[5, 6],
	[7, 8]
]

a = np.array(list1)
b = np.array(list2)

# matrix 곱하기
c = np.dot(a, b)
# c = [[19 22]
#      [43 50]]
```
``` python
a = np.array([[1, 2], [3, 4]])

# array 값 더하기
s = np.sum(a) # 10

# axis = 0 -> column 끼리 더하기
# axis = 1 -> row 끼리 더하기
s = np.sum(a, axis = 0)
# s = [4 6]

# array 값 곱하기
s = np.prod(a) # 24
```

### 형태
- Rectangular array : 모든 행 · 열이 동일 개수 요소 보유
- Jagged matrix / array : 행마다 요소 개수 상이

### 구현
- 1차원 배열
	- `address(list[k]) = address(list[1]) + (k-1) * element_size`
	- `= (address(list[1]) - element_size) + (k * element_size)`
	- `(address(list[1]) - element_size)` -> [[상수]], compile time 계산 O
- 다차원 배열
	- memory 는 1차원 -> 저장 시 1차원으로 변환
	- row major order ==(→)== : 일반적 사용
	- column major order ==(↓)==
	- ==ex)==

| 3 | 4 | 7 |
| --- | --- | --- |
| 6 | 2 | 5 |
| 1 | 3 | 8 |

	- row major : 3 4 7 / 6 2 5 / 1 3 8
	- column major : 3 6 1 / 4 2 3 / 7 5 8
	- `location(a[i][j]) = (address of a[1, 1] - ((n + 1) * element_size) + ((i * n + j) * element_size)`
		- 그 이전까지의 모든 주소값 계산

### 포인터와의 차이
- 배열 [[이름]] -> 첫 요소 주소, but [[포인터]] 와 항상 interchangeable X
``` c
char str1[32];
char str2[64];
char *p = str1;
```
- `str1` 과 `p` -> 같은 주소 값
- `sizeof(str1)` = ==32== / `sizeof(p)` = ==8== ==([[포인터]] 크기)==
- `p = str2` -> O ==(가리키는 대상 변경)==
- `str2 = p` -> X ==(배열 이름에 대입 불가)==

### 어셈블리 구현
- [[배열의 어셈블리 구현]] : 요소 주소 = base + index × element_size
- [[포인터 배열]] : 2차원 [[배열]] 의 또 다른 표기 -> [[메모리]] [[배치 처리|배치]] 상이
