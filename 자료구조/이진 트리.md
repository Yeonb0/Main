### 정의
- 공백 or 루트 & 왼쪽 subtree & 오른쪽 서브트리로 분리된 이진 트리로 구성된 노드의 유한 집합

## [[ADT]]
### [[객체|Objects]]
- 공백이거나 root node, 왼쪽 `Binary_Tree`, 오른쪽 `Binary_Tree` 로 구성되는 node 들의 유한 집합

### [[함수|Functions]]
$\forall$ bt, bt1, bt2 $\in$ `Bintree`, item $\in$ `element`


- `BinTree` `Create()`
	- 공백 이진 트리 생성

- `Boolean` `IsEmpty(bt)`
	- `if` (bt == 공백 이진 트리)
		- `return` TRUE
		- `else return` FALSE

- `BinTree` `MakeBT(bt1, item, bt2)`
	- `return` 왼쪽 서브트리가 bt1, 오른쪽 서브 트리가 bt2, 루트는 item 을 갖는 이진 트리

- `BinTree` `Lchild(bt)`
	- `if` (`IsEmpty(bt)`)
		- `return` error
	- `else`
		- `return` bt 의 왼쪽 서브트리

- `BinTree` `Rchild(bt)`
	- `if` (`IsEmpty(bt)`)
		- `return` error
	- `else`
		- `return` bt 의 오른쪽 서브트리

- `element` `Data(bt)`
	- `if` (`IsEmpty(bt)`)
		- `return` error
	- `else return` bt 의 root 에 있는 데이터
