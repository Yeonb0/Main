## Notations
- 알고리즘의 점근적 (Asymptotic) 성능

	- 상수 무시

### [[Big O-notation]]
- $O(n)$ : Upper bound

### [[Big Ω-notation]]
- $\Omega(n)$ : Lower bound

### [[Θ-notation]]
- $\Theta(n)$ : Tight bound

## 세 notation 의 관계

| 표기법  | 의미              | 비유  | 보장하는 것                 |
| ---- | --------------- | --- | ---------------------- |
| O(g) | 점근적 **상한**      | ≥   | f는 g보다 빠르게 자라지 **않는다** |
| Ω(g) | 점근적 **하한**      | ≤   | f는 g만큼은 **자란다**        |
| Θ(g) | 점근적 **타이트 바운드** | =   | 위 두 개를 **동시에** 만족      |
