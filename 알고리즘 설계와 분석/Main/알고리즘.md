### 조건
1. 입력 : 외부에서 제공되는 데이터가 0개 이상 존재
2. 출력 : 적어도 하나의 결과 생성
3. 명확성 : 각 명령들은 명확하고 모호하지 않아야 함
4. 유한성 : 알고리즘 대로 수행하면 한정된 수의 단계 뒤 반드시 종료
5. 유효성 : 원칙적으로 모든 명령은 종이와 연필만으로 수행할 수 있어야 함
