- 레코드 1개 이상 보관 가능한 버킷 메모리

| 이름                 | 설명                                               |
| ------------------ | ------------------------------------------------ |
| 버킷 (Bucket)        | 한 주소 가지는 파일의 한 구역  <br>버킷 크기 = 같은 주소 포함 가능 레코드 수 |
| 슬롯 (Slot)          | 1개 레코드 저장 공간. n개 슬롯 모여 1 버킷                      |
| [[Collision]] (충돌) | 서로 다른 두 레코드가 같은 주소                               |
| Synonym            | 충돌로 같은 주소 갖는 레코드 집합                              |
| Overflow           | 저장할 기억 공간 없는 상태                                  |
