- [[변수]] 가 여럿인 [[함수]] 에 대한 미분 -> $\frac{\partial f}{\partial x_0}$, $\frac{\partial f}{\partial x_1}$
- 목표 변수 하나에 초점 -> 다른 변수는 값 고정

$$
f(x_0, x_1) = {x_0}^2 + {x_1}^2
$$

```python
def function_2(x):
    return x[0] ** 2 + x[1] ** 2
```

### 예
- 문제 1 : $x_0 = 3$, $x_1 = 4$ 일 때 $\frac{\partial f}{\partial x_0}$
```python
def function_tmp1(x0):
    return x0 * x0 + 4.0 ** 2.0

print(numerical_diff(function_tmp1, 3.0))
```
![[신경망-학습-11.png]]

- 문제 2 : $x_0 = 3$, $x_1 = 4$ 일 때 $\frac{\partial f}{\partial x_1}$
```python
def function_tmp2(x1):
    return 3.0 ** 2.0 + x1 * x1

print(numerical_diff(function_tmp2, 4.0))
```
