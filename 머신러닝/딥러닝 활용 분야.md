### 사물 검출
![[딥러닝-14.png]]
- 이미지 어딘가에 있을 사물의 위치 파악
![[딥러닝-15.png]]
- R-CNN (Regions with Convolutional Neural Network) -> 후보 영역 추출 (Selective Search) 후 [[합성곱 신경망|CNN]] 적용
- Faster R-CNN -> 후보 영역 추출 & CNN 특징 계산 모두 CNN 사용

### 분할
- Segmentation : 이미지를 픽셀 수준에서 분류
- 픽셀 단위로 객체마다 채색된 지도 (supervised) [[데이터]] 로 학습
![[딥러닝-16.png]]
![[딥러닝-17.png]]
- FCN (Fully Convolutional [[컴퓨터 네트워크|Network]]) -> 한 번의 [[순전파]] 처리로 모든 픽셀의 [[클래스]] 분류

### 사진 캡션 생성
![[딥러닝-18.png]]
- 컴퓨터 비전 + [[자연어 처리|자연어]] 결합
![[딥러닝-19.png]]
- [[NIC]] (Neural Image Caption) -> 심층 [[합성곱 신경망|CNN]] + 순환 신경망 (RNN)
- 멀티모달 처리 (Multimodal procession)

### 그 외
- 이미지 스타일 (화풍) 변환
- 이미지 생성 -> DCGAN (Deep Convolutional Generative Adversarial Network)
	- [[생성자]] (Generator) & 판별자 (Discriminator) ==2개== [[신경망]] 사용
- 자율 주행 -> SegNet

### 강화학습
![[딥러닝-20.png]]
- reinforcement learning : 시행착오 과정에서 스스로 학습
- 환경 변화 -> 에이전트 보상 획득
- 더 나은 보상 받는 쪽으로 에이전트 행동 지침 교정
- DQN (Deep Q-Network) -> Q학습 : 최적 행동 가치 [[함수]]로 최적 행동 설정
