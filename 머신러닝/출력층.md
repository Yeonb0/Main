### 뉴런 수
- 문제에 맞게 적절히 결정
- 분류 -> 분류하고 싶은 클래스 수
- ==ex)== 입력 이미지 0 ~ 9 중 분류 -> 출력층 뉴런 10개

![[신경망-31.png]]

- 출력층 뉴런 : 숫자 0 ~ 9
- 뉴런의 회색 농도 : 해당 뉴런의 출력 값 크기 (확률)
- 이 그림에선 $y_2$ 선택
