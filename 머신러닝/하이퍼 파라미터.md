### 최적화
- 핵심 : 최적 값이 존재하는 범위를 조금씩 좁혀 나가기
- 규칙적 탐색보다 무작위 탐색이 좋은 결과
- 나쁠 듯한 값 조기 포기 -> [[에포크]] 작게 설정 -> 시간 ↓
- 세련된 기법 -> 베이즈 최적화 (Bayesian [[Optimization]])

1. 범위 설정 -> log scale 지정 (==0.001 ~ 1,000== 식)
2. 설정 범위에서 값 무작위 추출
3. 추출 값으로 학습 -> [[검증 데이터]] 로 정확도 평가 (에포크 작게)
4. 2 ~ 3 을 ==100회== 반복 -> 정확도 결과로 범위 축소

### 구현
- ==ex)== [[MNIST]] 대상 [[학습률]] · [[가중치 감소]] 계수 탐색
	- [[가중치 감소]] 계수 : $10^{-8} \sim 10^{-4}$
	- [[학습률]] : $10^{-6} \sim 10^{-2}$

```python
# 하이퍼파라미터 무작위 탐색======================================
optimization_trial = 100
results_val = {}
results_train = {}
for _ in range(optimization_trial):
    # 탐색한 하이퍼파라미터의 범위 지정===============
    weight_decay = 10 ** np.random.uniform(-8, -4)
    lr = 10 ** np.random.uniform(-6, -2)
    # ================================================

    val_acc_list, train_acc_list = __train(lr, weight_decay)
    print("val acc:" + str(val_acc_list[-1]) + " | lr:" + str(lr) + ", weight decay:" + str(weight_decay))
    key = "lr:" + str(lr) + ", weight decay:" + str(weight_decay)
    results_val[key] = val_acc_list
    results_train[key] = train_acc_list
```
