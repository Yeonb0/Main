- [[합성곱 계층]] 의 [[필터]] [[가중치]] 를 이미지로 확인하는 작업
- 학습 전후 비교 -> 무엇을 보고 있는지 파악

### 1번째 층
- ==ex)== `conv_param = {'filter_num': 30, 'filter_size': 5, 'pad': 0, 'stride': 1}` -> 필터 30개, 채널 1개, 5 × 5
- 채널 1개 -> 흑백 이미지 시각화 O
![[합성곱-신경망-(CNN)-32.png]]
- 학습 전 : 무작위
- 학습 후 : 규칙성 있는 이미지
	- 에지 : 색상이 바뀐 경계선
	- 블롭 : 국소적으로 덩어리진 영역
- 1번째 층 필터 -> 원시적 정보 추출

### 층 깊이에 따른 변화
![[합성곱-신경망-(CNN)-33.png]]
- 계층 ↓ 깊어질수록 추출 정보 [[추상화]] ↑
- 에지 + 블롭 -> 텍스쳐 -> 사물의 일부 -> 사물의 [[클래스]] (개, 자동차 등)
- 단순한 모양 -> 고급 정보 & 사물의 의미 이해
