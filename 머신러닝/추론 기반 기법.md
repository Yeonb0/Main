### 신경망의 단어 처리
- 단어 -> 원핫 (one-hot) 벡터 변환 -> 고정 길이 벡터 -> [[머신러닝/신경망|신경망]] 입력 O

![[word2vec-04.png]]
![[word2vec-05.png]]
- 어휘 수 ==7== -> 입력층 ==7== 개

![[word2vec-06.png]]
![[word2vec-07.png]]
- 은닉층 [[뉴런]] ==3== 개 & [[완전연결계층]] 구성

```python
import numpy as np

c = np.array([[1, 0, 0, 0, 0, 0, 0]])  # 입력
W = np.random.rand(7, 3)               # 가중치
h = np.matmul(c, W)                    # 중간 노드
print(h)
```
