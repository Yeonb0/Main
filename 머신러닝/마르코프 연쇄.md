- 미래 [[state|상태]]가 현재 상태에만 의존해 결정되는 확률 모델
- 확률이 직전 $N$ 개 사건에만 의존 -> $N$ 층 마르코프 연쇄

### 언어 모델 적용
- 맥락을 특정 길이로 고정 -> [[언어 모델]] 근사
- ==ex)== 맥락 왼쪽 2개 단어 한정 [[CBOW 모델]] -> 2층 마르코프 연쇄
- 한계 : 고정 길이 초과 맥락 반영 X -> [[순환 신경망]] 필요
