- 닫힌 경로 (순환 경로) 를 가진 [[머신러닝/신경망|신경망]]
- 순환 경로로 [[데이터]] 순환 -> 과거 정보 기억 + 최신 데이터로 갱신
- [[피드포워드 신경망]] 의 [[시계열 데이터]] 학습 불가 한계 -> RNN 등장

### 구조
![[순환-신경망-(RNN)-04.png]]
- $t$ : 시각 -> [[시계열 데이터]] 입력 의미
- 입력 -> 출력 : $(\mathbf{x}_0, \mathbf{x}_1, \cdots, \mathbf{x}_t, \cdots) \;\longrightarrow\; (\mathbf{h}_0, \mathbf{h}_1, \cdots, \mathbf{h}_t, \cdots)$
- 각 입력 · 출력 = 벡터 -> 실제로는 행렬 입력 & 행렬 출력

### 순환 구조 펼치기
![[순환-신경망-(RNN)-05.png]]
- 펼침 -> 다수 [[RNN 계층]] 이 연결된 신경망
- [[피드포워드 신경망]] : 입력 -> 출력 단방향
- 순환 신경망 : 입력 + 이전 출력 -> 출력

### 출력
$$
\mathbf{h}_t = \tanh(\mathbf{h}_{t-1} \mathbf{W}_h + \mathbf{x}_t \mathbf{W}_x + \mathbf{b})
$$

| 매개변수 | 역할 |
| --- | --- |
| $\mathbf{W}_x$ | 입력 $\mathbf{x}$ -> $\mathbf{h}$ 변환 [[가중치]] |
| $\mathbf{W}_h$ | 이전 출력 -> 다음 출력 변환 [[가중치]] |
| $\mathbf{b}$ | [[편향]] |

- 현재 출력 $\mathbf{h}_t$ 계산에 이전 출력 $\mathbf{h}_{t-1}$ 반영 -> [[은닉 상태]] 보유

### tanh 사용 이유
- 출력 유계 (bounded) -> [[state|상태]] 폭주 방지
- 원점 대칭 (zero-centered)
- 미분값이 [[시그모이드 함수]] 보다 큼
- 구현 간단
- -> [[tanh 함수]]

### 학습
- 시간 방향 [[오차역전파법]] -> [[BPTT]]
- 연결 끊어 블록 단위 학습 -> [[Truncated BPTT]]
