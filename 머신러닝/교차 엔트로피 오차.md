- 정답일 때의 추정 값에 자연로그 취한 [[손실 함수]]
- 정답 아닌 원소 -> $t_k$ 가 0 -> 결과 영향 X
- 정답일 때의 출력이 전체 값 지정

$$
E = -\sum_kt_k\log y_k
$$

- $y_k$ : [[신경망]] 의 출력 (신경망의 추정값)
	- 이 [[데이터]] 가 이 index 일 확률 [0.1, 0.05, 0.6, 0.0, …]
- $t_k$ : [[정답 레이블]]
	- 실제 정답 (원-핫 인코딩) [0, 0, 1, 0, 0 …]
- $k$ : 데이터 차원 수
- $\log$ : 밑이 $e$ 인 자연로그

### 구현
```python
def cross_entropy_error(y, t):
    delta = 1e-7
    return -np.sum(t * np.log(y + delta))
```

- `delta` 더하는 이유
	- `np.log()` 에 0 입력 -> `-inf` -> 계산 X
	- 아주 작은 값 더해 `-inf` 방지

### 배치용 구현
- [[훈련 데이터]] N 개로 확장

$$
E = -\frac{1}{N}\sum_n\sum_kt_{nk}\log y_{nk}
$$

- 마지막에 N 으로 나눠 [[정규화]] -> 평균 손실 [[함수]] -> 데이터 갯수 영향 X
- 데이터 1개 / [[미니배치 학습|배치]] 모두 처리 가능하도록

```python
def cross_entropy_error(y, t):
    if y.ndim == 1:
        t = t.reshape(1, t.size)
        y = y.reshape(1, y.size)
        
    batch_size = y.shape[0]
    return -np.sum(t * np.log(y + 1e-7)) / batch_size
```
- `y` : 신경망 출력 / `t` : [[정답 레이블]]
	- `y` 1차원 -> `reshape` 로 데이터 1개 형상으로 변환
	- else -> `y` 의 차원을 batch 기준 설정
- [[배치 처리|배치]] 크기로 나눠 정규화 -> 1장당 평균 교차 엔트로피 오차 $-\sum(t_k\log y_k)$

#### 정답 레이블이 원-핫 인코딩 X
```python
def cross_entropy_error(y, t):
    if y.ndim == 1:
        t = t.reshape(1, t.size)
        y = y.reshape(1, y.size)
    
    batch_size = y.shape[0]
    return -np.sum(np.log(y[np.arange(batch_size), t] + 1e-7)) / batch_size
```
- `t` 가 0 -> 교차 엔트로피 오차도 0 -> 계산 무시 O
- 정답에 해당하는 신경망 출력만으로 오차 계산 O
- `np.log(y[np.arange(batch_size), t])`
	- `np.arange(batch_size)` : 0 ~ batch_size - 1 [[배열]] 생성
		- ==ex)== [0, 1, 2, 3, 4]
	- `t` : 정답 레이블 저장
		- ==ex)== [2, 7, 0, 9, 4]
	- `y[np.arange(batch_size), t]` : 각 데이터의 정답 레이블에 해당하는 신경망 출력 추출
		- ==ex)== [y[0, 2], y[1, 7], y[2, 0], y[3, 9], y[4, 4]]
