- 전체 [[훈련 데이터]] 중 일부만 무작위로 뽑아 학습
- 미니배치 (mini-batch) : 전체의 근사치로 이용하는 [[데이터]] 일부
- 모든 데이터 대상 [[손실 함수]] 합 계산 부담 ↓

### 특징
- 손실 [[함수]]도 미니배치로 계산 -> 평균 손실 함수 -> 데이터 갯수 영향 X
- [[배치 처리]] 와 동일한 [[행렬의 곱]] 형상 활용

### 구현
- [[MNIST]] 데이터셋 읽기
```python
from mnist import load_mnist

(x_train, t_train), (x_test, t_test) = load_mnist(normalize=True, one_hot_label=True)

print(x_train.shape)
print(t_train.shape)
```
- 호출 시 `one_hot_label=True` 설정

![[신경망-학습-05.png]]
- 데이터 60000 개 / 입력 784 (28 × 28) / 출력 10 (0 ~ 9)

- 훈련 데이터에서 무작위 10장 추출
```python
train_size = x_train.shape[0] # 60000
batch_size = 10
batch_mask = np.random.choice(train_size, batch_size) # 랜덤 뽑기
x_batch = x_train[batch_mask]
t_batch = t_train[batch_mask]
```
- `np.random.choice()` : 지정 범위의 수 중 무작위로 원하는 갯수 추출
