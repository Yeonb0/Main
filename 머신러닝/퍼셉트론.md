- 다수의 신호를 입력으로 받아 하나의 신호 출력하는 [[알고리즘]]
- 프랭크 로젠블랫이 ==1957년== 고안
- 신경망([[딥러닝]]) 의 기원

### 구조
![[퍼셉트론-02.png]]

| 기호 | 내용 |
| --- | --- |
| $x_1$ & $x_2$ | 입력 신호 |
| $y$ | 출력 신호 |
| $w_1$ & $w_2$ | [[가중치]] |
| 원 ○ | [[뉴런]] or 노드 |
| $\theta$ | [[임곗값]] |

### 기능
- 입력 신호가 [[뉴런]]에 보내질 때 각각 고유한 [[가중치]] 곱해짐 $(w_1x_1, w_2x_2)$
- [[뉴런]]에서 받은 신호의 총합이 정해진 한계 ($\theta$) 초과할 때만 1 출력
- 수식

$$
y = \begin{cases} 0 & (w_1 x_1 + w_2 x_2 \leq \theta) \\ 1 & (w_1 x_1 + w_2 x_2 > \theta) \end{cases}
$$

- 복수의 입력 [[신호]] 각각에 고유 [[가중치]] 부여
	- [[가중치]] ↑ -> 해당 입력 신호의 중요도 ↑

### 특징
- [[AND 게이트]] / [[NAND 게이트]] / [[OR 게이트]] 에서 구조 모두 동일
	- 매개변수 ([[가중치]] & [[임곗값]]) 만 상이
- 단층 -> [[선형 영역]]만 표현 가능, [[XOR 게이트]] 표현 X
- [[다층 퍼셉트론]] -> [[비선형 영역]] 표현 O
