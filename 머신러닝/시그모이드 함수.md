- [[신경망]] 에서 자주 이용하는 [[활성화 함수]]
- 입력 -> 출력 변환기, [[비선형 함수]]

$$
h(x) = \frac{1}{1 +\exp(-x)}
$$

- $\exp(-x) = e^{-x}$
- $e = 2.7182\cdots$ -> 자연상수
- 시그모이드 (sigmoid) : ==S자 모양== 이라는 뜻. 매끄러운 곡선

### 구현
```python
def sigmoid(x):
    return 1 / (1 + np.exp(-x))
```
- `np.exp(-x)` = $\exp(-x)$
- [[넘파이]] [[브로드캐스트]] 기능 -> 넘파이 [[배열]] 처리 O

### 그래프
==ex)==
```python
def sigmoid(x):
    return 1 / (1 + np.exp(-x))

x = np.arange(-5.0, 5.0, 0.1)
y = sigmoid(x)
plt.plot(x, y)
plt.ylim(-0.1, 1.1)  # y축의 범위 지정
plt.show()
```

### [[계단 함수]] 와의 공통점
- 입력 ↓ -> 출력 0 에 근접, 입력 ↑ -> 출력 1 에 근접
- 입력 아무리 작거나 커도 출력은 ==[0, 1]==
- 둘 다 [[비선형 함수]]

### [[미분]]
$$
\frac{\partial L}{\partial y} y^2 \exp(-x) = \frac{\partial L}{\partial y} y(1-y)
$$

- [[순전파]] 출력 $y$ 만으로 [[역전파]] 계산 O
