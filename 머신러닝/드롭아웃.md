- [[뉴런]] 을 임의로 삭제하며 학습하는 [[과적합]] 억제 기법
- [[가중치 감소]] 만으로 대응 어려울 때 사용

![[학습-관련-기술들-22.png]]

### 특징
- 삭제된 [[뉴런]] -> [[신호]] 전달 X
- 훈련 시 -> 삭제할 뉴런 무작위 선택
- 시험 시 -> 모든 뉴런에 신호 전달 (출력에 훈련 때 삭제 안 한 비율 곱)

### 구현
```python
class Dropout:
    def __init__(self, dropout_ratio=0.5):
        self.dropout_ratio = dropout_ratio
        self.mask = None

    def forward(self, x, train_flg=True):
        if train_flg:
            self.mask = np.random.rand(*x.shape) > self.dropout_ratio
            return x * self.mask
        else:
            return x * (1 - self.dropout_ratio)

    def backward(self, dout):
        return dout * self.mask
```
- 훈련 시 [[순전파]] 마다 `self.mask` 에 삭제할 뉴런 `False` 표시
	- `self.mask` : x 와 형상 같은 [[배열]] 무작위 생성 -> `dropout_ratio` 초과 원소만 `True`
- [[역전파]] -> [[ReLU 계층]] 과 동작 일치
