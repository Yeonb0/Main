### 구현
```python
import pickle

def sigmoid(x):
    return 1 / (1 + np.exp(-x))

def softmax(a):
    c = np.max(a)
    exp_a = np.exp(a - c)  # 오버플로 대책
    sum_exp_a = np.sum(exp_a)
    y = exp_a / sum_exp_a

    return y
```

```python
def get_data():
    (x_train, t_train), (x_test, t_test) = load_mnist(normalize=True, flatten=True, one_hot_label=False)
    
    return x_test, t_test

def init_network():
    with open("sample_weight.pkl", 'rb') as f:
        network = pickle.load(f)
    
    return network

def predict(network, x):
    W1, W2, W3 = network['W1'], network['W2'], network['W3']
    b1, b2, b3 = network['b1'], network['b2'], network['b3']

    a1 = np.dot(x, W1) + b1
    z1 = sigmoid(a1)
    a2 = np.dot(z1, W2) + b2
    z2 = sigmoid(a2)
    a3 = np.dot(z2, W3) + b3
    y = softmax(a3)

    return y
```
- `get_data()` : [[MNIST]] [[데이터]] 가져오기 -> test 데이터만
- `init_network()` : [[피클]] 파일 `sample_weight.pkl` 에 저장된 '학습된 [[가중치]] 매개변수' 읽음
	- [[신경망-01.pkl|sample_weight.pkl]]
	- 이번 목표는 추론 -> 이미 학습된 매개변수 사용
	- 가중치 & [[편향]] 매개변수가 딕셔너리 [[변수]]로 저장
	- 피클 (pickle) 파일 : 파이썬 [[객체]]를 바이너리 형태로 직렬화 (serialize) 해 저장하는 파일 형식

- `predict()` : 실제 신경망으로 추론 진행 -> [[시그모이드 함수]] & [[소프트맥스 함수]] 사용

### 정확도 평가
```python
# MNIST 데이터셋 얻기 & 네트워크 생성
x, t = get_data()
network = init_network()

# 정확하게 맞춘 횟수
accuracy_cnt = 0

# x 에 저장된 이미지 데이터를 1장씩 꺼내 predict() 함수로 분류
for i in range(len(x)):
    y = predict(network, x[i]) # 각 확률을 넘파이 배열로 반환 
    p = np.argmax(y)  # 확률이 가장 높은 원소의 인덱스 구하기 = 예측 결과
    if p == t[i]: # 예측 == 실제 값이면
        accuracy_cnt += 1 # 맞춘 count + 1

print("Accuracy: " + str(accuracy_cnt / len(x))) # 맞춘 확률 = 정확도
```
