- 자연어에 대한 사람의 지식 포함

### 전처리
1. 텍스트 -> 단어 분할
2. 분할된 단어 -> 단어 ID 목록 변환

- 소문자 변환 & 마침표 분리 -> `split` 로 공백 기준 분할
```python
>>> text = 'You say goodbye and I say hello.'
>>> text = text.lower()
>>> text = text.replace('.', ' .')
>>> text
'you say goodbye and i say hello .'
>>> words = text.split(' ')
>>> words 
['you', 'say', 'goodbye', 'and', 'i', 'say', 'hello', '.']
```
- 딕셔너리로 단어 ↔ 단어 ID 대응표 작성
```python
>>> word_to_id = {}
>>> id_to_word = {}
>>>
>>> for word in words:
...     if word not in word_to_id:
...         new_id = len(word_to_id)
...         word_to_id[word] = new_id
...         id_to_word[new_id] = word
```
	- `word_to_id` : 단어 -> 단어 ID 변환
	- `id_to_word` : 단어 ID -> 단어 변환
```python
>>> id_to_word
{0: 'you', 1: 'say', 2: 'goodbye', 3: 'and', 4: 'i', 5: 'hello', 6: '.'}
>>> word_to_id
{'you': 0, 'say': 1, 'goodbye': 2, 'and': 3, 'i': 4, 'hello': 5, '.': 6}
```
- 단어 목록 -> 단어 ID 목록 ([[넘파이]] [[배열]])
```python
>>> import numpy as np
>>> corpus = [word_to_id[w] for w in words]
>>> corpus = np.array(corpus)
>>> corpus
array([0, 1, 2, 3, 4, 1, 5, 6])
```

### preprocess()
```python
def preprocess(text):
    text = text.lower()
    text = text.replace('.', ' .')
    words = text.split(' ')

    word_to_id = {}
    id_to_word = {}
    for word in words:
        if word not in word_to_id:
            new_id = len(word_to_id)
            word_to_id[word] = new_id
            id_to_word[new_id] = word

    corpus = np.array([word_to_id[w] for w in words])

    return corpus, word_to_id, id_to_word
```
- 반환 : `corpus`, `word_to_id`, `id_to_word`
```python
text = 'You say goodbye and I say hello.'
corpus, word_to_id, id_to_word = preprocess(text)
```
