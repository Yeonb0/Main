- 층이 여러 개인 [[퍼셉트론]]
- 여러 층을 쌓음 -> 더 다양한 표현 가능 -> [[비선형 영역]] 표현 O

### 특징
- 단층 [[퍼셉트론]]에서 구현 X 였던 [[XOR 게이트]] 구현 O
	- 기존 [[AND 게이트]], [[NAND 게이트]], [[OR 게이트]] 조합
- 이론상 [[NAND 게이트]] 만으로 컴퓨터 제작 가능
	- 현실적으로는 불가능
- 이론상 컴퓨터가 수행하는 처리도 모두 표현 가능
