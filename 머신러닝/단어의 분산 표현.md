- 단어를 고정 길이의 [[밀집벡터]] 로 표현한 것
- 단어의 의미를 벡터로 정확히 표현 ==ex)== 색을 RGB 3차원 벡터로 표현
- 이론적 근거 : [[분포 가설]]

### 밀집벡터
- 대부분의 원소가 ==0== 이 아닌 실수 ==ex)== `[0.21, -0.45, 0.83]`
- 대비 : [[희소벡터]] -> 원소 대부분 ==0== ==ex)== [[동시발생 행렬]], PPMI 행렬

### 획득 방법
- [[통계 기반 기법]] : [[동시발생 행렬]] -> [[점별 상호정보량|PPMI]] -> [[차원 감소]]
- [[추론 기반 기법]] : [[word2vec]]
- 기대 효과 : 의미가 가까운 단어 -> 벡터 공간에서 거리도 가까움
