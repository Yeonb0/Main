- 단어를 고정 길이의 [[밀집벡터]] 로 표현한 것
- 단어의 의미를 벡터로 정확히 표현 ==ex)== 색을 RGB 3차원 벡터로 표현
- 이론적 근거 : [[분포 가설]]

### 밀집벡터
- 대부분의 원소가 ==0== 이 아닌 실수 ==ex)== `[0.21, -0.45, 0.83]`
- 대비 : [[희소벡터]] -> 원소 대부분 ==0== ==ex)== [[동시발생 행렬]], PPMI 행렬

### 획득 방법
- [[통계 기반 기법]] : [[동시발생 행렬]] -> [[점별 상호정보량|PPMI]] -> [[차원 감소]]
- [[추론 기반 기법]] : [[머신러닝/word2vec]]
- 기대 효과 : 의미가 가까운 단어 -> 벡터 공간에서 거리도 가까움

### word2vec 의 가중치
- [[머신러닝/word2vec]] 의 두 [[가중치]] 모두 분산 표현에 해당
	- 입력측 [[완전연결계층]] $\text{W}_\text{in}$ : 각 행 = 각 단어
	- 출력측 [[완전연결계층]] $\text{W}_\text{out}$ : 각 열 = 각 단어
- 보통 입력 측 가중치만 이용
- [[가중치]] 재학습 O -> 분산 표현 갱신 & 새 단어 추가 효율적

### 활용
- 비슷한 단어 찾기 -> [[코사인 유사도]]
- [[전이 학습]] : 큰 [[말뭉치]] 로 학습한 분산 표현 -> 다른 작업에 [[재사용(Reuse)|재사용]]
- 단어 -> 고정 길이 벡터 변환 -> 일반 머신러닝 기법 ([[신경망]], SVM 등) 적용 O

- ==ex)== 메일 자동 분류 시스템 -> 감정 분류

### 평가 방법
- 분산 표현 평가 ≠ 분류 시스템 평가 -> 분리해 평가
- 유사성 : 사람이 부여한 점수 vs [[코사인 유사도]] 점수 비교
	- 사람이 작성한 유사도 검증 세트 이용
- [[유추 문제]] 정답률
![[word2vec-속도-개선-33.png]]
- 모델별 정확도 상이
- [[말뭉치]] 크기 ↑ -> 결과 ↑
- 단어 벡터 차원 수 -> 적당해야 함 (너무 크면 오히려 ↓)
