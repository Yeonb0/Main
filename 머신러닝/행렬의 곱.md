- 앞 행렬 가로 × 뒷 행렬 세로

![[신경망-11.png]]

### 조건
- 앞 행렬 row 수 = 뒷 행렬 column 수 -> 다르면 오류 발생

![[신경망-12.png]]

### 구현
```python
A = np.array([[1, 2], [3, 4]])
B = np.array([[5, 6], [7, 8]])
print(A.shape, B.shape)
print(np.dot(A, B))  # 행렬 곱
```
![[신경망-13.png]]
- `np.dot()`
	- 입력이 1차원 [[배열]] -> 벡터
	- 입력이 2차원 배열 -> 행렬 곱 계산
