- [[추론 기반 기법]] 으로 [[단어의 분산 표현]] 획득하는 기법
- 단순한 2층 [[머신러닝/신경망|신경망]]
- 두 모델 : [[CBOW 모델]] / [[skip-gram 모델]]

### 모델
| 모델 | 추측 방향 |
| --- | --- |
| [[CBOW 모델]] | 여러 단어 (맥락) -> 한 단어 (타깃) |
| [[skip-gram 모델]] | 한 단어 (타깃) -> 여러 단어 (맥락) |

### 가중치
![[word2vec-17.png]]

| [[가중치]] | 분산 표현 위치 |
| --- | --- |
| 입력측 [[완전연결계층]] $\text{W}_\text{in}$ | 각 행 = 각 단어 |
| 출력측 [[완전연결계층]] $\text{W}_\text{out}$ | 각 열 = 각 단어 |
- 보통 입력 측 가중치만 이용

### 장점
- [[가중치]] 재학습 O -> [[단어의 분산 표현]] 갱신 & 새 단어 추가 효율적
