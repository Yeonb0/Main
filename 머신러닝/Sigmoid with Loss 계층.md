- [[시그모이드 함수]] + [[교차 엔트로피 오차]] 통합 계층
- [[이진 분류]] 용 [[손실 함수|손실]] 계산 -> [[다중 분류]] 의 [[Softmax-with-Loss 계층]] 에 대응

### 계산 그래프
![[word2vec-속도-개선-12.png]]

### 손실
$$
L = -(t\log y + (1-t) \log(1-y))
$$

- $y$ : [[시그모이드 함수]] 출력 -> ==0 ~ 1== 확률
- $t$ : [[정답 레이블]] -> ==0 or 1==
	- $t = 1$ -> $-\log y$
	- $t = 0$ -> $-\log(1-y)$

### [[역전파]]
- $y - t$ -> 출력 확률 - [[정답 레이블]] -> 오차 그대로 전파
	- 오차 큼 -> 크게 학습
	- 오차 작음 -> 작게 학습
- 사용처 : [[네거티브 샘플링]] -> [[NegativeSamplingLoss]]
