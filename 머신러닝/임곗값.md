- [[뉴런]] 활성화 여부를 가르는 한계값 -> 기호 $\theta$
- 입력 [[신호]] 총합이 $\theta$ 초과 -> 1 출력, 이하 -> 0 출력

### 특징
- $-\theta$ 를 $b$ 로 치환 -> [[편향]] 표기
- [[가중치]]와 함께 [[퍼셉트론]]의 매개변수 구성
- ==ex)== [[AND 게이트]] 만족 조합 무수히 많음 : $(w_1, w_2, \theta)$ = (0.5, 0.5, 0.7), (0.5, 0.5, 0.8), (1.0, 1.0, 1.0)
