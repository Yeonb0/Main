- 모든 [[변수]] 의 [[편미분]] 을 묶어 정리한 것 $(\frac{\partial f}{\partial x_0}, \frac{\partial f}{\partial x_1})$
- 각 장소에서 [[함수]] 의 출력 값을 가장 크게 줄이는 방향 제시

### 구현
```python
def numerical_gradient(f, x):
    h = 1e-4 # 0.0001
    grad = np.zeros_like(x) # x와 형상이 같은 배열을 생성

    for idx in range(x.size):
        tmp_val = x[idx]
        # f(x+h) 계산
        x[idx] = tmp_val + h
        fxh1 = f(x)

        # f(x-h) 계산
        x[idx] = tmp_val - h 
        fxh2 = f(x)

        grad[idx] = (fxh1 - fxh2) / (2 * h)
        x[idx] = tmp_val # 값 복원
    
    return grad
```
- `np.zeros_like(x)` : x 와 shape 같고 원소 모두 0 인 [[배열]] 생성
- x 의 각 원소마다 [[수치 미분]] 수행

```python
print(numerical_gradient(function_2, np.array([3.0, 4.0])))
print(numerical_gradient(function_2, np.array([0.0, 2.0])))
print(numerical_gradient(function_2, np.array([3.0, 0.0])))
```

### 신경망에서의 기울기
- 형상 2 × 3 [[가중치]] $\text{W}$, [[손실 함수]] $L$ 인 [[신경망]] -> $\frac{\partial L}{\partial \text{W}}$ : 각 원소에 관한 [[편미분]]

![[신경망-학습-18.png]]
- $\frac{\partial L}{\partial \text{W}}$ 형상 = $\text{W}$ 형상

```python
from common import softmax, cross_entropy_error, numerical_gradient

class simpleNet:
    def __init__(self):
        self.W = np.random.randn(2, 3) # 정규분포로 초기화

    def predict(self, x):
        return np.dot(x, self.W)

    def loss(self, x, t):
        z = self.predict(x)
        y = softmax(z)
        loss = cross_entropy_error(y, t)

        return loss
```
- `simpleNet` : 형상 2 × 3 가중치 W 를 [[인스턴스]] [[변수]] 로 보유
	- `predict(x)` : 예측 수행
	- `loss(x, t)` : [[손실 함수]] 값 구하기
	- `x` : 입력 [[데이터]] / `t` : [[정답 레이블]]

- 생성
```python
net = simpleNet()
print(net.W)
```
