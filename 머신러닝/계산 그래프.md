- 계산 과정을 표현하는 [[Graph|그래프]]
- [[node]] + edge 로 표시 -> node 안 [[연산]], edge 위 중간 결과

### 형태
- ==ex)== 1개 100원 사과 2개 구입, 소비세 ==10%== -> 지불 금액
![[오차역전파법-01.png]]
- 연산 `×` 만 node 안 표기 -> 사과 개수 & 소비세는 [[변수]] 취급, 원 밖 표기
![[오차역전파법-02.png]]
- ==ex)== 사과 2개(개당 100원) + 귤 3개(개당 150원), 소비세 ==10%==
![[오차역전파법-03.png]]
	- 덧셈 node `+` 등장

### 흐름
1. 계산 그래프 구성
2. 왼쪽 -> 오른쪽 방향 계산 진행 = [[순전파]] (forward propagation)
- [[역전파]] (backward propagation) : 오른쪽 -> 왼쪽 방향 전파

### 장점
- 각 node 는 [[국소적 계산]] 만 담당 -> 문제 단순화
- 중간 계산 결과 보관 O
- [[역전파]] 로 [[미분]] 효율적 계산 O
	- 사과 값 $x$, 지불 금액 $L$ -> $\frac{\partial L}{\partial x}$
![[오차역전파법-05.png]]
	- 사과 1원 ↑ -> 최종 금액 ==2.2원== ↑
	- 소비세 · 사과 개수에 대한 [[미분]] 도 동일 방식 획득 O
- [[순전파]] & [[역전파]] 조합 -> 각 [[변수]] 의 [[미분]] 일괄 계산
