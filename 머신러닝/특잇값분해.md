- 임의의 행렬을 세 [[행렬의 곱]]으로 분해
- [[차원 감소]] 의 대표 수단

$$
\text{X} = \text{U} \Sigma \text{V}^T
$$

![[자연어와-단어의-분산-표현-09.png]]

### 구성
| 행렬 | 내용 |
| --- | --- |
| $\text{U}$, $\text{V}^T$ | 직교행렬 (orthogonal matrix), 어떤 basis 형성 |
| $\text{U}$ | 단어 공간 -> 단어 벡터 |
| $\Sigma$ | 특잇값 대각행렬, 큰 값부터 나열 = 중요한 축부터 |

![[자연어와-단어의-분산-표현-10.png]]

### 구현
- [[넘파이]] `linalg` (linear algebra) [[모듈]]의 `svd` [[메소드]]
```python
# SVD
U, S, V = np.linalg.svd(W)
```
- `U` : SVD 로 변환된 [[밀집벡터]] 표현
```python
print(C[0])  # "you"의 동시발생 행렬
print(W[0])  # "you"의 PPMI 행렬
print(U[0])  # "you"의 SVD 행렬
```

> [!note]- 실행 결과
> ![[자연어와-단어의-분산-표현-11.png]]

- 앞쪽 원소만 꺼내기 -> 원하는 차원으로 축소
```python
print(U[0, :2])  # "you"의 SVD 행렬에서 2차원으로 축소
```
