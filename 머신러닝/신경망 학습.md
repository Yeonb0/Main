- [[가중치]] & [[편향]] 을 훈련 [[데이터]] 에 적응하도록 조정하는 과정
- 전제 : [[머신러닝/신경망]] 에 적응 가능한 [[가중치]] $W$ 와 [[편향]] $b$ 존재

### 절차
1. [[미니배치]] : [[훈련 데이터]] 중 일부 무작위 선별 -> 해당 [[손실 함수]] 값 감소가 목표
2. [[기울기]] 산출 : 각 [[가중치]] 매개변수의 기울기 계산 -> 손실 [[함수]] 값 최소화 방향 제시
3. 매개변수 갱신 : [[가중치]] 를 기울기 방향으로 [[학습률|Learning Rate]] 만큼 갱신
4. 1 ~ 3 단계 반복

### 기울기 산출 방법
| 방법         | 특징                               |
| ---------- | -------------------------------- |
| [[수치 미분]]  | 구현 단순, 속도 ↓                      |
| [[오차역전파법]] | 속도 ↑ , 구현 복잡 -> [[기울기 확인]] 으로 검증 |

- 구현체 : [[TwoLayerNet]]

### 매개변수 갱신 기법
- 목적 : [[손실 함수]] 값 최소화 매개변수 [[Searching|탐색]] -> 최적화 ([[Optimization]])

| 기법             | 특징                         |
| -------------- | -------------------------- |
| [[확률적 경사 하강법]] | 기울기 방향 단순 갱신, 비등방성 함수에 비효율 |
| [[모멘텀]]        | 속도 개념 도입 -> 지그재그 ↓         |
| [[AdaGrad]]    | 매개변수 원소별 학습률 감소            |
| [[Adam]]       | 모멘텀 + AdaGrad 융합           |
