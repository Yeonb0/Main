- 각 층 활성화값이 적당히 분포되도록 강제 조정하는 기법 (==2015년== 제안)
- [[미니배치 학습|미니배치]] 단위로 학습 시 [[정규화]] -> 평균 0, 분산 1

### 장점
- 학습 속도 ↑
- [[가중치 초깃값]] 의존 ↓
- [[과적합]] 억제

### 구조
![[학습-관련-기술들-16.png]]
- [[배치 처리|Batch]] Norm 계층을 [[신경망]] 에 삽입
- [[활성화 함수]] 앞 or 뒤 배치 -> 데이터 분포 치우침 방지

### 수식
- $B = \{x_1, x_2, \cdots x_m\}$ : m 개의 입력 [[데이터]]
- $\mu_B$ : 평균
$$
\mu_B \leftarrow \frac{1}{m}\sum_{i=1}^{m} x_i
$$
- ${\sigma_b}^2$ : 분산
$$
\sigma_B^2 \leftarrow \frac{1}{m}\sum_{i=1}^{m}(x_i - \mu_B)^2
$$
- $\hat{x}$ : 입력 데이터 정규화
$$
\hat{x}_i = \frac{x_i - \mu_B}{\sqrt{\sigma_B^2 + \epsilon}}
$$
	- $\epsilon$ : 작은 값 ($10^{-7}$) -> `divideByZero` 방지
- 정규화 데이터에 고유한 확대 (scale) & 이동 (shift)
$$
y_i = \gamma \hat{x}_i + \beta
$$
	- $\gamma$ : 확대 담당, ==1== 부터 시작 -> 적절히 조정
	- $\beta$ : 이동 담당, ==0== 부터 시작 -> 적절히 조정
