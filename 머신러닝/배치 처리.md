### 형태
![[신경망-37.png]]
- x 형상 784 -> 100 × 784 -> 100장 분량 데이터를 한 입력 데이터로 표현
- y 형상 100 × 10 -> 100장 분량 입력 데이터 결과 한 번에 출력

### 구현
```python
x, t = get_data()
network = init_network()

batch_size = 100  # 배치 크기
accuracy_cnt = 0

for i in range(0, len(x), batch_size):
    x_batch = x[i:i+batch_size]
    y_batch = predict(network, x_batch)

    p = np.argmax(y_batch, axis=1)  # 확률이 가장 높은 원소의 인덱스를 얻는다
    accuracy_cnt += np.sum(p == t[i:i+batch_size])

print("Accuracy: " + str(accuracy_cnt / len(x)))
```
- `range()` : 0 ~ `len(x)` 까지 `batch_size` 씩 증가하는 [[Iterator|반복자]] return
	- `x[0:100]`, `x[100:200]`, … 100장씩 묶어 꺼냄
- `argmax()` : 최댓값의 인덱스 반환
	- `axis=1` : 1번째 차원 구성하는 각 원소에서 최댓값 찾기
	- ==ex)==
```python
>>> x = np.array([[0.1, 0.8, 0.1], [0.3, 0.1, 0.6]
				    	[0.2, 0.5, 0.3], [0.8, 0.1, 0.1]])
>>> y = np.argmax(x, axis=1)
>>> print(y)
[1 2 1 0] # 각 행렬에서 제일 최대인 인덱스들의 행렬
```
- `p == t[i:i+batch_size]` : 배치 단위로 분류한 결과를 실제 답과 비교 -> `np.sum()` 으로 `True` 갯수 세기
	- ==ex)==
```python
>>> y = np.array([1, 2, 1, 0])
>>> t = np.array([1, 2, 0, 0])
>>> print(y == t)
[True True False True]
>>> np.sum(y == t) # True 가 몇 개인가?
3
```
