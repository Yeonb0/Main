- [[데이터]] 를 [[미니배치 학습|미니배치]] 로 무작위 선정 -> [[경사 하강법]] 수행
- 확률적 = 무작위로 골라낸 데이터에 대한 경사 하강법

### 특징
- 전체 [[훈련 데이터]] 대상 [[손실 함수]] 계산 부담 ↓
- 대부분의 [[딥러닝]] [[프레임워크]]가 `SGD` [[함수]]로 구현

### 수식
$$
\text{W} ← \text{W} - \eta\frac{\partial L}{\partial \text{W}}
$$

- $\text{W}$ : 갱신할 [[가중치]] 매개변수
- $\frac{\partial L}{\partial \text{W}}$ : $\text{W}$ 에 대한 [[손실 함수]] 의 [[기울기]]
- $\eta$ : [[학습률]] (0.01 · 0.001 등)
- ← : 이 방향으로 값 갱신

### 구현
```python
class SGD:
    def __init__(self, lr=0.01):
        self.lr = lr
        # lr = learning rate

    def update(self, params, grads):
	    # params = 가중치 매개변수 저장 / grads = 기울기 저장
        for key in params.keys():
            params[key] -= self.lr * grads[key]
```
- `update(params, grads)` : 매개변수 & [[기울기]] 딕셔너리 받아 갱신, 반복 호출

```python
network = TwoLayerNet(...)
optimizer = SGD()

for i in range(10000):
		...
		x_batch, t_batch = get_mini_batch(...) # 미니배치
		grads = network.gradient(x_batch, t_batch)
		params = network.params
		optimizer.update(params, grads)
		...
```
- `optimizer` : 매개변수 & 기울기 정보로 자동 최적화 담당
- 다른 기법도 동일한 `update(params, grads)` [[인터페이스]] 로 구현 -> 교체 O
