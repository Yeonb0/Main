- [[머신러닝/신경망|신경망]] 의 현재 [[state|상태]]를 하나의 지표로 표현하는 [[함수]]
- 이 지표를 가장 좋게 만드는 [[가중치]] 매개변수 값 [[Searching|탐색]] 기준
- 값 작을수록 정답 가능성 ↑

### 종류
- [[오차제곱합]]
- [[교차 엔트로피 오차]]

### 정확도 대신 쓰는 이유
- [[신경망 학습]] -> 매개변수의 미분 값으로 서서히 갱신 반복
- [[정확도]] 를 지표로 삼으면 -> 대부분 장소에서 미분 0
	- ==ex)== 훈련 [[데이터]] 100장 중 32장 인식 -> 정확도 ==32%==, 가중치 조금 바꿔도 32% 유지 or 33 · 34% 로 불연속 변화
	- 분류 결과 O / X 만 존재 -> 불연속 -> 미분 값 0
	- 같은 이유로 [[계단 함수]] 를 [[활성화 함수]] 로 사용 X
- 손실 함수 -> 연속적 변화 -> 미분에 유리
