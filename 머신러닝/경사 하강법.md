- [[기울기]] 방향으로 일정 거리 이동 반복 -> [[함수]] 값 점차 줄이기
- [[손실 함수]] 최솟값 [[Searching|탐색]] 기법

### 절차
1. 현 위치에서 기울어진 방향으로 일정 거리 이동
2. 이동한 곳에서 다시 기울기 산출 -> 또 이동
3. 반복 -> 함수 값 점차 ↓

$$
x_0 = x_0 -\eta \frac{\partial f}{\partial x_0} \\
x_1 = x_1 -\eta \frac{\partial f}{\partial x_1}
$$

- $\eta$ (eta) : 갱신하는 양 -> [[학습률]]

### 구현
```python
def gradient_descent(f, init_x, lr=0.01, step_num=100):
    x = init_x

    for i in range(step_num):
        grad = numerical_gradient(f, x)
        x -= lr * grad
    return x
```
- `f` : 최적화하려는 함수
- `init_x` : 초깃값
- `lr` : learning rate = [[학습률]]
- `step_num` : 경사법 반복 횟수
- `numerical_gradient(f, x)` 로 기울기 산출 -> `lr` 곱한 값으로 갱신 -> `step_num` 만큼 반복

### 예
- $f(x_0, x_1) = {x_0}^2 + {x_1}^2$ 의 최솟값 구하기
```python
def function_2(x):
    return x[0] ** 2 + x[1] ** 2

init_x = np.array([-3.0, 4.0])
print(gredient_descent(function_2, init_x=init_x, lr=0.1, step_num=100))
```
- 초깃값 (-3.0, 4.0) 선택
