### 기존 머신러닝
- ==ex)== 이미지에서 '5' 라는 숫자 인식 프로그램 구현
	1. 이미지에서 [[특징]] (feature) 추출
	2. 특징 패턴을 머신러닝 기술로 학습
- [[특징]] : 입력 데이터에서 본질적인 (중요한) 데이터 정확히 추출하도록 설계된 변환기
	- 이미지 특징 : SIFT, SURF, HOG
	- [[지도학습]] 기술 : SVM, KNN
- 특징 설계는 사람 담당

### 신경망
- 이미지를 있는 그대로 학습 -> [[특징]] 까지 기계 스스로 학습
- [[딥러닝]] = [[종단간 머신러닝]] (end-to-end machine learning)
	- 데이터 (입력) -> 목표 결과 (출력) 까지 사람 개입 X
