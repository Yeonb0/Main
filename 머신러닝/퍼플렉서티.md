- [[언어 모델]] 평가 척도
- 확률의 역수 ([[데이터]] 1개일 때)
- 값 작을수록 좋은 모델
- ==ex)== 확률 0.8 -> ==1.25== / 확률 0.2 -> ==5==

### 분기 수
- 분기 수 (number of branches) = 다음에 취할 수 있는 선택 사항 (후보) 의 수
- 좋은 모델 -> 다음 출현 단어 후보 ↓
- 나쁜 모델 -> 후보 ↑

### 데이터 여러 개
$$
L = \frac{1}{N}\sum_n\sum_kt_{nk}\log y_{nk}
$$

$$
\text{perplexity} = e^L
$$

| 기호 | 의미 |
| --- | --- |
| $N$ | [[데이터]] 총 갯수 |
| $t_n$ | 원핫 벡터로 나타낸 [[정답 레이블]] |
| $t_{nk}$ | $n$ 번째 데이터의 $k$ 번째 값 |
| $y_{nk}$ | 확률 분포 ([[소프트맥스 함수]] 의 출력) |

- 각 후보의 확률 분포 [[손실 함수|손실]] 합산 -> 지수 적용
- [[교차 엔트로피 오차]] $L$ 과 동일 형태 -> [[에포크]] 마다 산출
