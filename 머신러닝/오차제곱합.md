- 각 원소의 출력 (추정 값) 과 [[정답 레이블]] (참 값) 의 차 제곱 -> 총합
- 가장 많이 사용되는 [[손실 함수]]

$$
E = \frac{1}{2}\sum_k(y_k-t_k)^2
$$

- $y_k$ : [[신경망 1]] 의 출력 (신경망의 추정값)
	- 이 [[데이터]] 가 이 index 일 확률 [0.1, 0.05, 0.6, 0.0, …]
- $t_k$ : [[정답 레이블]]
	- 실제 정답 (원-핫 인코딩) [0, 0, 1, 0, 0 …]
- $k$ : 데이터 차원 수

### 구현
```python
def sum_squares_error(y, t):  # y, t 는 넘파이 배열
    return 0.5 * np.sum((y-t) ** 2)
```
