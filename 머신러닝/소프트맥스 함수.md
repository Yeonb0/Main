- [[분류]] 문제의 [[출력층]] [[활성화 함수]]
- 출력이 모든 입력 신호로부터 화살표 받음

$$
y_k = \frac{\exp(a_k)}{\sum\nolimits_{i=1}^{n} \exp(a_i)}
$$

- $\exp(x)$ : $e^x$ 지수 [[함수]]
- $n$ : 출력층의 뉴런 수
- $y_k$ : $k$ 번째 출력
- 분자 : 입력 신호 $a_k$ 의 지수 함수
- 분모 : 모든 입력 신호의 지수 함수 합

![[신경망-29.png]]

### 구현
```python
def softmax(a):
    exp_a = np.exp(a)
    sum_exp_a = np.sum(exp_a)
    y = exp_a / sum_exp_a

    return y
```

### 주의점
- 지수 함수 사용 -> 매우 큰 값 -> 컴퓨터 계산 시 [[오버플로]] 발생
- 개선 수식

$$
\begin{align}y_k &= \frac{\exp(a_k)}{\sum_{i=1}^{n} \exp(a_i)} \\&= \frac{C\exp(a_k)}{C\sum_{i=1}^{n} \exp(a_i)} \\&= \frac{\exp(a_k + \log C)}{\sum_{i=1}^{n} \exp(a_i + \log C)} \\&= \frac{\exp(a_k + C')}{\sum_{i=1}^{n} \exp(a_i + C')}\end{align}
$$

1. 원래 공식
2. $C$ 라는 임의의 정수를 분자 & 분모 양쪽에 곱함 (결국 똑같은 계산)
3. $C$ 를 지수함수 $\exp$ 안으로 옮겨 $\log C$ 로 만듬
4. $\log C$ 를 $C'$ 라는 새로운 기호로 치환

- 지수 함수 계산 시 어떤 정수 더하거나 빼도 결과 변화 X
- $C'$ -> 일반적으로 입력 신호 중 ==최댓값== 이용

```python
def softmax(a):
    c = np.max(a) # c 를 입력값 중 가장 큰 값으로 설정하여 오버플로를 방지
    exp_a = np.exp(a - c) # 오버플로 방지를 위해 입력값에서 최댓값을 빼줌
    sum_exp_a = np.sum(exp_a)
    y = exp_a / sum_exp_a

    return y
```

### 특징
==ex)==
```python
a = np.array([0.3, 2.9, 4.0])
y = softmax(a)
print(y)
print(np.sum(y))
```

- 출력 : ==0 ~ 1.0== 사이의 [[실수]]
- 출력 총합 : ==1==
	- 출력을 확률로 해석 O -> 문제를 확률적으로 대응 O
	- `y[0]` 0.018%, `y[1]` 0.245%, `y[2]` 0.736%
- 소프트맥스 적용해도 각 원소의 대소 관계 변화 X
	- $y = \exp(x)$ 가 단조 증가 함수이기 때문
- [[신경망]] 이용 분류 -> 가장 ==큰== 출력 뉴런의 [[클래스]]로만 인식
	- 출력층의 소프트맥스 함수 생략 O
	- 분류 = "가장 큰 값이 어느 뉴런인지" 구하기
- 학습 단계 -> 소프트맥스 사용 O
- 추론 단계 -> 소프트맥스 사용 X
