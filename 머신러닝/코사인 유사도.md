- 두 벡터가 가리키는 방향의 유사 정도
- 단어 벡터 사이 유사도 측정에 주로 사용
	- 다른 척도 : 벡터의 내적, 유클리드 거리

$$
\text{similarity}(\mathbf{x}, \mathbf{y}) = \frac{\mathbf{x} \cdot \mathbf{y}}{\|\mathbf{x}\| \|\mathbf{y}\|} = \frac{x_1 y_1 + \cdots + x_n y_n}{\sqrt{x_1^2 + \cdots + x_n^2} \sqrt{y_1^2 + \cdots + y_n^2}}
$$

- 분자 : 벡터의 내적
- 분모 : 각 벡터의 노름 (norm)
	- norm : 벡터의 크기 (L2 노름)
- 각 벡터 정규화 -> 내적 -> 방향 비교
- 값 ==1== 에 가까울수록 유사

### 구현
```python
def cos_similarity(x, y, eps=1e-8):
    '''코사인 유사도 산출

    :param x: 벡터
    :param y: 벡터
    :param eps: '0으로 나누기'를 방지하기 위한 작은 값
    :return:
    '''
    nx = x / (np.sqrt(np.sum(x ** 2)) + eps) # x 의 정규화
    ny = y / (np.sqrt(np.sum(y ** 2)) + eps) # y 의 정규화
    return np.dot(nx, ny)
```
- `eps` : ==0== 으로 나누기 방지용 작은 값

```python
import sys
sys.path.append('../')
from common.util import preprocess, create_co_matrix, cos_similarity

text = 'You say goodbye and I say hello.'
corpus, word_to_id, id_to_word = preprocess(text)

c1 = C[word_to_id['i']]   # "i"의 단어 벡터

```

### 유사 단어 랭킹
- `most_similar()` : 검색어와 비슷한 단어를 유사도 순으로 출력

| 인수명 | 설명 |
| --- | --- |
| `query` | 검색어 (단어) |
| `word_to_id` | 단어 -> 단어 ID 딕셔너리 |
| `id_to_word` | 단어 ID -> 단어 딕셔너리 |
| `word_matrix` | 단어 벡터 모은 행렬 |
| `top` | 상위 몇 개까지 출력할지 설정 |

1. 검색어 꺼내기
2. 모든 단어에 대해 코사인 유사도 계산
3. 유사도 기준 내림차순 출력 -> `(-1 * similarity).argsort()`

```python
def most_similar(query, word_to_id, id_to_word, word_matrix, top=5):
    '''유사 단어 검색

    :param query: 검색어(단어)
    :param word_to_id: 단어에서 단어 ID로 변환하는 딕셔너리
    :param id_to_word: 단어 ID에서 단어로 변환하는 딕셔너리
    :param word_matrix: 단어 벡터를 정리한 행렬. 
    :param top: 상위 몇 개까지 출력할 지 지정
    '''
    
    # 1. 검색어 꺼내기
    if query not in word_to_id:
        print('%s(을)를 찾을 수 없습니다.' % query)
        return

    print('\n[query] ' + query)
    query_id = word_to_id[query]
    query_vec = word_matrix[query_id]

    # 2. 코사인 유사도 계산
    vocab_size = len(id_to_word)

    similarity = np.zeros(vocab_size)
    for i in range(vocab_size):
        similarity[i] = cos_similarity(word_matrix[i], query_vec)

    # 3. 코사인 유사도를 기준으로 내림차순 출력
    count = 0
    for i in (-1 * similarity).argsort(): # 오름차순 정렬, return 배열 인덱스 * -1
        if id_to_word[i] == query:
            continue
        print(' %s: %s' % (id_to_word[i], similarity[i]))

        count += 1
        if count >= top:
            return
```
