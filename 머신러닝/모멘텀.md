- 매개변수 갱신에 속도 (velocity) 개념 도입한 최적화 기법
- 기울기 방향으로 가속 + 마찰 · 공기 저항 효과 -> [[확률적 경사 하강법|SGD]] 의 지그재그 경로 완화

### 수식
$$
v ← \alpha \text{v} - \eta \frac{\partial L}{\partial \text{W}} \\
\text{W} ← \text{W} + \text{v}
$$

- $\text{W}$ : 갱신할 [[가중치]] 매개변수
- $\frac{\partial L}{\partial \text{W}}$ : $\text{W}$ 에 대한 [[손실 함수]] 의 [[기울기]]
- $\eta$ : [[학습률]]
- $\text{v}$ : 속도 (velocity)
	- $\alpha \text{v}$ : 아무런 힘 받지 않을 때 서서히 하강시키는 역할 ($\alpha$ 는 ==0.9== 정도)

### 구현
```python
class Momentum:
    def __init__(self, lr=0.01, momentum=0.9):
        self.lr = lr
        self.momentum = momentum
        self.v = None

    def update(self, params, grads):
        if self.v is None:
            self.v = {}
            for key, val in params.items():
                self.v[key] = np.zeros_like(val)

        for key in params.keys():
            self.v[key] = self.momentum * self.v[key] - self.lr * grads[key]
            params[key] += self.v[key]
```
- `v` : 물체의 속도
	- 초기화 시 `None` -> `update()` 최초 호출 때 매개변수와 같은 구조로 생성
