- [[합성곱 연산]] 수행 전 입력 [[데이터]] 주변을 특정 값으로 채우는 처리
- 크기는 원하는 정수로 설정 O

### 형태
![[합성곱-신경망-(CNN)-10.png]]
- ==ex)== (4, 4) 입력에 폭 1 패딩 -> 상하좌우 0 으로 둘러 (6, 6)

### 목적
- 출력 크기 조정
- [[필터]] 적용 -> 출력 크기 ↓
- 패딩 적용 -> 출력 크기 ↑ -> 입력과 출력 크기 동일 유지 O
- [[스트라이드]] 와 함께 [[합성곱 연산]] 출력 크기 결정
