### 샘플링 기법
- [[말뭉치]] 의 단어 출현 횟수 -> 확률분포 -> 확률분포대로 샘플링
- 자주 나오는 단어 많이, 드문 단어 적게
![[word2vec-속도-개선-20.png]]

```python
import numpy as np

# 0에서 9까지의 숫자 중 하나를 무작위로 샘플링
print(np.random.choice(10))

# words 에서 하나만 무작위로 샘플링
words = ['you', 'say', 'goodbye', 'I', 'hello', '.']
print(np.random.choice(words))

# 5 개만 무작위로 샘플링 (중복 O)
print(np.random.choice(words, size=5))

# 5 개만 무작위로 샘플링 (중복 X)
print(np.random.choice(words, size=5, replace=False))

# 확률분포에 따라 샘플링
p = [0.5, 0.1, 0.05, 0.2, 0.05, 0.1]
print(np.random.choice(words, size=5, p=p))
```

> [!note]- 실행 결과
> ![[word2vec-속도-개선-21.png]]

- `size` : 샘플링 수
- `replace` : 중복 허용 여부 (`False` -> 중복 X)
- `p` : 확률분포 리스트

### 0.75 제곱
- 기본 확률분포에 ==0.75== 제곱 -> 원래 확률 낮은 단어 버리지 않기

$$
P'(w_i) = \frac{P(w_i)^{0.75}}{\displaystyle\sum_{j}^{n} P(w_j)^{0.75}}
$$

```python
p = [0.7, 0.29, 0.01]
new_p = np.power(p, 0.75)
new_p /= np.sum(new_p)
print(new_p)
```

> [!note]- 실행 결과
> ![[word2vec-속도-개선-22.png]]

- 낮은 확률 단어 조금 더 쉽게 샘플링
- ==0.75== 자체에 특별한 의미 X
- 구현 : [[UnigramSampler]] -> [[NegativeSamplingLoss]]
