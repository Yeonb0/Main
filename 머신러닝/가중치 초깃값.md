- [[신경망 학습]] 성패 좌우하는 [[가중치]] 의 초기 설정값
- 작은 값에서 시작 권장 -> [[가중치 감소]] 와 연계
- 무작위 설정 필수

### 초깃값 0 문제
- 모두 ==0== 설정 -> [[오차역전파법]] 에서 전 [[가중치]] 동일하게 갱신 -> 가중치 다양성 소멸
- 균일값 회피 -> 무작위 초기화 필요

### 은닉층 활성화값 분포
- [[은닉층]] 활성화값 ([[활성화 함수]] 출력 [[데이터]]) 분포 -> 학습 [[state|상태]] 진단 지표
- ==ex)== 5층 [[신경망]] 에 무작위 입력, [[시그모이드 함수]] 사용, 표준편차 변경

```python
x = np.random.randn(1000, 100) # 1000 개의 데이터
node_num = 100                 # 각 은닉층의 노드 수
hidden_layer_size = 5          # 은닉층이 5개
activation = {}                # 활성화 함수의 결과 (활성화값) 저장

for i in range(hidden_layer_size):
    if i != 0:
        x = activation[i - 1]

    w = np.random.randn(node_num, node_num)  # 가중치 초기화 / 표준편차 1
    a = np.dot(x, w)                         # 행렬 내적
    z = sigmoid(a)                           # 활성화 함수 적용
    activation[i] = z                        # 활성화값 저장
```

![[학습-관련-기술들-11.png]]
- 표준편차 ==1== -> 0 · 1 에 치우침 -> 기울기 소실 (Gradient Vanishing)
	- 출력 0 · 1 근접 -> [[미분]] 0 근접 -> [[기울기]] 값 소멸

```python
    w = np.random.randn(node_num, node_num) * 0.01  # 가중치 초기화
                                                    # 표준편자 0.01
```

![[학습-관련-기술들-12.png]]
- 표준편차 ==0.01== -> 0.5 부근 집중 -> 표현력 제한
	- 다수 [[뉴런]] 이 거의 같은 값 출력 -> 뉴런 복수 [[배치 처리|배치]] 의미 X

### Xavier 초깃값
- 앞 층 [[뉴런|노드]] n 개 -> 표준편차 $\frac{1}{\sqrt{n}}$
- 전제 : [[활성화 함수]] 선형 -> [[시그모이드 함수]] · tanh 적합
- 일반적인 [[딥러닝]] [[프레임워크]] 표준 채택

```python
node_num = 100  # 앞 층의 노드 수
w = np.random.randn(node_num, node_num) / np.sqrt(node_num)
```

![[학습-관련-기술들-13.png]]
- 앞 방식보다 넓게 분포

### He 초깃값
- 앞 층 [[뉴런|노드]] n 개 -> 표준편차 $\sqrt{\frac{2}{n}}$
- [[ReLU 함수]] 음의 영역 0 -> 더 넓게 분포시키려 ==2배== 계수 필요

![[학습-관련-기술들-14.png]]
- 표준편차 0.01 -> 활성화값 과소 -> 기울기 ↓ -> 학습 거의 X
- Xavier -> 층 깊어질수록 치우침 ↑ -> 기울기 소실
- He -> 전 층 균일 분포 -> [[역전파]] 때도 적절한 값

### 대응
| 활성화 함수 | 초깃값 |
| --- | --- |
| Sigmoid, tanh | Xavier 초깃값 |
| ReLU | He 초깃값 |

![[학습-관련-기술들-15.png]]
