- [[가중치]] 값이 작아지도록 학습 유도 -> [[과적합]] 억제용 기법
- [[손실 함수]] 에 가중치의 제곱 노름 (L2 norm) 항 가산 -> 큰 가중치에 패널티

### 수식
- L2 노름 : 각 원소의 제곱들을 더한 값
$$
\sqrt{w_1^2 + w_2^2 + \cdots + w_n^2}
$$
	- L1 norm, L$\infin$ norm 도 존재
- 가중치 감소 항 : $\frac{1}{2}\lambda \text{W}^2$ -> 모든 [[가중치]] 각각의 [[손실 함수]] 에 가산
- $\lambda$ : 정규화 세기 조절 [[하이퍼 파라미터]], ↑ -> 큰 가중치 패널티 ↑
- $\frac{1}{2}$ : [[미분]] 결과인 $\lambda \text{W}$ 조정 역할
- [[기울기]] 산출 시 -> $\lambda \text{W}$ 가산
