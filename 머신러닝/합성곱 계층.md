### 완전연결 계층의 문제점
- [[Affine 계층]] : 인접 계층 [[뉴런]] 모두 연결, 출력 수 임의 지정 O
- 데이터 형상 무시 -> 가로 · 세로 · 색 3차원 이미지도 1차원 변환 필요
	- ==ex)== [[MNIST]] : (1, 28, 28) -> 784
- 공간적으로 가까운 픽셀의 유사성 소실

### 구현
- [[im2col]] 로 입력 전개 -> [[행렬의 곱]] -> `reshape` 로 4차원 복원
```python
class Convolution:
    def __init__(self, W, b, stride=1, pad=0):
        self.W = W
        self.b = b
        self.stride = stride
        self.pad = pad

    def forward(self, x):
        FN, C, FH, FW = self.W.shape
        N, C, H, W = x.shape
        out_h = int(1 + (H + 2*self.pad - FH) / self.stride)
        out_w = int(1 + (W + 2*self.pad - FW) / self.stride)
				
				# 입력 데이터 전개
        col = im2col(x, FH, FW, self.stride, self.pad)
        # 필터 전개 
        col_W = self.W.reshape(FN, -1).T 
        out = np.dot(col, col_W) + self.b

				# 출력 데이터 형상 바꾸기
        out = out.reshape(N, out_h, out_w, -1).transpose(0, 3, 1, 2)
        
        return out
```
- `__init__()` : [[필터]] (W), [[편향]] (b), [[스트라이드]], [[패딩]] 인수로 초기화
	- 필터 -> (FN, C, FH, FW) 4차원 : 필터 갯수, 채널, 필터 높이, 필터 너비
- `self.W.reshape(FN, -1).T` 의 `-1` -> 변환 후에도 원소 수 동일하도록 자동 계산
	- ==ex)== (10, 3, 5, 5) 원소 750개 -> `reshape(10, -1)` -> (10, 75)
- `transpose` -> 다차원 [[배열]] 축 순서 교체

```python
def backward(self, dout):
    FN, C, FH, FW = self.W.shape
    dout = dout.transpose(0,2,3,1).reshape(-1, FN)

    self.db = np.sum(dout, axis=0)
    self.dW = np.dot(self.col.T, dout)
    self.dW = self.dW.transpose(1, 0).reshape(FN, C, FH, FW)

    dcol = np.dot(dout, self.col_W.T)
    dx = col2im(dcol, self.x.shape, FH, FW, self.stride, self.pad)

    return dx
```
