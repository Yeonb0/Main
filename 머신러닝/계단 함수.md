- [[임곗값]] $b$ 를 경계로 출력 바뀌는 [[활성화 함수]]
- [[퍼셉트론]] 이 쓰던 [[함수]]
- [[비선형 함수]]

$$
h(x) = \begin{cases} 0 & (x \leq 0) \\ 1 & (x > 0) \end{cases}
$$

### 구현
```python
def step_function(x):
    if x > 0:
        return 1
    else:
        return 0
```
- 단순 & 쉬움, but 입력으로 [[넘파이]] [[배열]] X

```python
def step_function(x):
    y = x > 0
    return y.astype(int)
```
- 넘파이 배열에 부등호 [[연산]] -> 각각 부등호 연산 수행한 `bool` 배열 생성
- `y` : bool 배열 -> int 형 변환

### 그래프
==ex)==
```python
def step_function(x):
    return np.array(x > 0, dtype=int)

x = np.arange(-5.0, 5.0, 0.1)
y = step_function(x)
plt.plot(x, y)
plt.ylim(-0.1, 1.1)  # y축의 범위 지정
plt.show()
```
