- Σ 입력 [[신호]] -> 출력 신호로 변환하는 [[함수]]
- Σ 입력 신호가 활성화 일으키는지 판정
- $a = b + w_1x_1 + w_2x_2$ , $y = h(a)$

### 절차
![[신경망-04.png]]
1. 입력값 × [[가중치]] 합 + [[편향]] 총합 $a$ 계산
2. $a$ 를 함수 $h()$ 에 넣어 $y$ 출력

### 형태
- 일반
![[신경망-05.png]]
- 상세
![[신경망-06.png]]
	- $a$ : Σ 입력 신호
	- $h()$ : 활성화 함수
	- $y$ : 출력

### 종류
- [[계단 함수]] : [[퍼셉트론]] 이 사용
- [[시그모이드 함수]] : [[머신러닝/신경망]] 에서 자주 사용
- [[ReLU 함수]] : 최근 이용
- [[항등 함수]] / [[소프트맥스 함수]] : [[출력층]] 용
- 층 쌓아 표현 구체화 -> 반드시 [[비선형 함수]] 사용

### [[역전파]] 계층
- [[ReLU 계층]] / [[Sigmoid 계층]] : [[머신러닝/오차역전파법]] 용 계층 구현
- [[Softmax-with-Loss 계층]] : [[출력층]] 용 함수 + [[손실 함수]] 통합
