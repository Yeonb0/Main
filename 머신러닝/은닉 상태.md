- [[RNN 계층]] 의 출력 $\mathbf{h}_t$
- 과거 정보 압축 보관 -> 다음 시각 계층으로 인계
- [[순환 신경망]] 이 가진 [[state|상태]] -> 순차 논리 회로 (sequential logic) 와 유사

### 관리
- [[Time RNN 계층]] 이 [[인스턴스]] [[변수]] `h` 로 보관 -> 계층 간 인계 작업 불필요
- `stateful` 인수로 유지 여부 조정

| `stateful` | 동작 |
| --- | --- |
| `True` | 은닉 상태 유지 -> [[순전파]] 끊지 않고 전파 |
| `False` | 은닉 상태 영행렬 초기화 (무상태) |

- 기울기 `dh` -> [[역전파]] 시 이전 계층으로 전달할 은닉 상태 [[기울기]]
