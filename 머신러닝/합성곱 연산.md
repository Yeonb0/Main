- [[합성곱 계층]] 이 수행하는 [[연산]] -> 이미지 처리의 필터 연산
- [[필터]] = 커널 (kernal)

### 절차
![[합성곱-신경망-(CNN)-06.png]]
1. [[필터]] 의 윈도우 (window) 를 일정 간격 이동하며 입력 [[데이터]] 에 적용
2. 입력 × 필터 곱하고 총합 계산 -> 단일 곱셈-누산 (FMA, fused multiply-add)
3. 각 위치의 결과를 출력에 [[배치 처리 1|배치]]
![[합성곱-신경망-(CNN)-07.png]]
![[합성곱-신경망-(CNN)-08.png]]
- 윈도우 = 회색 3 × 3 영역
- ==ex)== 입력 (4, 4) / 필터 (3, 3) / 출력 (2, 2)

### 가중치와 편향
![[합성곱-신경망-(CNN)-09.png]]
- [[필터]] 의 매개변수 = [[가중치]] (W) 역할
- [[편향]] (b) -> 필터 적용 결과 각각에 더함
	- 편향은 항상 1개만 존재

### 출력 크기
- 입력 (H, W) / 필터 (FH, FW) / 출력 (OH, OW) / [[패딩]] P / [[스트라이드]] S

$$
OH = \frac{H + 2P -FH}{S} + 1
\\
$$

$$
OW = \frac{W + 2P -FW}{S} + 1
\\
$$

- ==정수로 나눠떨어져야== 함
	- 딥러닝 [[프레임워크]] 중 반올림 구현 존재
