- 흐름이 있는 무언가 -> [[퍼셉트론]] 입력 · 출력 단위
- 값은 0 or 1 둘 중 하나

### 상태
| 값 | 내용 |
| --- | --- |
| 1 | 신호가 흐른다 |
| 0 | 신호가 흐르지 않는다 |

- ==ex)== 전류, 강물

### 특징
- 입력 [[신호]] 각각에 고유 [[가중치]] 곱해짐
- [[뉴런]]에서 총합 계산 -> [[임곗값]] 초과 여부로 출력 [[신호]] 결정
