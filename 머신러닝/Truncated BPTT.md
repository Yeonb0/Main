- [[머신러닝/신경망|신경망]] 연결을 적당한 길이로 끊어 학습하는 [[BPTT]]
- 끊는 대상은 [[역전파]] 뿐 -> [[순전파]] 는 끊지 않고 전파
- 자원 소비 · [[기울기]] 불안정 문제 완화

### 블록
![[순환-신경망-(RNN)-07.png]]
- $N$ 개 단위로 절단 -> 잘린 단위 = 블록
- 각 블록 단위로 미래 블록과 독립적으로 [[오차역전파법]] 완결

### 절차
![[순환-신경망-(RNN)-08.png]]
1. [[시계열 데이터]] 를 순서대로 입력 -> [[순전파]] 수행
2. 블록 끝 도달 -> 해당 블록만 [[역전파]] 수행
3. 다음 블록으로 이동 -> [[순전파]] 연결 유지

![[순환-신경망-(RNN)-09.png]]
- [[순전파]] : [[데이터]] 계속 이어감
- [[역전파]] : 블록 단위로 끊어 수행

### 미니배치 학습
![[순환-신경망-(RNN)-10.png]]
- [[데이터]] 를 순서대로 제공
- [[미니배치 학습|미니배치]] 별로 데이터 입력 시작 위치 이동
- ==ex)== 길이 ==100== 데이터 · 미니배치 ==2개== -> 시작 위치 0 · 50
