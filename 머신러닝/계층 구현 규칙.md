- 모든 계층이 공유하는 [[인터페이스]] 약속
- 규칙 통일 -> 계층 교체 · 조합 자유 -> [[머신러닝/신경망|신경망]] 조립 용이

### 규칙
1. 모든 계층은 `forward()` 와 `backward()` [[메소드]] 보유
2. 모든 계층은 [[인스턴스]] [[변수]] `params` 와 `grads` 보유

| [[변수]] | 내용 |
| --- | --- |
| `params` | [[가중치]] `W` · [[편향]] `b` 담는 리스트 |
| `grads` | `params` 에 저장된 매개변수의 [[기울기]] 보관 리스트 |

- `params` 와 `grads` 의 원소 순서 일치 -> 갱신 시 짝 대응
- ==ex)== [[Affine 계층]] · [[ReLU 계층]] · [[Softmax-with-Loss 계층]]
- [[Trainer]] · optimizer 가 이 규칙에 의존 -> 학습 루프 일반화 O
