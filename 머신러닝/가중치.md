- [[퍼셉트론]]에서 각 입력 [[신호]]에 곱해지는 고유 매개변수
- 각 입력 [[신호]]가 결과에 주는 영향력 (중요도) 조절

### 특징
- [[가중치]] ↑ -> 해당 입력 [[신호]]의 중요도 ↑
- [[뉴런]] 총합 계산에 $w_1x_1 + w_2x_2$ 형태로 반영
- [[AND 게이트]] · [[NAND 게이트]] · [[OR 게이트]] 구분은 [[가중치]] · [[편향]] 값 설정 차이뿐
- ==ex)== [[NAND 게이트]] -> [[AND 게이트]] 매개변수의 부호 반전
