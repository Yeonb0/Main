- 이미지 인식 · 음성 인식 등에 사용하는 [[머신러닝/신경망]]
- 기존 계층 ([[입력층]] · [[은닉층]] · [[출력층]]) 조합 + [[합성곱 계층]] · [[풀링 계층]] 추가
- [[데이터]] 형상 유지 -> 공간 정보 보존

### 기존 신경망 구조
![[합성곱-신경망-(CNN)-01.png]]
- 인접 계층의 모든 [[뉴런]] 과 결합 -> [[완전연결 계층|완전연결]] = [[Affine 계층 1]]
- [[Affine 계층 1]] (`forward()` / `backward()`) 뒤에 [[활성화 함수]] 계층 ([[ReLU 계층]] · [[Sigmoid 계층]]) 연결
- 마지막 Softmax -> 최종 결과 (확률) 출력

#### 은닉
- [[Affine 계층 1]] : $\mathbf{W}\mathbf{X} + \mathbf{b}$ 계산
- 활성화 : 정답 고르기
	- [[ReLU 함수 1]]
	![[합성곱-신경망-(CNN)-02.png]]
	- [[시그모이드 함수 1]]
	![[합성곱-신경망-(CNN)-03.png]]
	- [[계단 함수]]
	![[합성곱-신경망-(CNN)-04.png]]
- [[손실 함수]] 계산
	- [[오차제곱합]] : 모든 값의 차이
	- [[교차 엔트로피 오차]] : 정답의 차이

#### 출력
- [[항등 함수]] : 그대로 출력
- [[소프트맥스 함수]] : ==0 ~ 1== [[정규화]] & 확률화

### 절차
| 단계 | 사용 [[함수]] | 결과물 |
| --- | --- | --- |
| ① [[순전파]] | `forward()` | 예측값 y |
| ② [[손실 함수\|손실]] 계산 | `loss.forward(y, t)` | 손실값 (스칼라) |
| ③ [[역전파]] | `backward()` | [[기울기]] dW, db |
| ④ 갱신 | (Optimizer) | 새로운 W, b |
