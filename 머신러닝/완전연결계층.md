- 인접 층 [[뉴런]] 이 모두 화살표로 연결된 계층
- [[가중치]] 와 [[편향]] 으로 [[행렬의 곱]] + 덧셈 수행 -> [[Affine 계층]] 으로 구현
- [[활성화 함수]] 와 번갈아 [[배치 처리|배치]] -> [[머신러닝/신경망|신경망]] [[순전파]] 구성

### 형태
- $y = xW + b$
- $x$ : 입력 / $W$ : [[가중치]] / $b$ : [[편향]]
- [[미니배치 학습|미니배치]] N 개 동시 입력 -> $x$ 를 $N \times D$ 형상으로 처리
	- [[편향]] 은 [[브로드캐스트]] 로 각 행에 더해짐

### 특징
- 층마다 [[가중치]] · [[편향]] 매개변수 보유 -> 학습 대상
- 뒤에 [[활성화 함수]] ([[시그모이드 함수]] 등) 배치 -> 비선형성 부여
- [[데이터]] 형상 무시 (1차원 평탄화) -> 이미지는 [[합성곱 계층]] 이 유리
- [[역전파]] 핵심 [[node]] : [[MatMul 노드]] + [[Repeat 노드]] ([[편향]] 덧셈)
