- 메일 송수신 담당 [[SMTP]] [[서버]] + [[클라이언트]]로 메일 전달하는 [[POP]] 서버
- [[소프트웨어]] : [[Postfix]], [[Dovecot]], [[SES]]

### 송신 ([[SMTP]])
1. 이메일 본문 작성 & 목적지 주소 설정
2. 전송에 필요한 정보 -> 이메일 소프트웨어에서 설정
3. 전송 버튼

### 수신 ([[POP|POP3]])
1. 목적지 주소 -> 목적지 [[도메인]] 관리 메일 서버 파악
	- [[DNS]] [[이름]] 해석 & [[MX 레코드]] 확인
2. 이메일 -> 목적지 도메인 관리 메일 서버 도착
3. 원하는 타이밍에 수신

### 이메일 주소
- `사용자@도메인 이름`
	- ==ex)== `kby7576@sogang.ac.kr`
- 수신자 주소 -> [[DNS]] 이름 해석 -> 서버 [[IP 주소]] 획득
- 호스트 이름 -> [[MX 레코드]] 로 대상 도메인 메일 서버 이름 획득
	- ==ex)== `kby7576@mail.sogang.ac.kr`

### 수신 프로토콜
- [[POP]] : 내려받은 뒤 서버에서 삭제
- [[IMAP]] : 서버에 저장해 둔 채 열람
