### 서버 구축 방식
- 정보 자산 필요할 때 필요한 만큼만 인터넷 통해 서비스 형태로 사용 -> 보통 종량제 방식
	- 온디맨드 : 필요할 때 필요한 만큼만 자산 이용
	- 종량제 : 이용한 만큼만 과금
- 장점
	- 즉시 이용 O
	- 즉시 중단 O
	- 초기 비용 거의 X
- 단점
	- 자유로운 구축 X
	- 자기 자산 X
