### 설정 사항
- 인터넷 연결 여부 -> [[인터넷 게이트웨이]] 설정 
- 오토 스케일링 -> 서버 자동 증설. [[IP 주소]] 넉넉히 확보
- [[보안 그룹]]
- 네트워크 [[ACL]]

### 사용 흐름
1. [[AWS]]에 로그인하기
	- [[리전]] 선택, [[관리 콘솔]] 열기
	- [[VPC]] [[대시보드]] 열기
2. [[VPC]] 생성하기
	- VPC 이름 설정하기
	- CIDR 블록 설정하기
	- 테넌시 (하드웨어 전용 사용 여부) 선택
3. [[Subnetting|서브넷]] 설정하기
	- 서브넷 이름 설정하기
	- 대상 VPC 설정하기
	- 가용 영역 선택하기
	- CIDR 블록 (서브넷) 설정하기
4. 인터넷 연결하기
	- [[인터넷 게이트웨이]] 생성하기
	- [[인터넷 게이트웨이|인터넷 게이트웨이(IGW)]]와 [[VPC]] 연결하기
	- 라우팅 설정하기
