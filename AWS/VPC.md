- [[AWS]] 계정 전용 가상 네트워크 제공
- 네트워크 범위, [[Subnetting|서브넷]], [[Router|라우팅 테이블]], [[게이트웨이]] 등 직접 설정 가능

- 특정 [[AZ]]에 속하지 않음. 단 [[Subnetting|서브넷]]은 반드시 어떤 [[AZ]]에 속해야 함
- VPC = 큰 [[LAN]]
	- VPC 안에 [[Subnetting|서브넷]] 만들고 안에 [[EC2]], [[RDS]] 인스턴스 배치
	- [[Subnetting|서브넷]] 안에 여러 [[인스턴스]] 둘 수 있음 -> 같은 네트워크
	- 기본적으로는 폐쇄. 공개 서버로 변환하려면 [[인터넷 게이트웨이]] 사용해 [[IP 주소]] 변환 해야함

### 기능

| 항목                                | 내용                                                 |
| --------------------------------- | -------------------------------------------------- |
| CIDR 블록                           | [[Subnetting\|서브넷]]. 네트워크 나누는 범위.                  |
| [[Subnetting\|서브넷 마스크]]           | 네트워크 크기 계산 값. $\ni$ CIDR                           |
| 가용 영역                             | [[Subnetting\|서브넷]] 배치하는 물리적 위치                    |
| [[인터넷 게이트웨이]]                     | 인터넷 접속 위한 출입구. 인터넷 연결 안하면 불필요                      |
| [[Router\|라우팅]]                   | 어떤 데이터를 어디로 보낼지 결정                                 |
| [[Router#Routing table\|라우팅 테이블]] | 라우팅 설정 적힌 테이블                                      |
| [[보안 그룹]]                         | [[AWS]] 제공 가상 [[방화벽]].<br>[[인스턴스]] 단위 설정           |
| [[네트워크 ACL]]                      | [[AWS]] 제공 가상 [[방화벽]]<br>[[Subnetting\|서브넷]] 단위 설정 |

### 특징
- [[Router#Routing table|라우팅 테이블]] (설정)이 사실상 [[Router|라우터]] 역할
- 특정 [[AZ]]에 속하지 않음
	- 물리적으로 떨어진 여러 [[Subnetting|서브넷]]을 하나의 [[LAN]] 처럼 다룰 수 있음

### 비용
- [[AWS]] 사이트 간 [[VPN]] + 클라이언트 VPN + 데이터 전송 + 옵션
