- 객체 스토리지 서비스
	- 데이터를 객체 단위로 관리
	- 저장 용량 제한 X -> 필요한 만큼 사용하며 점진적으로 확장
- 파일 저장소 + 정적 웹사이트 호스팅 기능 
- IoT, 데이터 분석, AI 분야에서도 폭넓게 활용

### 특징
- 저장된 파일은 [[S3 객체|객체]]로 관리. [[메타데이터]]가 함께 저장 
- [[버킷]] : [[S3 객체|객체]]를 저장하는 단위. [[Windows]]의 [[드라이브]]와 유사한 게념
- [[매니지드 서비스]]
- 다양한 [[스토리지 클래스]] 선택 가능
- 아카이브용 스토리지 클래스 제공 ([[Lambda]], [[Athena]], [[CloudWatch]] Logs)

### 기능
- [[정적 웹 사이트 호스팅]]
- [[쿼리]] -> 데이터 집계 가능

### 사용법
1. [[AWS]] 로그인하기
	- [[리전]] 선택 후 [[관리 콘솔]] 열기
	- [[S3]] [[대시보드]] 열기
2. [[버킷]] 생성하기
	- 버킷 이름 설정하기
3. [[버킷]] 설정하기
	- 정적 웹 서버로 사용 시 -> [[정적 웹 사이트 호스팅]] 설정
	- 접근 가능 사용자 설정
4. 파일 업로드

### 장점
- 확장성
	- 여러 스토리지 클래스 중 속도, 비용, 가용성 등 목적에 맞게 클래스 선택 가능. 
	- [[수명 주기]] 정책 이용시 자동 전환 가능
- 가용성 · 내구성
	- 99.999999999% 의 데이터 내구성 제공.
	- 장애, 오류, 외부 위협에 매우 강함!
	- 최소 3개의 가용 영역에 객체 복제해 저장
- 신뢰성
	- [[암호화]], [[접근제어자|접근 제어]] 기능 제공
	- 각종 규정 준수 + 감사 기능 존재
- 다양한 관리 기능
	- 스토리지 클래스 분석, 수명 주기 정책 등
	- 스토리지를 실사용 패턴에 최적화 가능
- [[AWS]] 연결 기능
	- [[Athena]], [[Redshift]] Spectrum -> 데이터 분석
	- [[Lambda]] -> 자동 처리 구현
