- [[키-밸류형 데이터베이스]]
- [[인스턴스]] or [[VPC]] 없이도 사용 가능 
- [[ACID 트랜잭션]], 데이터 [[암호화]], [[접근제어자|접근 제어]] 기능

### 명령어
- `PutItem` : 항목 생성
- `GetItem` : 항목 읽기
- `UpdateItem` : 항목 수정
- `DeleteItem` : 항목 삭제

- [[PartiQL]] 이라는 [[SQL]] 호환 언어로 사용 가능

### Amazon DynamoDB Streams
- 변경 데이터 캡쳐 기능
- 데이터 생성, 수정, 삭제마다 시간 순서대로 기록

### 비용
- 읽기/쓰기 요금 + 스토리지 요금 + 통싱 요금 + 기타 옵션
