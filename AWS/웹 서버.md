- 웹 사이드 기능 제공 [[서버]]
- [[HTML]] 파일, 이미지 파일, 프로그램 등을 저장해 두고, [[클라이언트]]가 [[웹 브라우저]]에 접속하면 해당 파일 제공
- 웹 사이트 + [[웹 시스템]] 기반
- [[소프트웨어]] : [[Apache]], [[Nginx]], [[IIS]], [[EC2]], [[S3]], [[Lightsail]], [[ECS]], [[EKS]]
- [[3계층 클라이언트 서버 시스템]] 의 표현 계층 담당

### 통신
- [[HTTP]] · HTTPS 프로토콜 이용
- [[웹 브라우저]] : 전송된 [[HTML]] 파일 · 이미지 -> 사람이 보기 편한 형태로 번역 · 표시
- [[HTTP 요청]] : [[클라이언트]] -> 서버
- [[HTTP 응답]] : 서버 -> [[클라이언트]]

### 구현 소프트웨어
- [[Nginx]] : 고속화 · 경량화 오픈 소스
- [[Apache]] HTTP 서버
- [[IIS|Internet Information Server(IIS)]] : 애플리케이션 서버 기능 탑재
- 오라클 HTTP 서버
