- 특정 이벤트 (트리거) 따라 프로그램 자동 실행 가능한 [[서버리스]] 서비스
- 서버 실행 안하고 코드 실행 가능

- Lambda 함수 : Lambda 에서 실행되는 프로그램
	- 언어에 맞는 규칙으로 작성해야 함
	- 크기 & 실행 시간에 제한 있음
	- 단독 실행 X, [[런타임]] 환경 필요
- Lambda 함수 호출 -> [[AWS 이벤트|이벤트]]

### 사용 흐름
1. AWS 로그인
	- 리전 선택 & 관리 콘솔 열기
	- Lambda 대시보드 열기
2. 빈 Lambda 함수 만들기
	- 함수 이름 설정
	- 런타임, 아키텍처 선택
	- 실행 역할 설정
3. 트리거 / 전송 대상 추가
	- 트리거 설정
	- 대상이 있는 경우 설정
4. Lambda 함수 프로그램 코드 작성

### 설정 항목

| 항목                                   | 내용                                                                            |
| ------------------------------------ | ----------------------------------------------------------------------------- |
| [[런타임]]                              | Lambda 함수가 실행될 환경. (사용 언어 + 버전)                                               |
| [[아키텍쳐]]                             | 런타임을 실행할 컴퓨터의 CPU 종류                                                          |
| 실행 역할                                | 함수 실행 시 [[IAM]] 역할. 권한 설정                                                     |
| 계층 (레이어)                             | 런타임에 추가적인 파일 추가                                                               |
| 함수 URL 활성화                           | 웹에서 [[HTTP]](S) 로 함수를 실행할 수 있음                                                |
| [[VPC]] 활성화                          | [[VPC]]에 연결. 활성화 X 시 공용 IP 환경에서 실행                                            |
| 트리거                                  | Lambda 함수 실행 계기. 다른 [[AWS]] 리소스 or 외부 서비스                                     |
| 이벤트 소스                               | 트리거가 되는 [[AWS]] 리소스 or 외부 서비스                                                 |
| 메모리                                  | 할당할 메모리                                                                       |
| 임시 스토리지 (/tmp)                       | 함수 실행 시 사용 가능한 스토리지 용량                                                        |
| 제한 시간                                | 실행 가능한 최대 시간. 이후는 강제 정료                                                       |
| [[RDS]] 데이터베이스                       | [[RDS]] [[데이터베이스\|DB]]에 연결 위한 설정                                              |
| 동시성                                  | 최대 동시 실행 수                                                                    |
| 프로비저닝된 동시성                           | 미리 준비된 런타임으로 즉시 실행할 수 있는 개수                                                   |
| 배달 못한 편지 대기열 <br>(Dead letter Queue) | [[비동기]] 통신에서 재시도 후에도 실패하면 알림<br>[[SQS Queue\|Amazon SQS 큐]] or [[Amazon SNS]] |
| 파일 시스템                               | 함수가 [[EFS]] 파일 시스템 사용시 설정                                                     |
| 상태 머신                                | Lambda 함수 통합 관리되는 상태 머신 설정                                                    |
