- ID 및 접근 관리
- [[AWS]]의 인증 기능 담당

### IAM 사용자
- 여러 개 생성 가능
- 사용자마다 서비스 접근 권한 세밀 설정 가능

### IAM 역할

- [[IAM]] 사용자나 [[EC2]] 인스턴스 같은 [[AWS 서비스]]에 대해 ==특정 역할로 동작할 수 있는 권한== 부여 기능
- 마치 다른 사용자로 전환된 것처럼 새로운 권한 이용 가능
- 사용자 권한 직접 변경보다 간단 & 안전

### IAM 그룹
- 여러 사용자를 하나의 단위로 묶는 기능
- 그룹에 속한 사용자 모두에게 동등한 권한 가능
- 여러 그룹 동시 소속 가능

### IAM 정책
- 실행 주체가, 어떤 대상에 대해, 어떤 작업을 허용 / 거부 할지 [[JSON]] 형식으로 정의한 규칙
- 자격 기반 정책 : 이 사용자가 무엇을 할 수 있는가?
- 리소스 기반 정책 : 이 리소스에 대해 무엇을 허용할 것인가?

- 고객 관리형 정책 : 직접 작성 -> 실수 가능성 높음
- 관리형 정책 : [[AWS]] 에서 미리 제공
