### 기밀성 (Confidentiality)
- 정당한 권리를 가진 사람만이 접근할 수 있는 것
- 방법
	- [[보안 그룹]] 같은 [[방화벽]] 설정
	- [[Subnetting|서브넷]] 적절히 나누기
	- 공개 범위 올바르게 설정하기
	- [[IAM]] 롤 적절히 운영

### 가용성 (Availability)
- 필요할 때 사용할 수 있는 것
- 방법
	- [[부하 분산]], [[스케일링]], [[레플리케이션]]
	- [[AWS]] : [[Auto Scaling]], [[매니지드 서비스]]

### 완전성 (Integrity)
- 데이터가 정상적인 상태인 것
- 방법
	- 시스템 · [[데이터베이스]] 올바르게 설계 · 관리
	- [[미들웨어]] · [[운영체제|OS]] 관리 · 업데이트

- [[인시던트]]를 예방하기.
	- How?
		1. 구조(방식)를 바꿀 수 있는가?
		2. 리스크를 어떻게 구분할까?
