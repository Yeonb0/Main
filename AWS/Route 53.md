- 도메인 [[이름]]으로 접근 관리하는 [[DNS]] 서비스 제공
- 이름 해석 (Name Resolution) : 사용자가 접속하려는 주소 -> [[AWS 서비스]] 엔드포인트에 연결
- 부하 분산, 서비스에 장애 발생 시 전환 기능 제공

### 용어

| 항목                                          | 내용                                                       |
| ------------------------------------------- | -------------------------------------------------------- |
| Resolover                                   | [[도메인]]명 <-> [[IP 주소]] 교환 기능<br>일반적인 [[DNS\|DNS 서버]]의 역할 |
| [[DNS 라운드 로빈\|DNS 라운드 로빈(DNS Round Robin)]] | 한 호스트 명에 여러 [[IP 주소]] 할당 -> 접속마다 돌아가며 응답                 |
| 트래픽 흐름                                      | 서버 부하 & 효율 고러 가장 적절한 서버의 [[IP 주소]] 반환하도록 조정하는 메커니즘       |
| 호스트 영역                                      | [[DNS]] 설정의 단위. 도메인 전체 or 서브도메인                          |
| 레코드                                         | 도메인 or 서브도메인 안에 설정하는 개별 항목<br>도메인 이름 - [[IP 주소]] 연결 정보   |
| [[쿼리]]                                      | [[DNS]]에 문의하는 요청                                         |


### 라우팅 종류
- [[DNS 라운드 로빈]] 방식 -> [[부하 분산]] O

| 종류 | 내용 |
| --- | --- |
| 단순 [[Router\|라우팅]] | 관리자 지정 순서로 응답 |
| [[가중치]] 기반 라우팅 | 한 이름의 여러 [[DNS]] 레코드에 가중치 부여 -> 응답 비율 지정 |
| [[Delay\|지연]] 라우팅 | 지연 (Latency) 최소 [[서버]] 의 [[IP 주소]] 응답 |

### 비용
- 호스트 영역별 기본 요금 + [[쿼리]] 건수에 따른 요금 + 상태 확인 요금
