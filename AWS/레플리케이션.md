- 복제본을 만드는 것
- 따로 준비한 다른 [[버킷]]에 [[객체]]를 [[비동기]] 방식으로 복사
	- 복사 대상 버킷 소유자 ≠ 원래 버킷 소유자 Ok
	- 단, 복제 수행 가능한 [[IAM|IAM 역할]] 반드시 필요
	- 복제 참여 양 [[버킷]] 모드 [[버전 관리]] 활성화 해야함
- CRR (Cross-Region Replication) : 여러 [[리전]]에 복제본 만들어두기
