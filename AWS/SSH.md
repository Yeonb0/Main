- [[서버]]를 안전하게 원격 제어하기 위한 통신 [[프로토콜]]

- 키 페어 방식 사용 : [[인스턴스]]에 공개키 등록, [[클라이언트]]는 비밀키 사용

### 특징
- [[TCP IP|TCP/IP]] 원격 접속 서비스 -> 텔넷 대비 암호화 기능 O -> 주 사용
- 리눅스 [[운영체제|OS]] [[서버]]에 기본 탑재
- 접속할 서버의 방화벽에 SSH [[Port|포트]] 번호 허용 -> 즉시 원격 접속 O
- [[운영체제|OS]] 부팅 이후 화면만 확인 O, 부팅 중 BIOS/[[UEFI]] 화면 확인 X -> [[콘솔 서버]] 필요
