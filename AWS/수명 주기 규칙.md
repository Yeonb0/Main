- [[객체]]들의 집합에 대해 정기적으로 수행할 작업을 자동으로 지정

### 주요 작업 요소

| 작업 요소                          | 내용                                            |
| ------------------------------ | --------------------------------------------- |
| Transition                     | [[객체]]를 다른 [[스토리지 클래스]]로 옮김                   |
| Expiration                     | 유효 기간 지난 객체 삭제.<br>[[버전 관리]] 켜지면 최신 버전만 삭제 대상 |
| NoncurrentVersionTransition    | [[객체]]를 현재 [[스토리지 클래스]]에 얼마나 남겨 둘지 지정         |
| NoncurrentVersionExpiration    | 과거 객체 버전을 실제 삭제 전 얼마나 오래 보관할지 결정              |
| AbortIncompleteMultipartUpload | 멀티 파트 업로드 허용 최대 시간 지정                         |
| ExpiredObjectDeleteMarker      | 만료된 객체 삭제 표시 제거                               |
