- 영구적으로 데이터 보관 가능한 블록 스토리지 볼륨
- [[EC2 인스턴스]]와 조합해 사용

- [[HDD]] / [[SSD]] 중 선택 가능
	- [[HDD]] -> 대용량, 저렴, 느림
	- [[SSD]] -> 비쌈, 고성능

### 기능
- 탄력적 볼륨 (Elastic Volumes) : 볼륨 크기 쉽게 조정 가능
- [[스냅샷]] : 특정 시점 데이터 통째로 저장
- 데이터 라이프사이클 매니저 : 일정에 따라 스냅샷 자동 생성 · 삭제
- 최적화 인스턴스 : 특정 인스턴스 유형을 최적화 인스턴스로 지정 -> 읽기/쓰기 속도 향상
- 암호화 : 데이터 볼륨, 부트 볼륨, 스냅샷 암호화
