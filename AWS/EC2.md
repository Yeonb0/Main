- 컴퓨팅 리소스 제공 서비스
- 서버 기능, OS, 소프트웨어를 통합 임대 가능
- 다양한 사양의 인스턴스 GUI 로 간편 실행 가능
- 성능 변경, 백업 생성, 복제 수행 가능

### 서버 구축
1. [[서버]] 설치 & 필요 자원 준비 -> [[관리 콘솔]]에서 서치
2. [[서버 OS]] 로그인해 각종 설정 & 작업 수행 -> [[SSH]] 이용해 수행

#### 서버 구축 고려 사항
1. 어떤 [[서버]]와 [[네트워크]]가 필요한가?
	- 무엇에 사용할 것인가?
	- 데이터는 얼마나 증가할 것인가?
	- 예상 접속 수는 어느 정도인가?
2. 서버 구축에 필요한 요소 선택
	- 머신 사양 (CPU · 메모리 · 스토리지) -> 인스턴스 유형 · 크기
	- 소프트웨어 (OS · 미들웨어) -> [[AMI]]
3. 네트워크를 설계한다
	- 네트워크 -> [[VPC|Amazon VPC]]
	- 고정 IP 주소 -> [[Elastic IP]]
	- [[DNS]] -> [[Route 53|Amazon Route 53]]
	- [[로드 밸런서]] -> [[ELB]]
	- 보안 -> [[WAF|AWS WAF]]

### 기능

| 항목             | 내용                                                                      |
| -------------- | ----------------------------------------------------------------------- |
| 인스턴스           | [[AWS]] [[클라우드]]에서 생성하는 가상 서버.<br>[[AMI]] 기반으로 동일한 구성의 서버를 여러 번 만들 수 있음 |
| [[AMI]]        | 가상 이미지. ([[클래스]]와 유사) 다양한 AMI 제공                                        |
| 키 페어           | 인스턴스 접속 시 인증 위해 사용하는 키                                                  |
| [[EBS]]        | AWS 클라우드에서 사용하는 스토리지. 인스턴스의 디스크로 활용                                     |
| 보안 그룹          | 가상 [[방화벽]]. 1개 이상의 인스턴스에 대한 트래픽 제어                                      |
| [[Elastic IP]] | 고정 (정적) [[IPv4]] 주소                                                     |
- [[EC2 인스턴스]] : 물리적 [[서버]] + [[운영체제|OS]] + [[소프트웨어]]가 하나로 묶인 서버

### 절차
1. [[AWS]] 로그인
	- [[리전]] 선택 & [[관리 콘솔]] 열기
	- [[EC2]] [[대시보드]] 열기
2. [[EC2 인스턴스]] 생성하기
	- [[AMI|AMI(Amazon Machine Image)]] 선택하기
	- 인스턴스 유형 선택
	- 네트워크 · [[IP 주소]] 할당
	- 스토리지 추가
	- 보안 그룹 설정
	- 키 페어 선택 (작성)
3. [[EC2]]에 연결
	- [[SSH]]로 접속하기
4. [[소프트웨어]] 설치 · 설정

### 비용
- [[EC2 인스턴스]] 사용료 + [[EBS]] 요금 + 통신 요금 + 기타 옵션
