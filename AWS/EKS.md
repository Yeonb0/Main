- [[쿠버네티스]] 호환 환경 원할 때 사용
- [[쿠버네티스]]를 온프레미스 또는 클라우드에서 실행하는 관리형 [[서버 컨테이너|컨테이너]] 서비스

### 서비스 이름 & 구성
| 항목       | 이름                                                                |
| -------- | ----------------------------------------------------------------- |
| [[클러스터]] | 제어하는 리소스를 묶어 관리하는 단위                                              |
| Pod      | 컨테이너의 실행 단위. 볼륨 (스토리지) 도 포함 가능                                    |
| 디플로이먼트   | Pod 수를 항상 설정값대로 유지<br>- 동작 제대로하는지 감시 & 비정상 종료시 재생성                |
| 컨트롤 플레인  | [[클러스터]] 전체 관리 -> 모니터링 & 관리자 조작 따라 상태 변경<br>-> [[클러스터]] 구성 요소에 포함 |
| 매니페스트 파일 | Pod, 디플로이먼트의 설정 저장 문서. [[YAML]] 형식, 파일로 준비                        |
### 사용 흐름
1\. [[AWS]] 로그인
- EKS 대시보드 열기
- [[리전]] 선택, [[관리 콘솔]] 열기
2\. [[클러스터]] 만들기
- 클러스터 이름 설정
- 클러스터에 할당할 [[IAM]] 역할 설정
- [[쿠버네티스]] 버전 선택
- 배치할 네트워크 설정
- 관찰성 (모니터링 · 로그) 항목 설정
- 클러스터에서 실행할 추가 기능 구성하기
##### [[EC2]] 사용시
3\. 노드 그룹 만들기
- 노드 그룹 이름 설정하기
- 기동할 인스턴스 유형, 볼륨 크기, 인스턴스 수, [[IAM]] 역할 선택
- 배치할 네트워크 설정

##### [[Fargate]] 사용시
3\. Fargate 프로파일 만들기
- Fargate 프로파일 이름 설정
- Pod 실행 역할 설정
- 배치할 네트워크 설정
- 어떤 이름 공간의 Pod 실행할지 설정

4\. kubectl 로 작업할 수 있도록 설정
- `aws eks update-kubeconfig -region 리전 코드 -mane 클러스터 이름` dlqfur
- 인증 설정 완료 후 해당 클러스터 제어 가능

5\. Pod 나 Sevice 등 만들기

### 비용
- EKS 사용료 (시간당 0.10$) + 컨테이너 실행 환경 사용료
