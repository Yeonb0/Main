- AWS 자체 제공 [[서버 컨테이너|컨테이너]] 오케스트레이션 서버
- [[EC2]] 나 [[Fargate]] 와 함께 사용

### 서비스 이름 & 구성

| 항목       | 이름                                                 |
| -------- | -------------------------------------------------- |
| [[클러스터]] | 제어하는 리소스를 묶어 관리하는 단위                               |
| 태스크      | 컨테이너의 실행 단위. 볼륨 (스토리지) 도 포함 가능                     |
| 서비스      | 태스크 수를 항상 설정값대로 유지<br>- 동작 제대로하는지 감시 & 비정상 종료시 재생성 |
| 컨트롤러     | [[클러스터]] 전체 관리 -> 모니터링 & 관리자 조작 따라 상태 변경           |
| 태스크 정의   | 태스크, 서비스의 설정 저장 문서. [[JSON]] 형식, [[GUI]] 설정 가능     |

### 사용 흐름
1. AWS 로그인
2. 클러스터 만들고 설정

| 항목     | 내용                                               |
| ------ | ------------------------------------------------ |
| 네임스페이스 | 서비스를 묶어 관리하기 위한 명칭                               |
| 인프라    | 태스크 실행할 서버 유형 ([[Fargate\|AWS Fargate]]/[[EC2]]) |
3. 태스크 정의 만들기

| 항목                              | 내용                                               |
| ------------------------------- | ------------------------------------------------ |
| 태스크 정의 패밀리                      | 작업 정의에 부여할 이름                                    |
| 시작 유형                           | 태스크 실행 방식 ([[Fargate\|AWS Fargate]]/[[EC2]])     |
| [[운영체제\|OS]], [[아키텍쳐]], 네트워크 모드 | 태스크에 필요한 방식 선택                                   |
| 태스크 크기                          | 태스크가 요구하는 CPU 성능 & 메모리                           |
| 태스크 역할                          | 태스크 실행 시 사용할 [[IAM]] 역할                          |
| [[이미지]] URI                     | 실행하려는 컨테이너의 이미지 이름 or URI                        |
| [[Port\|포트]] 매핑                 | 실행 시 사용할 포트 설정                                   |
| 환경 변수                           | 컨테이너 실행 시 적용할 환경 변수                              |
| 로그 수집                           | 로그 기록 대상. [[CloudWatch\|Amazon CloudWatch]] 등 설정 |
| 스토리지                            | 컨테이너 실행 시 할당할 스토리지 설정                            |
4. 서비스 만들고 배포하기

| 항목                 | 내용                                                               |
| ------------------ | ---------------------------------------------------------------- |
| 기존 [[클러스터]]        | 배포 대상 (실행 대상) 클러스터                                               |
| 컴퓨팅 옵션             | [[부하 분산]]을 고려한 태스크 실행 방식                                         |
| 애플리케이션 유형          | 서비스 (상시 실행) or 태스크 (1회 실행 후 종료) 중 하나                             |
| 태스크 정의             | 실행 방식을 정의                                                        |
| 서비스 유형             | 복제본 (클러스터 전체에 필요한 수의 태스크 배치)<br>데몬 (배치 대상 인스턴스 마다 필요한 수의 태스크 배치) |
| 서비스 검색             | [[Route 53\|Amazon Route 53]] ([[DNS]]) 이용해 검색 설정                |
| 네트워킹               | 배포 대상 [[VPC]], [[Subnetting\|서브넷]], [[보안 그룹]]                    |
| [[로드 밸런서\|로드 밸런싱]] | [[ELB]]로 로드 밸런싱할 때 설정                                            |
| 서비스 자동 크기 조정       | [[CloudWatch]] 경보에 따라 태스크 수 자동으로 늘리/줄이기                          |
| 볼륨                 | 태스크 내 컨테이너에 스토리지 추가 설정                                           |

### 비용
- ECS 사용료 (무료) + 컨테이너 실행 환경 사용료
