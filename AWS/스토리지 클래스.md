- [[S3|Amazon S3]] 에서 사용 가능한 스토리지의 종류
	- 상황에 따라 변경 가능

### 종류
#### 표준 클래스
1. 범용 (S3 Standard)
	- 가장 기본적 스토리지 클래스
	- 3개 이상의 [[AZ]]에 데이터 저장 -> 99.99%의 가용성 보장
	- 데이터 검색 요금 X
	- 최소 용량 요금 X 

2.  접속 연동형 (S3 Intelligent-Tiering)
	- 접근 빈도 따라 최적화된 3 계층에 데이터 저장
	- [[S3 객체|객체]] 별로 접근 빈도 모니터링 -> 결과 따라 저장 계층 자동 변경
	- 모니터링 위한 추가 비용 발생

3. 고성능 (S3 Express One Zone)
	- 자주 접근해야하는 데이터 저장 위한 저렴 & 빠른 스토리지 클래스
	- 하나의 [[AZ]]에만 데이터 저장 -> 데이터 손실 위험↑

4. 저빈도 접근 (S3 Standard-IA/S3 One Zone-IA)
	- 표준 클래스보다 저장 요금 저렴, 데이터 접근 요금 높음
	- Standard-IA -> 최소 3개 이상의 [[AZ]] 저장
	- One Zone-IA -> 한 개의 [[AZ]] 에만 저장 

5. 아카이브 (S3 Glacier)
	- 데이터 아카이브 & 장기백업 목적
	- 대용량 데이터 낮은 비용으로 저장
	- 한 번 데이터를 꺼낼 때 ==전체 데이터== 가져옴
	- Flexible Retrieval : 기본적 아카이브 용도
	- Deep Archive : 검색 시간↑, 비용↓
	- Instant Retrieval : 즉시 검색 가능, 비용↑
