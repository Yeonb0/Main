### 인스턴스 유형
- `m` : 범용
- `r/x/y` : [[메모리]] 최적화
- `c` : 컴퓨팅 최적화
- `t` : 버스트 성능
- `r` : 읽기 최적화

| 용도      | 인스턴스 유형                   | 내용                                     |
| ------- | ------------------------- | -------------------------------------- |
| 범용(표준)  | `db.m3/m4/m5/m6/m7` 각 시리즈 | [[연산]] · [[메모리]] · 스토리지 성능이 균형 잡힌 인스턴스 |
| 메모리 최적화 | `de.r3/r5/x1/x2/z1` 시리즈   | 메모리 사용량 많은 시스템 적합                      |
| 컴퓨팅 최적화 | `db.c6gd`                 | 높은 [[CPU]] 성능이 필요한 계산 집약형 워크로드용        |
| 버스트 기능  | `db.t3/t4g`               | 짧은 시간, 높은 성능 필요한 스파이크형 워크로드용           |
| 읽기 최적화  | `db.r6id/r6gd`            | 빠르고 지연 낮은 읽기 처리 최적화                    |

### 인스턴스 클래스
- micro < small < medium < large < xlarge ~ 32xlarge
