- 인터넷 쇼핑몰로 알려진 아마존이 제공하는 [[클라우드 컴퓨팅 서비스]]
- [[클라우드 벤더]] 중 가장 큰 시장 점유율
- 다양한 서비스 조합 -> 모든 애플리케이션 위한 인프라 구현 가능 

### 장점
1. 300종이 넘는 서비스 제공 -> 자유롭게 조합 가능
   외부 시스템 or 네트워크와도 연결 가능
2. [[IaaS]], [[PaaS]], [[FaaS]] 형태의 서비스 제공
3. [[GUI]] 기반의 관리 콘솔 제공
4. [[매니지드 서비스]] (Managed Service)
	- 한 번 설정하면 AWS 가 자동으로 서버 관리
5. 종량제 방식 -> 사용한 만큼 비용 지불, 낭비 X
6. 한국어 & 원화 결제 지원
7. 글로벌 확장 & 중복화 용이
8. 보안 기준 충족

### 비용
- 사용하는 서비스 1개당 금액 + 사용한 만큼 과증 
- 장점 : 구축 · 운영 · 관리 수고 감소
- 단점 : 운영 비용 상대적으로 높아질 수 있음
