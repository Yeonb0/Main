- [[S3 객체|객체]]를 저장하는 상자
	- 저장 객체 수 제한 X
	- 전체 저장 용량 제한 X 
- 폴더와는 다른 개념 -> 버킷 안에 또다른 버킷 생성 불가능!
- [[AWS 계정]] 1 개당 최대 100개 생성 가능 -> 상향 신청 시 최대 1,000개 까지 가능
- 버킷 이름 -> [[S3]] ==전체== 에서 유일해야함 (다른 사용자가 사용중이면 사용 불가!)
- 한 번 생성 후에는 이름 or [[리전]] 변경 불가능

### 명명 규칙
- 버킷 이름의 시작 or 끝은 알파벳이나 숫자여야 함
- 3자 ~ 36자
- [[DNS]] 명명 규칙 따라야 함
- [[IP 주소]] 형식의 버킷 이름 지정 불가
- 대문자 or `_` 는 버킷명으로 사용 불가 
- ==ex)== `gilbut.bucket.marvelous.sample`
