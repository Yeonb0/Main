- 하나의 전송 매체를 여러 station 이 공유 -> 접근 순서 조정 필요
- 목표 : 여러 명 동시 전송 혼잡 X, 매체 효율적 사용

### 네트워크 구성
- point-to-point : 직접적으로 유선 연결
	- ==ex)== bus, [[switch]], hub
- shared medium : [[Wi-Fi]] 같이 무선 매체로 공유
	- 한 번에 한 user 만 전송 O -> control 필요
