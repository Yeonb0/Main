- [[IP 주소]] 기본형. 4 byte ($2^{32}$ 개)
- 이미 모두 소진

### 표기
- Binary Notation ↔ Dotted-decimal notation
- `10000000 00001011 00000011 00011111` ↔ `128.11.3.31`

### 배정
- IANA : 국가 별 배정
- APNIC : 아시아 국가들에 배정
- KRNIC : 한국 내에서 배정
- ISP : KT, LG U+, SKT 등 -> 개인에게 배정

### 구분
- [[IPv4 Class]] : [[컴퓨터 네트워크|Network]] / Host 주소 비율 분류
- [[Subnetting]] : mask 로 network / host 경계 표시
