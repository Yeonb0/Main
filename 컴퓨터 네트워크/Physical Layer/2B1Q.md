- 2 bit 가 한 [[Signal Element]] 로 mapping -> [[Multilevel Encoding]] 의 한 종류
- 4 signal levels (Q)
- [[DSL]] 에서 사용

![[Digital-Transmission-07.png]]

### 규칙
- 00 / 01 / 10 / 11 -> 2 bit 씩 묶어서 표현
	- 0X -> 앞이랑 부호 같음
	- 1X -> 앞이랑 부호 반대
	- X0 -> 1
	- X1 -> 3
