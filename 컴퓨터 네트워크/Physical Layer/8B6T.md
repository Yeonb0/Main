- level 3개 · 6 signal element 로 8 bit 표현 -> [[Multilevel Encoding]] 의 한 종류
	- $3^6$ = 729 로 $2^8$ = 256 개 표현
	- 특정한 pattern 만 사용
- 100BASE-4T 에서 사용

### 조건
- `+`, `-` 균형이 맞는 pattern 만 사용
	1. `+` 와 `-` 갯수가 일치
	2. `+` 가 한 개 더 많음 -> 다음 나오는 불균형 [[신호]]를 ==invert== -> `-` 가 하나 더 많도록 상쇄
