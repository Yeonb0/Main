- 장애물 · 반사 때문에 수신 [[신호]] 세기 변동
- [[Pathloss]] 와 함께 수신 세기 결정 ==2 요소==

### 종류
| 종류 | 원인 |
| --- | --- |
| Slow (large-scale) fading | 아파트 같은 큰 건물 · 동산에 가려짐 -> 감쇠 |
| Fast (small-scale) fading | 반사 -> 여러 경로 도달 -> 위상 증폭 · 상쇄 |

![[Case-Study-Wi-Fi-03.png]]

### 특징
- 경로별 속도 차이 -> 위상 차 -> 증폭 / 상쇄
- 작은 움직임에도 신호 변화 -> fast fading
- 다중 안테나로 완화 -> [[MIMO]] 의 diversity gain
