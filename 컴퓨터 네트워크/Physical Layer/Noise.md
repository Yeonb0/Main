- 원하지 않는 주파수가 [[신호]]에 첨가되는 [[Transmission Impairment]]
- 복원하기 어려움

### 종류
| 종류 | 원인 |
| --- | --- |
| Thermal noise | 전자의 임의적 움직임 |
| Induced noise | motor, power line 의 자기장 |
| Crosstalk | 주변 유선 / 무선의 간섭 |
| Impulse noise | 갑작스러운 일 (번개, power surges 등) |

### 특징
- 신호 대비 크기 측정 -> [[SNR]]
- noise 고려 X 전송 한계 -> [[Nyquist Equation]]
- noise 고려 O 전송 한계 -> [[Shannon Capacity]]
