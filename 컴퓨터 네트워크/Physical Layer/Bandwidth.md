- [[신호]]가 차지하는 Frequency 의 영역
- ==highest frequency - lowest frequency== -> 중간 주파수 상관 X

![[Data-and-Signals-09.png]]

### 종류
| 구분 | 내용 |
| --- | --- |
| Frequency bandwidth | channel 통과 가능한 frequency 범위 (Hz) |
| Data bandwidth | channel 이 버틸 수 있는 maximum bit rate |

- 두 의미 서로 [[연관성]] 있음 -> 비례

### 특징
- bandwidth ↑ -> [[Data Transfer Rate]] ↑
- 최대치 개념 -> 실제 전송량은 [[Throughput]] (Throughput < Bandwidth)
- bandwidth = f -> 최고 transfer rate = 2f

### 예시
- ==ex)== AM Radio : 대역폭 10kHz, 530 ~ 1700kHz band 사용
- ==ex)== FM Radio : 대역폭 200kHz, 88 ~ 108MHz band 사용
- ==ex)== Wi-Fi 802.11n : 대역폭 20MHz | 40MHz, 2.4GHz · 5GHz · 6GHz band 사용
- ==ex)== LTE : 대역폭 10MHz | 20MHz, 1.8GHz band 사용
