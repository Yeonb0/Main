- binary data -> digital signal 변환
- [[Physical Layer]] 에서 [[Data Element]] 를 [[Signal Element]] 로 표현하는 과정

### 종류
- [[Line Coding]] : data element 를 signal element 로 직접 대응
- [[Block Coding]] : m bit -> n bit 확장 -> 여분 bit 로 [[동기]] · 오류 검출
- [[Scrambling]] : bit 추가 X, 0 지속 구간만 치환
