- [[서버 컨테이너|컨테이너]]를 오케스트레이션할 수 있는 도구
	- 시스템 전체 통합적 관리 & 여러 컨테이너 한 번에 제어

### 특징
- [[서버 컨테이너|컨테이너]]를 ==Pod== 라는 단위로 실행
	- 컨테이너 + 볼륨이 한 세트로 묶인 것
- [[클러스터|Cluster]]를 구성
	- 마스터 노드 + 워커 노드 조합으로 구성
	- 마스터 노드 : 워커 노드들에 명령 & 전체 관리
	- 워커 노드 : Pod 가 실제로 실행되는 노드
- 자율적으로 작동
	- 마스터 노드의 설정 변경으로만 동작
