- 통신에 이용되는 규칙
- IETF (Internet Engineering Task Force) · ISO (International Organization [[for]] Standardization) 같은 기관에서 책정
	- [[컴퓨터 네트워크|네트워크]] 장비 업체 -> 규정에 맞게 장비 & [[소프트웨어]] 개발
- 각 계층 별 규정 -> 목적에 맞게 조합해 사용

### 계층별 종류
| 계층 | 프로토콜 |
| --- | --- |
| 응용 계층 | 파일 공유 ([[FTP]]), 웹 (HTTP), 이메일, 채팅, IP 전화, [[DHCP]] |
| 전송 계층 | [[TCP]], [[UDP]] |
| 네트워크 계층 | [[IP]] |
| [[데이터]] 링크 계층 | [[Ethernet\|이더넷]], 무선 [[LAN]], ISDN, ADSL |

### 특징
- 각 계층 프로토콜 -> 자신 계층만의 헤더 추가 or 제거
- 계층 분류 기준 -> [[OSI 참조 모델]] / [[TCP IP|TCP/IP]]

### 운용 관련 프로토콜
- [[NTP]] : 시간 동기화
- [[SNMP]] : 네트워크 장비 · [[서버]] [[state|상태]] 감시
- [[SSH]] : 암호화 원격 접속
