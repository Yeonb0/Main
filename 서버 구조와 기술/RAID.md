- 스토리지 [[이중화]] 구성
- 대량 [[데이터]] 를 여러 스토리지에 분할 저장
- 디스크 : 보조 기억 장치
	- [[메모리]]로 저장 불가능한 데이터 보관
	- 비휘발성 -> 전원 차단해도 데이터 유지
- 스토리지 : 외부 기억 장치
	- 데이터 장기 기억시키는 디스크 집합
	- [[컴퓨터 네트워크\|네트워크]] 경유 ([[NAS]]) or 전용 스토리지 [[컴퓨터 네트워크|네트워크]] 경유 ([[SAN]]) 로 이용

### 종류
- RAID0 : 스트라이핑
	- 이중화 구성 X
	- 데이터 블록 단위 분할 -> 여러 디스크 분산 -> 읽기 · 쓰기 속도 ↑
	- 디스크 장애 -> ==모든 데이터 손실==
	- ![[서버-장애에-대비하자-01.png]]
- RAID1 : 미러링
	- 동일 데이터를 디스크 ==2개== 에 거울처럼 똑같이 저장
	- ![[서버-장애에-대비하자-02.png]]
- RAID5 : RAID0 + 패리티 디스크
	- 에러 정정 & 데이터 복구 O
	- 패리티 디스크 분산 저장 -> 읽기 · 쓰기 성능 ↑
	- ![[서버-장애에-대비하자-03.png]]
- RAID6 : RAID5 의 패리티 디스크 ==2개== 로 확장
	- 디스크 ==2개== 동시 고장에도 데이터 복구 O
	- ![[서버-장애에-대비하자-04.png]]

### 구성 방식
| 방식 | 내용 |
| --- | --- |
| 소프트웨어 방식 | [[서버]] 설치 [[소프트웨어]] 가 다수 디스크 드라이브를 하나의 디스크로 취급 |
| 하드웨어 방식 | 서버 [[CPU]] 와 독립된 컨트롤러 보유 -> 장애 부위 발견 쉬움 ↔ 구성 비용 ↑ |
