- URL · 이메일 주소 -> [[IP 주소]] 변환 매커니즘 or 그 [[서버]]
- [[웹 서버]] 통신 -> URL ([[도메인]]) 이용 -> [[이름]] 해석 필요

### 이름 해석 절차
1. 모르는 정보 -> 다른 DNS 서버에 문의
2. 알아낸 DNS 서버에 또 문의
3. 반복

- [[루트 DNS]] : 최상위 [[도메인]] 관리 서버
	- ==ex)== `com`, `net`, `kr`
- [[메일 서버|메일 시스템]] 에서도 이용 -> 중요 서버 -> 보통 ==기본 서버 + 보조 서버 2대== 구성

### 소프트웨어
- BIND : 점유율 최다, [[Linux|리눅스]] 계열 [[운영체제|OS]] 표준
- PowerDNS : GUI 관리 O
- NSD : 속도 빠름 ↔ [[업데이트]] · Q&A 서비스 약함
- 직접 구축 X -> 인터넷 서비스 제공자 서버 이용 다수
