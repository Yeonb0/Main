- 컴퓨터에서 이용되는 다수 [[프로토콜]] 을 역할별로 분류한 7계층 모델
- 상위 계층 -> 하위 계층 기능 (서비스) 이용
- 하위 계층 -> 상위 계층에 기능 제공

### 구조
| 층 | [[이름]] | 역할 |
| --- | --- | --- |
| 7계층 (L7) | 응용 계층 (Application Layer) | 애플리케이션 서비스 제공 |
| 6계층 (L6) | 표현 계층 (Representation Layer) | 데이터 형식을 일반적 형식으로 변환 |
| 5계층 (L5) | 세션 계층 (Session Layer) | 세션 (통신 시작 ~ 종료) 관리 |
| 4계층 (L4) | 전송 계층 ([[Transport Layer]]) | 고품질 데이터 전송 확보 |
| 3계층 (L3) | [[컴퓨터 네트워크\|네트워크]] 계층 ([[컴퓨터 네트워크\|Network]] Layer) | 네트워크끼리 중계 |
| 2계층 (L2) | 데이터 링크 계층 (Data Link Layer) | 같은 [[컴퓨터 네트워크\|네트워크]] 내에서 통신 제공 |
| 1계층 (L1) | 물리 계층 (Physical Layer) | [[데이터]] → 전기 [[신호]] 변환해 전송 |

### 역할 구분
- 1 ~ 3 계층 : 데이터 전송
- 4 계층 : 데이터 전송 보완
- 5 ~ 7 계층 : 통신 서비스 기능

### 비교
- [[TCP IP|TCP/IP]] : 실제 인터넷 통신 규약 -> 계층 수 더 적음
