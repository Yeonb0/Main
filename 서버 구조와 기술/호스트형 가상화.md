- 물리 [[서버]]의 [[운영체제|OS]] 위에서 가상화 [[소프트웨어]] 작동 -> 그 위에 [[가상 머신]] 구축
- 가상화 소프트웨어 = 호스트 OS 상의 애플리케이션처럼 작동
- ==ex)== Oracle VM VirtualBox, VMware Workstation Player

### 장점
- 손쉬운 가상 환경 이용

### 단점
- 매번 호스트 OS 경유 -> 오버헤드로 성능 ↓
- 애플리케이션 동작 불안정 가능
