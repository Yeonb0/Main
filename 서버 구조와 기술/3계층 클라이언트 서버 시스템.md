- [[클라이언트-서버 시스템]] 을 표현 · 응용 · [[데이터]] ==3계층== 으로 분리한 구조
- 각 계층 독립된 모델 -> 독립적 관리 O

### 구조
| 계층 | 역할 | [[웹 시스템]] 대응 |
| --- | --- | --- |
| 표현 계층 | 사용자 GUI 담당 | [[웹 서버]] |
| 응용 계층 | 주 기능이 될 업무 처리 제공 | [[웹 애플리케이션 서버]] |
| 데이터 계층 | 데이터 관리 기능 제공 | [[데이터베이스 서버]] |

- 응용 계층 : 업무 처리에 의존하는 데이터 가공
- 데이터 계층 : [[데이터베이스]] 처리

### 응용 계층 서버 측 배치 시
- 애플리케이션 수정 -> [[서버]] 측에서 종료
- [[클라이언트]] 측 -> 화면 조작만 담당
- 처리 요청 & 결과 데이터만 통신 -> [[컴퓨터 네트워크|네트워크]] 부하 ↓
