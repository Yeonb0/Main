- 각종 대상에서 로그 수집 -> 보관 · 감시 · 분석하는 [[서버]]
- 로그 관리 -> 장애 예측 & 장애 탐지 속도 ↑

### 기능
| 기능 | 내용 |
| --- | --- |
| 로그 수집 | 각종 대상에서 로그 수집 |
| 로그 보관 | 수집한 로그 안전하게 보관 |
| 로그 감시 | 문제 발생 시 통지 & 대응 |
| 로그 분석 · 리포트 | 로그 [[데이터]] 집계 & 분석 · 리포트 |

### 관련
- 시스템 로거 : 각 [[서버]]에서 로그 관리하는 것
- ==ex)== 리눅스의 [[syslog]]
- 오래된 로그 -> 백업 or 삭제 조치 필요 -> [[로그 로테이션]]
