- 외부에서 시도하는 부정 접근 차단 기능
- [[보안 구역]] 경계에 [[배치 처리|배치]] -> 구역 간 통신 제어

### 기능
- [[패킷 필터링]] : 발신자 [[IP 주소]] · 이용 중 [[Port|포트]] 확인 -> 필요 없는 통신 차단

### 한계
- 정상 통신으로 위장한 불법 통신 탐지 X -> [[IDS]] · [[IPS]] 병행
- 웹 애플리케이션 계층 공격 차단 X -> [[WAF]] 병행
- 통합 이용 형태 -> [[UTM]]
