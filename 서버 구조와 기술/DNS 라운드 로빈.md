- [[DNS]] 질의에 응답하는 [[서버]] 를 순차적으로 변경하는 [[부하 분산]] 기술
- 응답 대상 서버군 -> [[클러스터링]] 구성

### 절차
1. [[클라이언트]] -> [[웹 브라우저]]로 URL 접속
2. 클라이언트 -> URL 기재 [[웹 서버]] 의 [[FQDN]] (Fully Qualified Domain Name, 전체 [[도메인]] 이름) 으로 [[DNS]] 서버에 [[이름]] 해석 요청
3. DNS 서버 -> 요청마다 서버 A / 서버 B / 서버 C 주소 번갈아 [[IP 주소]] 응답
4. 클라이언트 -> 응답받은 IP 주소로 통신
