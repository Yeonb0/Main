- 사용자마다 공개 키 / 개인 키 쌍 생성
	- 공개 키 : 일반에게 공개
	- 개인 키 : 사용자가 비밀로 관리
- 한쪽 키로 암호화 -> 다른 쪽 키로 복호화 O

### 장점
- 통신 중 유출돼도 개인 키로만 복호화 O -> 안전
- 키 사전 공유 불필요 -> cf) [[공통 키 암호 방식]]
