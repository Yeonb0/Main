- 사내 [[컴퓨터 네트워크|네트워크]] 안에서만 서비스 제공하는 [[서버]]
- 내부 세그먼트에 설치 -> cf) [[사외용 서버]] : [[DMZ]] [[배치 처리|배치]]

### 종류
| 서버 | 기능 |
| --- | --- |
| [[DNS 캐시 서버]] | [[LAN]] 내부 기기에 [[이름]] 해석 (도메인 이름 + [[IP 주소]] 연결 정보) 기능 제공 |
| [[파일 서버]] | LAN 내부 기기에 파일 관리 서비스 제공 |
| [[프린터 서버]] | LAN 내부 기기에 인쇄 기능 제공 |
| [[디렉터리 서버]] | LAN 내부 사용자 정보 관리 |
| [[데이터베이스 서버]] | 기업 내 중요 [[데이터]] 관리 |
| [[그룹웨어 서버]] | LAN 내부 사용자에게 이메일 · 일정 관리 등 기업에 필요한 서비스 제공 |

- [[DHCP]] 서버 : LAN 내부 기기에 [[IP 주소]] 자동 할당
- [[버전 관리 시스템]] 서버 : 원격 [[Repository|레포지터리]] 공유
