- [[미들웨어]] & 애플리케이션만 가상화, [[운영체제|OS]] 탑재 X
- 물리 [[서버]]의 OS 위에서 [[컨테이너 엔진]] 동작 -> 그 위에 컨테이너 구축
	- 컨테이너 = [[가상 머신]] 역할

### vs. [[서버 가상화]]
- 차이 = 게스트의 OS 탑재 여부
- 일반 서버 : 물리 서버 위에 OS 1 개
- 서버 가상화 : 게스트마다 OS 탑재
- 서버 컨테이너 : OS 탑재 X

### 장점
- 자동 증감 [[스케일링|스케일]] 대응 빠름
- 물리 서버 1 대에 가상 머신보다 많은 컨테이너 탑재 O
