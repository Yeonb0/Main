- [[Router|라우터]] [[이중화]] [[프로토콜]]
- [[컴퓨터 네트워크|네트워크]] 장비 이중화 수단
- 메인 시스템 라우터 + 대기 시스템 라우터 -> 논리적으로 ==1대== 의 라우터처럼 동작
- 항상 가상 [[IP 주소]] (VIP, Virtual [[IP]]) 를 기본 [[게이트웨이]] 로 설정해 통신

### 장점
- 경로 전환 위한 기본 [[게이트웨이]] 설정 변경 X

### 상태
| 라우터 | [[state\|상태]] |
| --- | --- |
| 메인 라우터 | Active |
| 대기 라우터 | Standby |

- 그룹 내 라우터끼리 응답 상태 확인
- 메인 라우터 장애 -> 메인 우선순위 ↓ -> 대기 라우터 우선순위 ↑ 되도록 설정
