- 기업에서 필요한 [[소프트웨어]] 모아 제공하는 [[서버]]
- 그룹웨어 : 그룹 소프트웨어
- [[사내용 서버]] -> [[LAN]] 내부 사용자 대상

### 기능
| 기능 | 내용 |
| --- | --- |
| 스케줄 관리 | 스케줄 등록 & 공유 |
| 게시판 | 한 게시물에 여러 사람 의견 교환 |
| 시설 예약 | 시설 예약 & 확인 |
| 메시지 | 이메일 or 채팅 |
| 근태 관리 | 출퇴근 시간 기록 |
| 워크플로 | 각종 수속 신청 & 승인 |

### 특징
- 자체적 구축 X -> 보통 서비스 이용
- ==ex)== Office 365 (마이크로소프트), 구글 스위트 (구글)
