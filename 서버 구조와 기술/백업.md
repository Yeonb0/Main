- [[데이터]] 손실 대비 -> 별도 보관
- 복원 : 백업에서 데이터를 원래대로 되돌리는 것

### 대상
| 대상 | 영역 | 주기 |
| --- | --- | --- |
| 시스템 백업 | [[운영체제\|OS]] 및 애플리케이션이 설치된 영역 | 변경 少 -> 유지 보수 작업 이후 주로 수행 |
| 데이터 백업 | 애플리케이션이 사용하는 데이터를 저장한 영역 | 기본적으로 매일 |

### 방식
| 방식 | 범위 | 특징 |
| --- | --- | --- |
| 전체 백업 | 모든 데이터 | 전체 데이터 복구 O, 시간 ↑ |
| 차등 백업 | 마지막 전체 백업 이후 변경 데이터 | 복구 = 전체 백업 -> 차등 백업 |
| 증분 백업 | 직전 백업에서 변경된 데이터만 | 백업 시간 ↓, 복구 시간 ↑ |
