- 파일 변경 이력 저장 · 관리 서비스
- 변경 이력 = 언제 · 누가 · 어떤 목적으로
- 필요 시 과거 [[state|상태]] 롤백 O
- 여러 사람 작업 결과 병합 O
- ==ex)== [[Git]], [[Subversion]]

### 절차
1. 사용자가 파일 작성 or 수정 -> 작업 장소 : 워크 [[트리]] (work tree)
2. 시스템 관리 임시 영역에 파일 [[배치 처리|배치]] -> 임시 영역 : 인덱스 (index)
3. 인덱스 배치 파일에 세이프 포인트 설정 -> 조작 : [[Commit|커밋 (commit)]]
4. 관리 영역에 커밋 파일 배치 -> 관리 영역 : [[Repository|레포지터리 (repository)]]

### [[Repository]] 종류
| 종류 | 위치 |
| --- | --- |
| 원격 레포지터리 | 전용 [[서버]] 배치 -> 여러 사람 공유 |
| 로컬 레포지터리 | 사용자 개개인의 로컬 컴퓨터 배치 |

### 조작
- 클론 (clone) : 이미 있는 레포지터리 [[레플리케이션|복제]]
- 패치 (fetch) : 다른 레포지터리의 변경 사항 확인 & 가져오기
