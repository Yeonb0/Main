- [[컴퓨터 네트워크|네트워크]] 관리 -> 설정 파일 이용
	- [[운영체제|OS]] 공통 설정 파일
	- 장치별 연결 파일
- 물리적 네트워크 장치 ([[Ethernet|이더넷]], [[IEEE 802.11|Wi-Fi]], 적외선, 블루투스) -> OS 에서 네트워크 장치로 인식

### 종류
| 장치 | 내용 |
| --- | --- |
| 루프백 (lo) | [[TCP/IP]] 이용 단말에 반드시 필요, 네트워크 검증용 |
| 이더넷 (enX, wlX) | NIC 를 논리적으로 [[캡슐화]], 유선 en… · 무선 wl… |
| 본딩/티밍 (bondX, teamX) | NIC 이중화를 위해 NIC 를 묶었을 때의 가상 장치 |

- 이더넷 장치명 -> [[운영체제|OS]] 가 장치 찾은 순서대로 명명 (X 는 숫자 or 알파벳)
- 본딩/티밍 -> 마스터 NIC · 슬레이브 NIC 설정 파일과 연동해 작동
