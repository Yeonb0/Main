- 시스템에 부정적 영향 미칠 가능성 (잠재적)
	- ==ex)== 도청, 사칭, 서비스 방해, 정보 유출
- 인시던트(incident) : 실제로 부정적 영향 미치는 사건 발생
- 리스크 예방 + 인시던트 대응 -> 둘 다 중요

### 구성
- 취약점 : 시스템이 안고 있는 결함
- 위협 : 결함을 공격하는 것
- 자산 : 보호 대상
- 리스크 = 위협 × 취약점 × 자산

### 자산 종류
| 종류 | 예 |
| --- | --- |
| [[소프트웨어]] | [[데이터베이스]], [[데이터]] 파일, 설계서 |
| 하드웨어 | 컴퓨터, 통신 장비, 기억 매체 |
| 서비스 | 전원, 난방, 조명, 통신망 |
| 사람 | 사람 자체 |
