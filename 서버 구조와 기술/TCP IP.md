- [[LAN]] · 인터넷에서 널리 사용되는 통신 규약
- [[OSI 참조 모델]] 보다 적은 수의 계층 -> 4계층

### 계층 대응
| OSI | TCP/IP | 역할 |
| --- | --- | --- |
| 응용 · 표현 · 세션 계층 | 응용 계층 (Application Layer) | 사용자에게 각종 서비스 제공 |
| 전송 계층 | 전송 계층 ([[Transport Layer]]) | 출발지 → 목적지로 [[데이터]] 전송 |
| [[컴퓨터 네트워크\|네트워크]] 계층 | [[컴퓨터 네트워크\|네트워크]] 계층 ([[컴퓨터 네트워크\|Network]] Layer) | 데이터 전송 경로 선택 + 전송 & 중계 |
| 데이터 링크 · 물리 계층 | 데이터 링크 계층 (Data Link Layer) | 데이터 전송 경로 제공 |

### 계층별 기능
- 응용 계층
	- 애플리케이션 담당
	- 파일 공유 · 웹 · 이메일 · 채팅 · IP 전화 · [[DHCP]]
- 전송 계층
	- 큰 애플리케이션 데이터를 정해진 크기로 작게 분할
	- 목적지 ([[IP 주소]]) 붙은 [[Packet|패킷]] 에 분할 데이터 적재
	- 도착한 데이터에서 분할된 데이터 다시 연결
	- [[TCP]] / [[UDP]]
- [[컴퓨터 네트워크|네트워크]] 계층
	- MAC 프레임에 패킷 넣고 배송 방법 결정
	- 필요 경로 선택 ([[Routing Algorithm|라우팅]]) 후 전송
	- [[IP]]
- 데이터 링크 계층
	- 받은 데이터를 목적지까지 전송
	- [[Ethernet|이더넷]] : 수신 패킷에 MAC 헤더 부착 -> 보낼 상대 지정
