- [[커널]] 프로그램 [[메모리]] 로드 -> CPU 가 커널 실행 시점에 [[운영체제|OS]] 시작
- 한 기기에 여러 서비스 제공 O

### 절차
1. 전원 켜기
2. BIOS/[[UEFI]] 시작 -> 커널을 [[메모리]]에 로드
3. 부트 로더 로딩 -> 커널 & 초기 RAM 디스크 로드
	- 초기 RAM 디스크 : 커널 로드 직후 사용할 디바이스 드라이버 저장
4. 커널 로딩
5. 초기 프로세스 실행 (init/systemd)
	- init 프로그램(systemd) : 모든 서비스 실행 상위 프로그램
	- 시작 · 정지 · 재시작 · 활성화 · 비활성화 · 자동 시작 관리
