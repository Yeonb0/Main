- [[서버 컨테이너|컨테이너]]를 실행하기 위해 바탕이 되는 것
- 컨테이너에서 실행할 애플리케이션 + 의존 파일 포함 데이터
	- 환경 변수 등

- 컨테이너 재료
	- 도커파일 (Dockerfile) : 컨테이너 작성 절차 기록 파일
	- 컨텍스트 (Context) : 컨테이너에 저장하거나, 빌드할 때 사용하는 파일

#### ==ex)==
- `Hello, World!` 를 출력하는 셸 스크립트 작성
```sh
$ mkdir myimage
$ cat <<EOF > ./myimage/hello.sh
#!/bin/bash
set -eu
echo "Hello, World!"
exec sleep infinity
EOF
$ chmod +x ./myimage/hello.sh
```

- Dockerfile 작성
```sh
$ cat <<EOF > ./myimage/Dockerfile
FROM ubuntu:22.04           
COPY ./hello.sh /hello.sh
ENTRYPOINT ["/hello.sh"]
EOF
```

1. `FROM`: `ubuntu:22.04` 이미지를 바탕으로 새 이미지 작성 선언
2. `COPY`: 컨텍스트에 포함된 `hello.sh` 파일을 컨테이너 내부의 `/hello.sh`에 복사
3. `ENTRYPOINT`: 컨테이너를 가동할 때 `hello.sh` 를 실행하도록 지시
