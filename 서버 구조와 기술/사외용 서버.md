- 인터넷에 서비스 제공 · 인터넷상 단말기와 정보 주고받는 [[서버]]
- [[DMZ]] 에 [[배치 처리|배치]] -> 사내 세그먼트와 격리

### 종류
| 서버 | 기능 |
| --- | --- |
| [[웹 서버]] | 인터넷상의 단말기에 웹 페이지 제공 |
| [[웹 애플리케이션 서버\|웹 애플리케이션 서버(WAS)]] | 애플리케이션 실행 -> 웹 페이지 내용 생성, 화면 표시는 [[웹 서버]] 담당 |
| DNS 콘텐츠 서버 | 인터넷상의 단말기에 [[이름]] 해석 (도메인 이름 + [[IP 주소]] 연결 정보) 기능 제공 |
| [[메일 서버]] | [[LAN]] 내부 단말기 -> 인터넷상 단말기에 이메일 전송 |
| SSL 서버 | 인터넷상 단말기 - LAN 내부 기기 간 통신 암호화 |
| FTP 서버 | 인터넷상의 단말기에 파일 전송 기능 제공 |

### 배치
- 대규모 환경 : [[방화벽]] 으로 분리된 [[DMZ]] 에 서버 여러 대 배치
- 소규모 환경 : 서버 한 대가 방화벽 + 서버 기능 겸함 -> 보안 수준 ↓
