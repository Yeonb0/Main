- 비무장 지대, 인터넷 ↔ 내부 [[컴퓨터 네트워크|네트워크]] 분리 영역
- [[LAN]] 과 인터넷 경계에 [[배치 처리|배치]] -> 내부 직접 노출 X
- 함께 구성 : [[방화벽]], [[Router|라우터]]
- 사내 [[컴퓨터 네트워크|네트워크]] 와 인터넷 사이에 [[배치 처리|배치]]하는 완충 구간
- 중요 [[서버]] 배치 네트워크로 향하는 부정 통신 · 공격적 통신 방지

### 특징
- [[사외용 서버]] 의 배치 위치
- [[방화벽]] 으로 사내 세그먼트와 분리
	- 대규모 환경 : 방화벽으로 분리된 DMZ 에 서버 여러 대 배치
	- 소규모 환경 : 서버 한 대가 방화벽 + 서버 기능 겸함 -> 보안 수준 ↓
