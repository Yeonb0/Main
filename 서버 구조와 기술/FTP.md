- 파일 전송 목적 서비스 · 프로토콜
- 익명 FTP 서비스 -> 공개 [[소프트웨어]] 내려받기
- 웹 사이트로 콘텐츠 전송

### 소프트웨어
- vsftpd : [[Linux|리눅스]] 계열 표준 FTP [[서버]]
- [[IIS|인터넷 정보 서비스(IIS)]] : 윈도우 계열 FTP 서버

### 클라이언트 조작법
- [[Command|커맨드]]라인 : 명령어 [[String|문자열]] 입력
- FTP 클라이언트 소프트웨어
	- ==ex)== FFFTP, WinSCP

### 통신
- [[TCP]] 프로토콜 일종
	- 제어용 ==TCP 21번== [[Port|포트]]
	- 전송용 ==TCP 20번== [[Port|포트]]

### 절차
1. 클라이언트 - 서버 TCP 21번 포트 접속 -> 제어용 커넥션 시작
2. 클라이언트 - 전송용 커넥션 위한 포트 준비 & 번호 서버에 전달
3. 클라이언트 - 서버에 파일 전송 요청
4. 서버 - 2에서 받은 포트에 접속 -> 전송용 커넥션 시작 (TCP 20번)
5. 파일 전송 시작

### 모드
| 모드 | 전송용 커넥션 방향 |
| --- | --- |
| 액티브 모드 | 서버 -> [[클라이언트]] |
| 패시브 모드 | [[클라이언트]] -> 서버 |

- 패시브 모드 -> [[NAT|NAPT]] 기능 등으로 [[IP 주소]] · 포트 변경되어 [[Router\|라우터]] 경유 시 사용
