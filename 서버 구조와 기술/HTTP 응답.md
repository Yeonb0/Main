- [[웹 서버]] -> [[클라이언트]] 방향 [[HTTP]] 메시지
- [[HTTP 요청]] 에 대한 처리 결과 반환

### 구성
| 정보 | 내용 |
| --- | --- |
| [[state\|상태]] 라인 | 요청 처리 결과 나타내는 ==세 자리 숫자== |
| 헤더 부분 | [[서버]]에서 보낸 정보 유형 · 콘텐츠 크기 · 갱신 일시 등 |
| 바디 부분 | [[클라이언트]] 가 지정한 URL 콘텐츠 정보 |

### 상태 코드
| 범위 | 의미 |
| --- | --- |
| 100 ~ 199 | 정보 제공 |
| 200 ~ 299 | 성공 |
| 300 ~ 399 | 리다이렉트 |
| 400 ~ 499 | 클라이언트 [[Error\|오류]] |
| 500 ~ 599 | 서버 오류 |

### 예시
- ==ex)==

```yaml
HTTP/1.1 200 OK
Content-Type: text/html

<!DOCTYPE html>
<html>
```
