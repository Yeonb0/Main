- [[폰 노이만 구조]]를 그대로 반영한 언어 형태
- 프로그램 = [[하드웨어]] 동작 시나리오 -> 하드웨어와 연결해 사고

### 대응
| 하드웨어                 | 언어                           |
| -------------------- | ---------------------------- |
| Memory cell          | [[변수]]                       |
| Store                | [[연산\|Operation]] Assignment |
| Arithmetic Operation | Expression                   |
| Conditional Jump     | Loop / If                    |
