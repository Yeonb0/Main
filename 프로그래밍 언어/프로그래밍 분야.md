- 어떤 영역에서 어떤 [[프로그래밍 언어]]를 사용할 것인가?

1. 과학 계산 : [[실수|floating point]] 계산
	- ==ex)== FORTRAN
2. 비즈니스 영역 : 10진수 처리, 복잡한 입출력
	- ==ex)== COBOL
3. [[AI]] : Symbol 처리
	- ==ex)== LISP, PROLOG
		- 현재는 사용 X
4. [[시스템 프로그래밍]] : [[하드웨어]] 제어 위한 bit 단위 [[연산|Operation]]
	- ==ex)== [[C]]
		- high-level 은 bit & memory 접근 회피 목적 -> [[OS]] 작성 필요성 -> 등장
5. Web Software : Dynamic 한 content
	- ==ex)== [[JavaScript]]
		- [[웹 브라우저]] 내 [[인터프리터|interpreter]] 내장 -> Web [[운영체제|OS]] 위 Web App
