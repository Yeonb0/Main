- 기본적으로 [[stack]]-dynamic

### Stack-dynamic Local Variable
- subprogram 실행 시작 시 storage bind, 종료 시 해제 -> [[저장소 바인딩]]
- 장점
	- 재귀적 subprogram 허용
	- 저장 공간 공유
- 단점
	- 호출마다 할당 · 초기화 · 해제 시간 비용
	- 간접 참조 -> 속도↓
	- history-sensitive procedure 허용 X

### Static Local Variable
- program 실행 시작 시 storage bind
- 장점
	- 빠른 참조 허용
	- history-sensitive procedure 가능
- 단점
	- 재귀 허용 X
