- [[Subprogram]] 내에서 visible 하지만 내부 선언 X 인 [[변수]]
- [[지역 변수]] 와 대비

### [[Scope]] 별 문제
- [[Static Scope]] 언어 : 필요 이상의 nonlocal 접근 허용
- [[Dynamic Scope]] 언어 : nonlocal 변수 참조 static 하게 [[타입 검사]] 불가능

### 언어별 접근
- FORTRAN : `COMMON` 통해 전역 저장소 [[Block|블록]] 접근
	- 첫 `COMMON` 문 발견 시 생성
	- 문제점 -> 두 subprogram 이 서로 다른 [[이름]]으로 동일 [[데이터]] 블록 포함 O
- [[C]] : procedure 중첩 X
	- 전역 변수 -> [[함수]] 정의 외부 선언으로 생성
	- `extern` 문 선언 -> 외부 선언 변수 접근 O
