### 제어 흐름 종류
- 한 문장 내 -> [[연산자 우선순위]] & associativity
- 문장(statement) 간 -> 문장 수준 제어 구조
- unit 간 -> procedure 호출
- [[명령형 언어]]의 computation : 오른쪽 계산 -> 왼쪽 저장

### 종류
- [[조건문]] : [[if]] / [[switch]]
- [[반복문]] : [[for]] / [[while]]
- [[GOTO]] : 무조건 분기
- [[Guarded Commands]] : non-deterministic 선택
- Single-Entry & Single-Exit 지향

### [[Compound Statement]]
- 여러 statement 묶은 것
- [[Block]] : 묶기 + [[변수]] 선언
