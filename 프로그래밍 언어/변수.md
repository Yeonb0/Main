- 컴퓨터 memory cell 의 [[추상화]]
- [[명령형 언어]] 의 기본 단위
- 실제 세계 & [[데이터 타입]] 의 match 정도가 언어 설계의 관건

### 속성
- Name : [[변수]]를 식별하는 [[이름]] (identifier)
- Address : 변수가 위치한 memory 주소
	- 전역 변수 vs. 지역 변수 이름 동일 -> 지역 변수 우선
		- scoping rule : 내가 속한 지역에서 먼저 변수명 [[Searching|탐색]] -> 없으면 지역 밖 탐색
	- aliase : 한 memory cell 에 이름 여러 개 -> debugging 어려움
		- ==ex)== pointer
	- 결정 시점 -> [[저장소 바인딩]]
- Type : 값의 범위 & 사용 가능 연산자 정의
	- Assembly 언어는 type X
	- 결정 시점 -> [[타입 바인딩]]
- Value : memory cell 에 들어 있는 값
- [[Lifetime]] / [[Scope]]

### l-value & r-value
```c
a = a + 1;
```
- 왼쪽 a -> l-value (left, location) : 변수의 memory 주소
- 오른쪽 a -> r-value (right, real) : 변수에 저장된 실제 값

### 초기화
- 대부분의 언어 : [[저장소 바인딩]] + value 바인딩 동시 수행
	- 수행 도중 value 변경 O
- run time 중 값 고정 -> [[Named Constant]]
