- 어떤 타입 값 -> 다른 타입 값으로 바꾸기
- 여러 [[데이터 타입]] 동시 표현 언어 -> 변환 규칙 필요
- 컴퓨터는 서로 다른 타입 피연산자 계산 X -> 변환 후 [[연산]]

### 종류
| 구분           | 수행 주체      | 시점            |
| ------------ | ---------- | ------------- |
| [[coercion]] | compiler   | 암묵적(implicit) |
| [[캐스팅]]      | programmer | 명시적(explicit) |

### 형태
- Narrowing conversion : 원래 타입 모든 값 포함 X
	- ==ex)== `float` -> `int`
- Widening conversion : 원래 타입 모든 값 적어도 근사적으로 포함 O
	- ==ex)== `int` -> `float`
	- 항상 안전, but 일부 정밀도 손실 가능

### [[C]]의 강제 변환
- 숫자 [[데이터 타입]] : `int | short | long` / `float | double`
- `short` -> `int`, `float` -> `double` 강제 변환
- [[타입 검사]] X -> 표현식 실행 중 오류 발생 가능
