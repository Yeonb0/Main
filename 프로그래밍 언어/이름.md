- 프로그램에서 entity 식별 위해 사용하는 [[String|문자열]]
- [[변수]] · [[함수]] · [[상수]] 등의 식별자 (identifier)
- 이름 짓기 -> 중요하면서도 어려운 작업

### 형태
- 이름 길이
	- 초창기 언어 : 글자 수 제한 O
	- 최근 언어 : 글자 수 제한 X
- 대소문자 구별
	- ==ex)== C, C++ 구별 O

### 특수 단어
- Keyword : 특정 context 에서만 의미 가지는 단어
- Reserved word (예약어) : 항상 의미 가지는 단어 -> 이름으로 사용 X
	- ==ex)== `if`, `while`, `return`, `class`
