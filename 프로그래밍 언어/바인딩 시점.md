- [[바인딩]] 이 일어나는 때

### 절차
1. Language design time : 언어 설계 시
	- ==ex)== `*` 를 곱하기 연산자로 정하기
2. Language implementation time : 언어에 대한 [[컴파일|compiler]] 제작 시
	- [[데이터 타입]] (int, float) 이 가능한 값의 범위 (word size) 에 바인딩
	- integer 는 항상 word size 로 저장
3. Compile time
	- [[변수]]의 type 결정 (a 는 int, b 는 float)
	- in C -> [[타입 바인딩]] 시점
4. Link time
	- main & subroutine 존재 시 main - sub 바인딩 시점
5. Load time
	- 실행 위해 변수가 memory 에 올라오는 시점
		- 이때 변수는 local X / global O
		- 빈 memory 에 올라감
	- global 변수 attribute 바인딩 시점
6. Run time
	- 실행 중 변수의 value 바인딩 시점
	- local 변수 attribute 바인딩 시점

### 언어별 비교
| 속성 | C | [[Python]] |
| --- | --- | --- |
| Name | compile time | run time |
| Type | compile time | run time |
| Address | load time (전역 변수) / run time (지역 변수) | run time |
| Value | load time (전역 변수) / run time (지역 변수) | run time |
| Lifetime | run time | run time |
