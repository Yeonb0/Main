- [[산술 표현식]] 안 연산자들 적용 차례
- 우선순위 다른 인접 연산자 -> 우선순위 높은 쪽 먼저
	- ==ex)== `A + B * C`
- unary operator ==(항등 연산자)== : 피연산자 하나, 다른 피연산자 영향 X
	- ==ex)== `+A`, `A + (-B) * C`
- 대부분 언어에서 우선순위 규칙 동일

### 우선순위 ==(high <- -> low)==
| 언어 | 순서 |
| --- | --- |
| FORTRAN | `**` -> `*, /` -> `all +, -` |
| Pascal | `*, /, div, mod` -> `all +, -` |
| ANSI [[C]] | `++, --, unary +, -` -> `*, /, %` -> `binary +, -` |

### 우선순위 변경
- 같은 우선순위 인접 -> [[결합 규칙]] 따라 결정
- 괄호 -> 우선순위 & [[결합 규칙]] 덮어쓰기 O
