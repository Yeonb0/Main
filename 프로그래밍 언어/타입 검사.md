- operator 와 operand 들이 서로 호환 가능한 타입인지 확인
- 호환 불가능 -> compiler 가 error 알림
- 일부 compiler 는 자동 형 변환 ([[coercion]]) 통해 호환 가능하게 만듦

### 조건
- 모든 [[변수]]가 static [[타입 바인딩]] -> type error 항상 발견 가능 -> [[Strong Typing]]
- [[Dynamic Scope]] -> 타입 검사 어려움
