1. [[Readability|Readability(가독성)]] : 얼마나 쉽게 읽고 이해할 수 있는가?
2. [[Writability|Writability(작성 용이성)]] : 얼마나 쉽게 표현할 수 있는가?
3. [[Reliability|Reliability(신뢰성)]] : 신뢰도 있는 프로그램인가?
4. Cost (비용)
	- 프로그래머 교육 비용, 프로그램 작성 비용, [[컴파일]] 비용, 실행 비용, 유지보수 비용
5. Portability : 얼마나 많은 플랫폼에 컴파일러 존재?
6. Generality : 얼마나 많은 기능, 분야 커버 가능?
	- 기능 과다 -> [[컴파일]] 시간↑
7. Well-definedness : 언어 문서화 얼마나 잘 되어 있음?
