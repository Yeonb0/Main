- memory 소진 시점에 사용 불가 cell 을 한꺼번에 회수하는 [[Heap Management]] 방식
- 일괄 회수 ==(batch reclamation)==
- 모든 heap cell 에 garbage 여부 표시하는 indicator bit ==(마크 비트)== 보유

### 절차
1. heap 의 모든 cell 을 garbage 로 표시
2. 프로그램의 모든 [[Pointer]] 추적 -> 접근 가능한 cell 은 garbage X 표시
3. 남은 garbage 를 사용 가능 공간 리스트로 변환

### 단점
- memory 꽉 찬 시점에 수행 -> 가장 필요할 때 가장 느린 동작
- 마크 비트 저장 공간 overhead
- 모든 pointer 추적 시간 overhead

### 가변 크기 추가 문제
- heap 의 모든 cell 을 garbage 로 초기 설정 어려움
- pointer 없는 cell 존재 -> 마킹 과정 누락
- 회수 후 단편화 ==(fragmentation)== -> 사용 가능 공간 흩어짐
