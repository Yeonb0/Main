- [[프로그래밍 언어]]를 공부해야 하는 근거

### 이유
- 표현 능력 확장 -> 어휘력(기능) 多 -> idea 표현 폭↑
- 특정 기능 위한 언어 파악 -> 분야에 맞는 언어 선택 가능
	- ==ex)== FORTRAN : 과학 계산용 언어
		- 계산 주체가 user 냐 compiler 냐 차이
- 새로운 언어 습득 용이
- 구현 방식 이해 -> 언어의 효율적 사용
	- ==ex)== 대부분 언어 subprogram([[함수]]) 기능 有 -> [[매개 변수]] 이동 overhead 파악 -> 효율적 코드 작성
- 컴퓨팅 전체의 발전
