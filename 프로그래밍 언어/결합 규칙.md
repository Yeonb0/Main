- 같은 우선순위 연산자 인접 -> 어느 쪽부터 평가할지 정하는 언어 규칙
- 대부분 좌결합, 거듭제곱 `**` 는 우결합

### 언어별
| 언어 | 좌결합 | 우결합 |
| --- | --- | --- |
| FORTRAN | `*, /, +, -` | `**` |
| Pascal | 전부 | 없음 |
| ANSI [[C]] | `*, /, %, binary +, binary -` | `++, --, unary +, unary -` |
| APL | 없음 | 전부 ==(우선순위 X, 오른쪽 -> 왼쪽)== |

### 재배열
- [[연산자 평가 순서]] 재배열 -> 속도↑ 가능
- 정수 [[연산]] overflow -> 결합 법칙 깨질 수 있음 -> 재배열 위험
