- [[Subprogram]] 이 [[데이터]]에 접근하는 방법 중 하나
- parameterized computation -> subprogram 의 [[연산]] 내용을 parameter 가 결정
- 데이터 아닌 연산 전달 O -> subprogram [[이름]]을 parameter 로 사용

### 종류
| 구분 | 내용 |
| --- | --- |
| Formal parameter | subprogram header 에 있는 parameter |
| Actual parameter | 호출 시 전달 목록, formal parameter 에 [[바인딩]] |

### 전달 방식
- Positional parameter : actual - formal 바인딩을 위치로 결정
- Keyword parameter : 연결될 formal parameter 이름 명시
	- ==ex)== Ada `SUMER (LENGTH => MY_LENGTH, LIST => MY_LIST, SUM => MY_SUM);`
	- 사용자가 formal parameter 이름 알아야 함
- Default value : actual parameter 미전달 시 기본값 사용

### 전달 모드
![[Subprogram-01.png]]
1. in mode : actual parameter -> formal parameter
2. out mode : actual parameter <- formal parameter
3. inout mode : actual parameter <-> formal parameter
- 데이터 이동 방법 -> 실제 값 물리적 이동 (actual data transfer) / 접근 경로(pointer) 이동

### 전달 방법
- [[Pass-by-Value]]
- [[Pass-by-Result]]
- [[Pass-by-Value-Result]]
- [[Pass-by-Reference]]
- [[Pass-by-Name]]

### 언어별 방식
| 언어 | 방식 |
| --- | --- |
| [[C]] | [[Pass-by-Value]], pointer 사용 시 [[Pass-by-Reference]] |
| C++ | reference type 제공 -> [[Pass-by-Reference]] |
| [[Java]] | [[Pass-by-Value]], 객체는 [[Pass-by-Reference]] |
| [[Python]] | [[Pass-by-Assignment]], Call-by-[[객체\|Object]] |

- [[Python]] : 모든 데이터가 객체
```c
def spam(eggs):
    eggs.append(1)
    eggs = [2, 3]

ham = [0]
spam(ham)
print(ham)
```
	- 객체 내부 수정 -> caller 반영 (call-by-reference)
	- 객체 새로 할당 -> caller 에 영향 X (call-by-value)
- Call-by-Object
	- 불변 (정수, [[String|문자열]], 튜플) 인자 -> call-by-value, 수정 X 새로운 객체 가리킴
	- 가변 (list, dict, set) 인자 -> call-by-reference, ==단 new list 할당 시는 영향 X==
- [[Python]] arguments

| 기능 | 방법 | 특징 |
| --- | --- | --- |
| [[Command\|커맨드]] 라인 인자 | `sys.argv` | 리스트 형태로 저장 |
| 가변 길이 인자 | `*변수명` | 튜플 형태로 묶임 |

### 타입 검사
- actual - formal parameter 타입 검사 필요하다는 것이 통설 -> [[타입 검사]]

| 언어 | 검사 |
| --- | --- |
| [[C]] | parameter 개수 · 타입 검사 X |
| ANSI C | C 방식 -> 검사 X / prototype 방식 -> 검사 O & [[coercion\|강제 변환]] |
| C++ | 타입 지정 parameter & ellipsis(`…`) 사용 O |
| Perl, [[JavaScript]], PHP | 검사 X |
| [[Python]], Ruby | 객체가 타입 보유 -> 검사 불가능 |

### 구현 방식
