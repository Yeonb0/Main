- [[변수]]의 address 가 결정되는 [[바인딩]]

### 종류
1. Static variable
	- global 변수
	- 프로그램 시작 전 미리 할당 (load time)
2. [[stack|Stack]] dynamic variable
	- procedure 안에 만들어진 local 변수
	- type 할당 -> compile time
	- [[함수]] 호출 시 (run time) address 할당
	- recursion 위해 자주 사용
	- 같은 stack 공간 [[재사용(Reuse)|재사용]] O
	- 호출마다 stack 에 쌓이는 [[Activation Record]] 안에 할당
3. explicit [[Heap]] Dynamic Variable
	- `malloc` 과 같은 함수로 ==프로그래머==가 직접 할당하는 변수
	- 프로그래머가 `free` 할 때까지 사용 -> stack 아닌 heap 에 저장
	- pointer 변수 통해 참조
4. implicit Heap Dynamic Variable
	- ==프로그램==에 의해 자동으로 값이 assign 될 때만 address 할당
	- 자동적 할당 -> PHP, [[JavaScript]]
	- 그때 그 type 에 맞게 memory 할당
