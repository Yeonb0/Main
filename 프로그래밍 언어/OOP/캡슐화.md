- [[데이터]] & [[함수]] 하나로 묶은 것
- [[객체]]의 데이터를 외부에서 직접 접근하지 못하도록 보호
- 필요한 경우 [[메소드]]를 통해 접근하도록 함

- 내부 구현은 숨기고, 필요한 기능만 외부에 공개

```java
public class Main {
    public static void main(String[] args) {

        Cookie cookie = new Cookie("용감한 쿠키");

				System.out.println(cookie.Hp); //ERROR
        System.out.println(cookie.getHp());

        cookie.setHp(150);
        cookie.Hp=200; //ERROR

    }
}
```

### 장점
- 데이터 보호
- 유지 보수 용이
- [[객체]]의 [[무결성]] 유지
- 재사용성↑, 외부 모듈 변경 파급 효과↓
- 인터페이스 단순화, [[객체]]간 [[결합도]]↓
