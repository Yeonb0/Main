- 기존 정의된 [[클래스]]를 재사용해 새로운 클래스를 정의하는 것
- 부모 [[클래스]] (상위 클래스) : 상속의 대상이 되는 클래스
- 자식 [[클래스]] (하위 클래스) : 상속을 하는 클래스
	- 부모의 [[필드]] & [[메소드]]를 물려 받음

```java
A extends B
```
- A 가 B 를 상속한다 
	- A : 부모 클래스
	- B : 자식 클래스

### 특징
1. 자식 [[클래스]]는 하나의 부모 [[클래스]] 만 상속 할 수 있다
	- 한 부모는 여러 자식 -> 가능
2. 부모 [[클래스]]에서 [[접근제어자]]가 `private` 인 [[필드]]와 [[메소드]]는 직접 사용할 수 없다.
3. `final` [[클래스]]는 [[상속]]할 수 없다
   `final` [[메소드]]는 재정의 할 수 없다
4. [[상속]] 관계에 있는 두 대상은 IS-A 관계 (~는 ...이다) 를 가져야 한다
```java
class 학생 extends 사람 {..}
class 전기자동차 extends 자동차 {..}
class 사과 extends 과일 {...}

//학생은 사람이다.
//전기자동차는 자동차이다.
//사과는 과일이다.
```

### 장점
- 다형적 표현 가능 (다양한 형태로 객체 사용 가능)
	- 확장성, 유지 보수성
- 코드의 중복성 제거
