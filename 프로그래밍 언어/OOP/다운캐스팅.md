- 부모 [[클래스]]로 만든 [[객체]]를 자식 클래스 타입으로 강제 [[coercion|형 변환]]
- 부모 타입 -> 자식 타입
- 명시적 타입 변환 필수
- [[업캐스팅]] 된 자식 클래스 복구 -> 자식 클래스의 [[필드]]와 [[메소드]] 회복
```java
Person p = new Actor();  // 업캐스팅
Actor a;
a = (Actor) p;     // 다운캐스팅
a.introduce();           // "I am an actor."
```
