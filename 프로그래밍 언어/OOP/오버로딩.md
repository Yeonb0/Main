- 한 [[클래스]] 내에서 하나의 [[메소드]]나 [[생성자]]에 대해서 여러 개 정의 하는것

### 조건
- [[메소드]] [[이름]]이 같아야 한다
- [[매개 변수]]의 개수 또는 [[자료형]]이 달라야 한다
- [[매개 변수]]는 같고 `return` 타입 다름 -> [[오버로딩]] X

### [[메소드]] 오버로딩
- 한 [[클래스]] 내에 같은 이름의 메소드를 여러 개 정의
```java
class MyPrint {
	void printData() { …… }
	void printData(int a) { …… }
	void printData(char b) { …… }
	void printData(int a, char b) { …… }
	void printData(int a, int b, int c) { …… }
	void printData(float a, int b) { …… }
	……
}
```

```java
class Calculator {
    int add(int a, int b) {
        return a + b;
    }
    double add(int a, int b) {
        return a + b;
    }
 }
```
-> 오버로딩 X ([[매개 변수]] 같음)

### [[생성자]] 오버로딩
- 한 [[클래스]] 내에 여러 [[생성자]] 선언 
```java
public class Student{
	Student(){..}
	Student(String name){..}
	Student(String name, int age){..}
	Student(int age, String name){..}
}
```
- `@Builder` 사용시 간편

### 연산자 오버로딩
- 한 operator 를 여러 방식으로 사용
- [[Readability]] & [[Reliability]] 해치지 않는 선에서 허용
- ==ex)== `+`, `-`, `*`, `/` -> `int` & `float` 공통 사용
- ==ex)== [[C]]의 `&` -> bit AND / 주소 참조
- user-defined overloaded operator : 사용자가 직접 operator overload O
	- [[매개 변수|parameter]] 개수 & 타입 변화 O
	- return 타입 변화 O

### [[Subprogram]] 오버로딩
- 동일 [[Referencing Environments|참조 환경]] 내에서 다른 subprogram 과 같은 이름 보유
- overloading 된 procedure 끼리 parameter type & return 값 유일해야 함
- 호출 시 actual parameter 목록 따라 결정
- C++ : 각 [[함수]]의 parameter 개수 또는 type 유일 -> overloading O
```cpp
void fun(float b = 0.0) {
    …
}
void fun() {
    …
}
main() {
    …
    fun() ; /* ?? */
    …
}
```
