### 정보처리기사
- 문제 전체적, 포괄적 개념 설계 -> 차례로 세분화 해 구체화
- 최소 비용으로 실제 상황 대처, 시스템 구조 · 구성 대략적 파악 가능

| 종류                    | 설명                                      |
| --------------------- | --------------------------------------- |
| 과정([[추상 메소드]]) 추상화    | 자세한 수행 과정 정의 X, 전반적 흐름만 파악              |
| 데이터 ([[추상 클래스]]) 추상화  | 데이터 세부적 속성 · 용도 정의 X, 데이터 구조 대표 표현으로 대체 |
| 제어 추상화                | 이벤트 발생 절차 · 방법 정의 X, 대표 표현으로 대체         |
