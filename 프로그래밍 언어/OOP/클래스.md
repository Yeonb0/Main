- [[객체]]를 [[소프트웨어]] 내에서 생성하기 위한 설계도
- 공통된 [[데이터]] · [[함수]] 가지는 [[객체]]의 집합. 객체의 일반적 타입
- 각 객체의 [[필드]] & [[메소드]] 정의 틀
- 데이터 [[추상화]] 단위

### 용어들
- [[인스턴스|인스턴스(Instance)]] : [[클래스]] 안의 각 [[객체]]
- [[인스턴스화|인스턴스화(Instantiation)]] : 클래스에서 새로운 객체 생성
- 최상위 클래스 : 상위 클래스가 없는 클래스
- 슈퍼 클래스(Super Class), 부모 클래스 : 특정 클래스의 상위 클래스
- 서브 클래스(Sub Class), 자식 클래스 : 특정 클래스의 하위 클래스 

### [[Python]] 클래스
- 개발자가 정의하는 자료형
```python
class 클래스_이름:
	def __init__(self, 인수, ...):   # 생성자
		...
	def 메소드1(self, 인수, ...): 
		...
	def 메소드2(self, 인수, ...): 
		...
```
- ==ex)==
```python
class Man:
	def __init__(self, name):
		self.name = name
		print("Initilized!")
	
	def hello(self):
		print("Hello " + self.name + "!")
	
	def goodbye(self):
		print("Good-bye " + self.name + "!")
	
m = Man("David")
m.hello()
m.goodbye()
```
