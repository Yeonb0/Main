- 하나의 [[객체]]가 여러 형태를 가질 수 있는 설정
- 한 개의 [[참조변수]]에 여러가지 [[객체]]를 대입해 사용 방법 변경 않고도 다양한 실행 결과 얻을 수 있음

### [[오버라이딩|오버라이딩(Overriding)]]

### [[오버로딩|오버로딩(Overloading)]]

### 참조 변수
- [[업캐스팅]] : 부모 [[클래스]]의 [[참조변수]] 하나로 여러 자식 클래스 [[객체]] 참조 가능
	- 자식 타입 참조 변수로 부모 객체 참조는 불가능
	- 부모 클래스의 멤버에만 접근 가능
- [[다운캐스팅]] : [[업캐스팅]] 된 자식 클래스 복구
- `instanceof` : 매개 값의 타입 조사. 
	- 타입 일치 -> `true` / 타입 불일치 -> `false`
```java
Parent p= new Actor();

if(p instanceof Child){ 
		Actor a=(Actor) p;
}
```

```java
public class Main {
    public static void main(String[] args) {
    
        Person p1 = new Person();
        p1 = new Actor();
        
        Person p2 =  new Student();
        
        Person p3 = new Professor();
    }
}
```
```java
class Person {
    void introduce() {
        System.out.println("I am a person.");
    }
}

class Actor extends Person {
		@Override
    void introduce() {
        System.out.println("I am an actor.");
    }
}

class Student extends Person {
    @Override
    void introduce() {
        System.out.println("I am a student.");
    }
}

class Professor extends Person {
    @Override
    void introduce() {
        System.out.println("I am a professor.");
    }
}
```
```java
public class Main {
    public static void main(String[] args) {
        // Person 타입 배열
        Person[] people = new Person[4];

        // 서로 다른 자식 클래스 객체들을 배열에 저장
        people[0] = new Person();
        people[1] = new Actor();
        people[2] = new Student();
        people[3] = new Professor();

        
        for (Person p : people) {
            p.introduce();  // 각 객체의 오버라이딩된 introduce() 실행
        }
    }
}
```

> [!note]- 실행 결과
> I am a person.
> I am an actor.
> I am a student.
> I am a professor.
