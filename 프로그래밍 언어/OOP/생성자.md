- [[객체]]가 생성될 때 자동으로 호출되는 특수 목적 [[메소드]].
- [[객체]]의 [[초기화]] 위해 사용
### 키워드
- `this` : 자기 자신을 지칭하는 키워드
- `super` : 부모를 지칭하는 키워드
```java
class Parent{
    int x =10;
}

class Child extends Parent{
    int x=20;
    void test(){
        System.out.println("x: "+x); 
        System.out.println("this.x: "+this.x); 
        System.out.println("super.x: "+super.x); 
    }
}

public class Example {
    public static void main(String[] args) {
        Child c = new Child();
        c.test();
    }

}
```

- `this()` : 자신이 속한 클래스에서 다른 [[생성자]] 호출
	- 생성자 내부에서만 사용 가능
	- 생성자의 첫 줄에 위치해야 함
```java
public class Test {
    public static void main(String[] args) {
        Example example = new Example(5);
    }
}

class Example  {
    // 생성자1
    public Example() {
        System.out.println("기본 생성자 호출");
    };
    
    // 생성자2
    public Example(int x) {
        this();
        System.out.println("두 번째 생성자 호출");
    }
}
```
- `super()` : 부모 생성자를 호출하는 키워드
	- 자식 클래스의 기본 생성자에 항상 `super()` 포함
	- 자식 생성자 제일 첫줄에 적어야 함
### 특징
- [[생성자]]의 이름 = [[클래스]]의 이름
- 특별한 [[메소드|Method]] -> `return` 값 없음
- [[매개 변수]] 조건 따라 여러 개 작성 가능 ([[오버로딩]])
- [[클래스]]에 생성자 코드가 없을 경우 [[컴파일러]]가 자동으로 기본 생성자 만듬

```java
class Student{
    int no;
    String name;
    int score;

    Student(){} //기본 생성자 
    Student(int n, String nm){
        no = n;
        name=nm;
    }
    Student(int n, String nm, int s){
        no = n;
        name=nm;
        score=s;
    }

...
}
```

### [[어노테이션]]
- [[Builder|빌더(Builder)]] 패턴 사용
```java
@Builder
public class People {
    private String name;
    private int age;
    private String address;
    private String phoneNumber;
    private String email;
    private double height;
    private double weight;
}
```

```java
public class Main {
    public static void main(String[] args) {

        People person = People.builder()
            .name("김지오")
            .age(30)
            .address("서울시 마포구 대흥동")
            .phoneNumber("010-1234-5678")
            .email("jj@example.com")
            .height(190.2)
            .weight(75.5)
            .build();
            
            
         People person1 = People.builder()
            .name("홍길동")
            .age(30)
            .weight(75.5)
            .build();
    }
}
```
-> 생성될 때 어떤 값이 어떤 [[필드]]에 들어갔는지 쉽게 알 수 있음 
-> [[클래스]]에서 [[필드]]의 추가, 삭제, 수정이 있어도 [[생성자]] 추가 수정 필요 X
