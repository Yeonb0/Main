- 서로 다른 두 개의 시스템 사이에서 정보나 신호를 주고받는 경우의 접점
![[Pasted image 20260707094829.png]]
- [[추상 클래스]]의 특별한 형태
	- [[추상 메소드]]의 집합 + [[객체]] 간의 통신 규약

### 형태
```java
interface 인터페이스 이름{
	public static final 타입 상수명=값;
	public abstract 메소드 프로토타입;
}
```

### 특징
1. [[인터페이스]]의 [[접근제어자]]는 `public` 또는 `default`
2. [[인터페이스]]안의 [[필드]]는 변수가 아닌 상수 (`public static final`)로만 정의 가능
3. [[인터페이스]]에 선언된 [[메소드]]는 `public abstract method`
- [[메소드]]와 [[상수]] 앞의 `public abstract method`, `public static final` 은 생략 가능

### 사용
```java
public class Child implements ParentInterface{
.......
}
```
- [[클래스]] 선언 부에 `implements` 키워드 추가
```java
interface Parent{
	int data1=100; //interface 내의 멤버변수는 반드시 초기화되어야 한다.
	void show(); //interface 내의 메소드는 자동으로 추상 메소드이므로 body부분을 가질 수 없다. 
}

class Child implements Parent {
	int data2;
	Child(){}
	Child(int d2){
		data2=d2;
	}
	@Override
	public void show(){
		System.out.println(data1+","+data2);
	}
}
```
- [[메소드]] [[오버라이딩]] 할 때 반드시 `public` 키워드 붙여야 함
