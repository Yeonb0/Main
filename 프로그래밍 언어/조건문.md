- 두 개 이상 실행 경로 중 하나 선택하는 [[제어문]]
- single-entry & single-exit 유지

### 종류
| 종류 | 내용 |
| --- | --- |
| Single-Way Selector | 조건 참 -> 문장 실행, 거짓 -> 건너뜀 |
| Two-Way Selector | 두 경로 중 하나 선택 |
| Multiple Selection | 여러 문장 · 문장 그룹 중 선택 |

- [[if]] : Single-Way · Two-Way
- [[switch]] : Multiple Selection
