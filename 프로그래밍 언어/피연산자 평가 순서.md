- [[산술 표현식]] 안 피연산자들 계산 차례
- 피연산자가 [[사이드 이펙트]] 가짐 -> 순서 따라 결과 상이 -> 순서 중요
- 순수 값 피연산자만 -> 순서 무관

### [[사이드 이펙트]]
- [[함수]]가 [[매개 변수]] 또는 전역 [[변수]] 변경 -> 발생
- 피연산자가 함수 호출 -> 같은 식이 다른 값

### 처리 방법
- 함수적 side effect 허용 X
- 언어 정의에서 평가 순서 고정

- ==ex)== 피연산자가 함수 호출인 경우
```pascal
procedure sub1(....) ;
  var a : integer
  function fun(x:integer) : integer ;
  ....
    a := 27 ;
    return(5);
  end

procedure sub2(....) ;
  ....
    a := 10 ;
    b := a + fun(b) ;  ← 피연산자가 함수 호출인 경우
    print(b) ;
  end
end
```
