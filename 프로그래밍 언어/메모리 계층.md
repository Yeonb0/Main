- register / memory / disk 순의 저장 장치 계층
- speed ↔ cost trade-off

### 구성
- cache : 자주 참조하는 것을 가까이 [[배치 처리|배치]]
- buffer : 장치 간 속도 차이 완충

### 계층 구조
![[Cache-Memory-08.png]]

- L0 (Register) / L1 ~ L3 ([[캐시 메모리]]) / L4 ([[메모리|Main Memory]]) / L5 · L6 (disk · remote storage)
- [[CPU]] -> L0 -> L1 -> L2 -> … -> L6 순으로 보유 여부 조회
- 위쪽 : 빠름 & 공간 ↓ & 비쌈
- 아래쪽 : 공간 ↑ & 느림 & 쌈

### 특징
- 빠른 저장공간 -> 비쌈 & 크기 ↓
- 크기 큰 저장공간 -> 쌈 & 느림
- L0 · L4 -> program code ([[어셈블리 코드|assembly]]) 로 control O
- L1 ~ L3 -> program code 가 존재 여부 인지 X
