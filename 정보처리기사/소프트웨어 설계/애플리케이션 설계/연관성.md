- 두 개 이상 [[객체]]가 상호 [[참조]]하는 관계

| 종류                   | 표현             | 설명                  |
| -------------------- | -------------- | ------------------- |
| 연관화 (Association)    | is member of   | 2개 이상 객체 상호 관련      |
| 분류화 (Classfication)  | is instance of | 동일형 특성 객체 모아 구성     |
| 집단화 (Aggregation)    | is part of     | 관련 객체 모아 하나의 상위 객체  |
| 일반화 (Generalization) | is a           | 공통된 성질 추상화 상위 객체 구성 |
| 상세화 (Specialization) | is a           | 상위 객체 구체화 해 하위 객체   |
