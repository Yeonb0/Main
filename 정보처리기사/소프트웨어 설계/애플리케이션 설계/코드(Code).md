- 분류, 조합, 집계, 추출 쉽게 하기위해 사용하는 기호
	- ==ex)== 주민등록번호, 학번, 전화번호

### 기능
- 식별 : 데이터 간 성격 따라 구분 가능
- 분류 : 특정 기능 · 동일 유형 해당 데이터 그룹화 기능
- [[배열]] : 의미 부여해 나열 가능
- 표준화 : 다양한 데이터를 기준 맞춰 표현 가능
- 간소화 : 복잡한 데이터 간소화 가능

### 종류
| 이름                                 | 종류                                                                         |
| ---------------------------------- | -------------------------------------------------------------------------- |
| 순차 코드  <br>Sequence Code           | 최초 자료부터 일련 번호 부여  <br>==ex)== 1, 2, 3, 4 …                                 |
| 블록 코드  <br>Block Code              | 공통성 있는 것끼리 블록. 블록 내 일련 번호 부여  <br>==ex)== 1001 ~ 1100 : A, 1101 ~ 1200 : B |
| 10진 코드  <br>Decimal Code           | 0~9까지 10진 분할, 각각에 대해 또 10진 분할  <br>==ex)== 도서 분류 코드                        |
| 그룹 분류 코드  <br>Group Classification | 대, 중, 소분류 구분. 각 그룹 내 일련번호 부여  <br>==ex)== 1-01-001 / 2-01-001              |
| 연상 코드  <br>Mnemonic Code           | 명칭 · 약호와 관계 있는 문자, 숫자, 기호 사용  <br>==ex)== TV-40, L-15-220                  |
| 표의 숫자 코드  <br>Significant Digit    | 물리적 수치를 코드에 적용. 유효 숫자 코드  <br>==ex)== 120-720-1500                         |
| 합성 코드  <br>Combined Code           | 2개 이상 코드 조합  <br>==ex)== 연상 + 숫자 → KE - 711                                |
