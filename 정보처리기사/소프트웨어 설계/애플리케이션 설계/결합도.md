- [[모듈]] 간 상호 의존 정도 / 두 모듈 사이 연관 관계
- 낮을 수록 좋음

### 종류
1. 자료 결합도 (Data Coupling)
	- [[데이터]]만 주고 받음
	- 내용 변경해도 영향 X
2. 스탬프 결합도 (Stamp Coupling)
	- [[배열]] · [[레코드]] 등 [[Data Structure|자료구조]] 전달
	- 자료구조에 변화 -> 양쪽 영향
3. 제어 결합도 (Control Coupling)
	- 제어 신호 통신 or 제어 요소 전달
	- 한 [[모듈]] -> 다른 [[모듈]] 통제 시 사용
	- 권리 전도 현상 발생 (하위 -> 상위)
4. 외부 결합도 (External Coupling)
	- 데이터를 외부 모듈에서 [[참조]]
	- 참조 범위 제한 가능
5. 공통 결합도 (Common Coupling)
	- 공유하는 공통 데이터 영역을 여러 모듈이 함께 사용
	- 모듈 독립성↓
6. 내용 결합도 (Content Coupling)
	- 내부 기능 · 자료를 직접 [[참조]] · 수정
	- 제어 이동 시에도 내용 결합
