- 미들 (Middle) + [[소프트웨어]] (Software)
- 분산 컴퓨팅 환경에서 원만한 통신 이뤄지도록 서비스 제공
- [[운영체제]] - [[애플리케이션]] 사이에서 애플리케이션 사용 시 기본 기능 제공
- 표준화 [[인터페이스]] -> 일관성 보장
- 위치 투명성 제공
	- 시스템 논리적 명칭으로만 엑세스 가능
- 미들웨어 내부 동작은 별도 소프트웨어 사용

### 형태
- 1 : 1
- 1 : N
- N : M

### 종류
- [[데이터베이스|DB(Database)]] 
	- 데이터 베이스 벤더 제공, 원격 DB 와 연결 위한 미들웨어
	- 2-Tier 아키텍쳐
	- ==ex)== [[ODBC]], [[IDAPI]], [[Glue]]

- [[RPC|RPC(Remote Procedure Call)]]
	- 원격 [[프로시저]] 호출
	- 응용 프로그램 프로시저 사용 -> 원격을 로컬 프로시저처럼 호출하는 미들웨어
	- ==ex)== [[Entrea]], [[ONC]], [[RPC]]

- [[MOM|Message Oriented Middleware]]
	- [[메세지]] 지향 미들웨어
	- 서로 다른 플랫폼에서 독립적으로 실행되는 [[소프트웨어]]
	  -> 하나의 통합된 시스템처럼 동작
	- 메세지 기반 [[비동기]]형 메세지 전달
	- ==ex)== [[MQ]], [[Message Q]], [[JMS]]

- [[TP-Monitor|TP-Monitor(Transaction Processing Monitor)]]
	- [[트랜젝션]] 처리 모니터
	- 온라인 트랜젝션 업무 처리 · 감시 미들웨어
	- 사용자↑ 응답 속도↑ 업무
	- ==ex)== [[tuxedo]], [[tmax]]

- [[ORB|ORB(Object Request Broker)]]
	- [[객체]] 요청 브로커
	- [[객체 지향]] 미들웨어
	- [[CORBA]] 표준 스펙 구현
	- [[트랜젝션]] 처리 + 모니터링 추가 구현
	- ==ex)== [[Orbix]], [[CORBA]]

- [[웹 애플리케이션 서버|WAS(Web Application Server)]]
	- 웹 애플리케이션 서버
	- 동적 컨텐츠, 웹 환경 구현
	- [[HTTP]] 세션 처리
	- 미션 - 크리티컬 기업 업무
	- ==ex)== [[WebLogic]], [[WebSphere]]
