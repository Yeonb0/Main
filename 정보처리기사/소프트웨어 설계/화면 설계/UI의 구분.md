| 종류                             | 설명                     |
| ------------------------------ | ---------------------- |
| CLI (Command Line Interface)   | 명령 · 출력이 텍스트로          |
| GUI (Graphical User Interface) | 아이콘 · 메뉴 마우스 선택해 작업 수행 |
| NUI (Natural User Interface)   | 사용자 말 · 행동으로 기기 조작     |
| VUI (Voice User Interface)     | 사람 음성으로 기기 조작          |
| OUI (Organic User Interface)   | 모든 사물-사용자 간 상호작용       |
