- [[소프트웨어]] 품질 특성과 평가 위한 표준 지침
	-> 2011 년에 ==ISO/IEC 25010== 으로 개정

### 기능성 (Functionality)
- 사용자 [[요구사항]] 정확히 만족?

| 종류                        | 설명                           |
| ------------------------- | ---------------------------- |
| 적절성 / 적합성 (Suitability)   | 지정 작업 · 사용자 목적 달성에 적절한 기능 제공 |
| 정확성 / 정밀성 (Accuracy)      | 요구 결과 정확하게 산출                |
| 상호 운용성 (Interoperability) | 다른 시스템과 서로 어울려 작업            |
| 보안성 (Security)            | 정보 접근 권한 따라 허용 / 차단          |
| 준수성 (Compliance)          | 기능 관련 표준, 관례, 규정 준수          |
### 신뢰성 (Reliability)
- 요구된 기능 정확 · 일관되게 오류 없이 수행하는 정도

| 종류                       | 설명                        |
| ------------------------ | ------------------------- |
| 성숙성 (Maturity)           | 결함으로 인한 고장 회피력            |
| 고장 허용성 (Fault Tolerance) | 결함 or 결여 시에도 규정 성능 수준 유지력 |
| 회복성 (Recoverability)     | 고장 시 규정 성능까지 회복 · 복구력     |
### 사용성 (Usability)
- 사용자가 쉽게 학습 · 사용 가능?
- 재사용 원하는 정도

| 종류                      | 설명                       |
| ----------------------- | ------------------------ |
| 이해성 (Understandability) | 소프트웨어 적합성, 사용 방법 사용자 이해력 |
| 학습성 (Learnability)      | 소프트웨어 애플리케이션 학습력         |
| 운용성 (Operability)       | 사용자 소프트웨어 운용 · 제어력       |
| 친밀성 (Attractivenes))    | 사용자 소프트웨어 재사용 원하는 정도     |
### 효율성 (Efficiency)
- 사용자 요구 기능 할당 시간 동안 한정 자원으로 얼마나 빨리 처리 가능?

| 종류                          | 설명                   |
| --------------------------- | -------------------- |
| 시간 효율성 (Time Behaviour)     | 적절 반응 시간, 처리 시간, 처리율 |
| 자원 효율성 (Resource Behaviour) | 적절 자원 양 · 종류 제공      |
### 유지 보수성 (Maintainability)
- 환경 변화 or new 요구사항 시 [[소프트웨어]] 개선 · 확장?

| 종류                  | 설명                      |
| ------------------- | ----------------------- |
| 분석성 (Analyzability) | 결함, 고장 원인, 수정할 부분 식별력   |
| 변경성 (Changeability) | 결함 제거, 환경 변화로 인한 수정 구현력 |
| 안정성 (Stability)     | 변경 인한 예상치 못한 결과 최소화     |
| 시험성 (Testability)   | 소프트웨어 변경 검증력            |
### 이식성 (Portability)
- 다른 환경 적용력

| 종류                   | 설명                        |
| -------------------- | ------------------------- |
| 적용성 (Adaptability)   | 원래 목적 이외 다른 환경 변경 가능성     |
| 설치성 (Installability) | 임의 환경에 소프트웨어 설치 가능성       |
| 대체성 (Replaceability) | 동일 환경, 동일 목적 다른 소프트웨어 대체력 |
| 공존성 (Co-existence)   | 자원 공유 환경에서 다른 소프트웨어와 공존력  |

## 기타 품질 표준
- ISO / IEC 12119 :[[ ISO & IEC 9126]] + [[테스트]] 절차
- ISO / IEC 14598 : 소프트웨어 품질 측정 · 평가
- ISO / IEC 25000 : 9126 + 14598. 품질 평가 위한 모델
