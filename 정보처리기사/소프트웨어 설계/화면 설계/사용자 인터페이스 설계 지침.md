- 사용자 중심 : 사용자 쉽게 이용 · 편리 사용 환경. 실사용자 이해 바탕
- 사용성 : 사용자가 얼마나 쉽게 · 편리 · 효율적 사용? → **최우선 고려**
- 일관성 : 버튼, 조작법 일관성 있게 제공
- 단순성 : 조작 방법 단순화 → 인지적 부담 ↓
- 결과 예측 가능 : 기능 보고 결과 예측 가능해야 함
- 가시성 : 메인 화면에 주요 기능 노출 → 조작 쉽게 설계
- 심미성 : 디자인 좋게, 가독성 높이기
- 표준화 : 기능 구조 · 디자인 표준화
- 접근성 : 남녀노소 다양 계층 사용하도록
- 명확성 : 사용자가 개념적으로 쉽게 인지하도록
- 오류 발생 해결 : 오류 발생하면 사용자 쉽게 인지
