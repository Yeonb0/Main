- [[사물(Things)]]들 사이의 연관성 표현

### 종류
- 연관 (Association) 관계 : 2개 이상 사물이 서로 관련되어 있음
	- 실선으로 표현. 방향성 있을 시 -> <- 와 같이 화살표로 표현
	- 다중도 (연관 참여 객체 갯수) : 선 위에 표기

| 1        | 1개 연관        |
| -------- | ------------ |
| n        | n개 연관        |
| 0..1     | 없거나 1개만 존재   |
| 0..* / * | 없거나 다수일 수 있음 |
| 1..*     | 적어도 1개 이상    |
| n..*     | 적어도 n개 이상    |
| n..m     | n개 이상 m개 이하  |
![[Pasted image 20260706171154.png]]

- 집합 (Aggregation) 관계 : 한 사물이 다른 사물에 포함
	- 전체 ⊃ 부분 : 단, 전체 & 부분은 독립적
![[Pasted image 20260706171427.png]]

- 포함 (Composition) 관계 : 집합의 특수 형태
	- 전체의 변화가 부분에 영향 줌
	- 전체 ⊃ 부분 : 부분은 전체에 의존. [[생명 주기]] 같음
![[Pasted image 20260706171535.png]]

- 일반화 (Generalization) 관계 
	- 일반적 (부모) - 구체적 (자식)
![[Pasted image 20260706171631.png]]

- 의존 (Dependency) 관계 : 짧은 시간 동안만 연관 유지 관계
	- 소유하는 관계 X, 영향 O
	- 한 [[클래스]]가 다른 [[클래스]]를 [[변수]]로 사용
![[Pasted image 20260706171727.png]]

- 실체화 (Realization) 관계 : [[오퍼레이션]], [[인터페이스]]로 그룹화 할 수 있는 관계
![[Pasted image 20260706171809.png]]
