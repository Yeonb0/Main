- 동적 모델링


| 종류                                             | 설명                                                              |
| ---------------------------------------------- | --------------------------------------------------------------- |
| **[[유스케이스 다이어그램]]**  <br>Use Case Diagram      | 사용자 요구 분석. 기능 모델링 작업에 사용  <br>사용자 & 사용 사례로 구성. 사용 사례 간 여러 형태 관계 |
| **순차 다이어그램**  <br>Sequence Diagram             | 상호작용 시스템 or 객체가 주고 받는 메세지                                       |
| **커뮤니케이션 다이어그램**  <br>Communication Diagram    | 객체가 주고 받는 메세지 + 객체들 간의 연관                                       |
| **상태 다이어그램**  <br>State Diagram                | 한 객체의 상태가 어떻게 변화하는지?  <br>이벤트에 의한 객체 상태 변화. 동적 모델링에 활용          |
| **활동 다이어그램**  <br>Interaction Overview Diagram | 상호 작용 다이어그램 간 제어 흐름 표현                                          |
| **타이밍 다이어그램**  <br>Timing Diagram              | 객체 상태 변화 · 시간 제약 명시적 표현                                         |
