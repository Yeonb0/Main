- 정적 모델링


| 종류                                        | 설명                                                              |
| ----------------------------------------- | --------------------------------------------------------------- |
| **[[클래스 다이어그램]]**  <br>Class Diagram      | 클래스, 속성, 관계 표현  <br>시스템 구조 파악 · 문제점 도출 可                        |
| **[[객체]] 다이어그램**  <br>Object Diagram      | 클래스의 인스턴스를 객체-객체 관계로 표현  <br>[[럼바우(Rumbaugh) 방법]] 객체 지향 분석 기법에서 활용 |
| **[[컴포너트]] 다이어그램**  <br>Component Diagram | 컴포넌트 간 관계, 인터페이스 표현  <br>구현 단계에서 사용                             |
| **배치 다이어그램**  <br>Deployment Diagram      | 요소들 위치 표현. 노드와 통신 경로로 표현  <br>구현 단계에서 사용                        |
| **복합체 구조 다이어그램**  <br>Composite Diagram   | 클래스 or 컴포넌트가 복합 구조면 내부 구조 표현                                    |
| **[[패키지]] 다이어그램**  <br>Package Diagram    | 유스케이스 · 클래스 등 모델 요소 그룹화 패키지 관계 표현                               |
