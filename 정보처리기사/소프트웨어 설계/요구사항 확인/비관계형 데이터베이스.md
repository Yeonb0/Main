- 비구조화 [[데이터]] 관리
- 설계 비용↓, 동작 빠름
- 복잡한 기능 제공 X, 데이터 정합성 완벽 보장 X
- 상황 & 목적 따라 잘 나눠 사용해야 함!

### 종류
- [[키-밸류형 데이터베이스|키-밸류형]] (Key-value 형, KVS)
	- 데이터 형식 제약 X
	- 각 데이터에 대해 어떤 키가 되는 값 연결해 저장
- [[문서형 데이터베이스|문서형]]
	- 데이터를 [[JSON]] 같은 문서 형태로 저장 가능한 [[데이터베이스|DB]].
	- ==ex)== [[MongoDB]]
- [[그래프형 데이터베이스|그래프형]]
	- 여러 요소간 관계 & 처리 흐름 표현 -> [[Graph|그래프]] 형식으로 표현
	- 관계 분석 용이
	- ==ex)== [[Neo4j]]
- [[시계열 데이터베이스|시계열형]]
	- 시간 흐름 따라 값 변화 기록 DB
	- [[IoT]] 현장에서 많이 사용
