- 데이터베이스 관리 시스템 $_{\text{DBMS, DataBase Management System}}$
	- [[데이터베이스]] 관리
	- 사용자 - [[데이터베이스|DB]] 사이에서 정보 생성 & 관리
	- [[Oracle]], [[IBM DB2]], [[MySQL]], [[SQLite]], [[MongoDB]], [[Redis]]

- 고려 사항 : 가용성, 성능, 기술 지원, 상호 호환성, 구축 비용

### 종류
- 계층형 (Hierarchical)
- 망형 (Network)
- 관계형 (Relational)
- 비관계형 (NoSQL)

### 기능
1. 정의 (Definition) : 데이터 형, 구조, 이용법, 제약 정의
2. 조작 (Manipulation) : 데이터 검색, 갱신, 삽입, 삭제 처리
3. 제어 (Control)
	- 접근 정확하게 수행 -> 데이터 무결성 유지
	- 보안 유지, 권한 검사
	- [[병행 제어|병행 제어(Concurrency Control)]]
