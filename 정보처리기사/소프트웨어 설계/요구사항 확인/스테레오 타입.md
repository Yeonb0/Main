- [[UML]] 기본 기능 외 추가 기능 표현
- 길라멧 (Guillemet) `<< >>` 사이에 기술

| 종류                | 설명                   |
| ----------------- | -------------------- |
| `<<include>>`     | 연결된 다른 UML 요소에 포함 관계 |
| `<<extend>>`      | 연결된 다른 UML 요소에 확장 관계 |
| `<<interface>>`   | 인터페이스 정의             |
| `<<exception>>`   | 예외 정의                |
| `<<constructor>>` | 생성자 역할 수행            |
