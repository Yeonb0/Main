- 웹 애플리케이션 서버 $_{\text{WAS, Web Application Server}}$
- 동적 컨텐츠 처리 위한 [[미들웨어]]
- [[Tomcat]], [[Glassfish]], [[JBoss]], [[Jetty]], [[Resin]], [[WebLogic]], [[WebSphere]]

- 고려 사항 : 가용성, 성능, 기술 지원, 구출 비용

- [[웹 시스템]] 의 [[UI|사용자 인터페이스]] 이용 -> [[데이터베이스|DB]] 관리 [[데이터]] 처리
- [[웹 서버]] 요청 -> 프로그램으로 처리
- [[3계층 클라이언트 서버 시스템]] 의 응용 계층 담당

### 구현
- [[PHP]] : 오픈 소스 스크립트 언어
	- [[HTML]] 파일에 프로그램 삽입 형태로 코드 작성
	- [[웹 서버]] [[모듈]]로 작동 -> 웹 서버 애플리케이션과 조합
- [[Tomcat|톰캣(Tomcat)]] : [[Java|자바]] 로 애플리케이션 [[서버]] 구축
	- [[자바 서블릿]] : 애플리케이션 서버에서 동작, [[클라이언트]] 요청 따라 서블릿 컨테이너 이용해 프로그램 실행
	- [[JSP]] : [[HTML]] 안에 자바 코드 삽입 -> 동적 웹 페이지 생성
- Nginx Unit : [[PHP]] · [[Python|파이썬]] · [[Java|자바]] · Node.js 등 다수 언어 지원
