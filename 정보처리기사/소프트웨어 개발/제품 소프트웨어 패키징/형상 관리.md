- [[소프트웨어]] 변경 사항 관리
- 관리 항목 : 소스 코드, 프로젝트 계획, 분석서, 설계서, 프로그램, [[테스트 케이스]]
- 개발 all 단계 + 유지 보수
- 전체 비용↓, 방해 요인 최소화
- 가시성, 추적성 보장 -> 생산성, 품질성↑
- ==ex)== [[Git]], [[CVS]], [[Subversion]]

### 기능
- 형상 식별 : 관리 대상 이름 · 번호 부여 -> 계층 구조로 구분
- 버전 제어 : 업그레이드, [[유지보수]] 버전 관리
- 형상 통제 (변경 관리) : 현재 기준선 (Base line) 반영 조정
- 형상 감사 : 무결성 평가. 확인, 검증, 검열 과정
- 형상 기록 (상태 보고) : 결과 기록 · 관리, 보고서 작성

### 주요 용어
- 저장소 ([[Repository]]) : 최신 파일, 변경 내역 저장소
- 가져오기 (Import) : 빈 저장소에 첫 파일 복사
- 체크아웃 (Check-Out) : 저장소에서 파일 받아오기
- 체크인 (Check-In) : 저장소 파일 new 버전으로 갱신
- 커밋 ([[Commit]]) : 이전 갱신 -> 충돌 알리고 diff 도구 이용 갱신 완료
- 동기화 (Update) : 최신 버전으로 동기화

### 과정
1. 가져오기 (Import)
2. 인출 (Check-Out)
3. 예치 ([[Commit]])
4. 동기화 (Update)
5. 차이 (Diff)
