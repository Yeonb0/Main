- 테스트 결과 판단 위해 사전 정의된 참 값 대입 · 비교

### 특징
- 제한된 검증 : 모든 [[테스트 케이스]] 적용 X
- 수학적 기법 : 수학적 기법으로 참 값 도출 O
- 자동화 기능 : 실행, 결과 비교, [[커버리지]] 측정 자동화 O

### 종류
| 종류 | 내용 |
| --- | --- |
| 참 (True) | 모든 테스트 케이스 기대 결과 제공 |
| 샘플링 ([[Sampling]]) | 특정 테스트 케이스 값만 제공 |
| 추정 (Heuristic) | 특정 테스트 케이스 값만 제공 + 나머지 추정 처리 |
| 일관성 (Consistency) 검사 | [[애플리케이션 테스트\|애플리케이션]] 변경 -> 테스트 케이스 수행 전 · 후 결과 비교 |
