- 상위 모듈의 [[테스트 케이스]] 사용 어려움

### 단계
1. 주요 제어 모듈 -> 작성 프로그램 사용
   종속 모듈 -> [[스텁]]으로 대체
2. 통합 방식 따라 스텁 -> 실제 모듈 교체
3. 모듈 통합 마다 테스트 실시
4. [[회귀 테스트]] 실시 -> new 오류 발생 X 보증
