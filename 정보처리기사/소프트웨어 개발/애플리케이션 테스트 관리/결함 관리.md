### 상태 추적

| --- | --- |
| 결함 분포 | 특정 속성 해당 결함 수 측정 |
| 결함 추세 | 결함 수 추이 분석 |
| 결함 에이징 | 결함 지속 시간 측정 |

### 추적 절차
1. 결함 등록 (Open) : QA 의해 결함 등록
2. 결함 검토 (Reviewed) : 테스터, QA, 개발자 검토
3. 결함 할당 (Assigned) : 개발자 담당 배정
4. 결함 수정 (Resolved) : 개발자 수정 완료
5. 결함 조치 보류 (Deffered) : 수정 불가능해 연기
6. 결함 종료 (Closed) : 결함 해결해 종료 승인
7. 결함 해제 (Clarified) : 결함 X 판정
