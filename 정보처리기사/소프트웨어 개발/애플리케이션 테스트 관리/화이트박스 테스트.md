- [[모듈]] 원시 코드 오픈 상태 -> 논리적 모든 경로 테스트하는 [[테스트 케이스]] 설계
- 모듈 안 작동 직접 관찰. 논리적 경로 제어

### 종류
- 기초 경로 검사 (Base Path Testing) 
	- 대표적 화이트박스 테스트 기법
	- 절차적 설계 논리적 복잡성 측정
- 제어 구조 검사 (Control Structure)
	- 조건 검사 (Condition Testing)
	- 루프 검사 (Loop Testing)
	- 데이터 흐름 검사 (Data Flow Testing)

### 검증 기준
1. 문장 검증 기준 (Statement Coverage)
	- 코드의 모든 구문 한 번 이상 수행되도록 설계
2. 분기 검증 기준 (Branch Coverage)
   = 결정 검증 기준 (Decision Coverage)
	- 모든 조건문 True / False 인 경우 한 번 이상 수행되도록 설계
3. 조건 검증 기준 (Condition Coverage)
	- 조건문 포함 개별 조건식 True / False 인 경우 한 번 이상 수행 설계
4. 분기 / 조건 기준 (Branch / Condition Coverage)
	- 2 + 3 [[테스트 케이스]] 설계
