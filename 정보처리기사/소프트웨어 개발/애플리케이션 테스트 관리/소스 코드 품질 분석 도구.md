- 소스 코드 [[결함]] · 품질 검증 도구

### 정적 분석 도구
- 코드 실행 X 분석 -> [[정적 테스트]]
- 초기 결함 찾기, 개발 소스 코드 품질 검증
- 코딩 [[복잡도]], 모델 [[의존성]], 불일치성 분석
- ==ex)== pmd, cppcheck, SonarQube, checkstyle, ccm, cobertura

### 동적 분석 도구
- 코드 실행 -> [[동적 테스트]]
- [[메모리]] 누수, 스레드 결함 분석
- ==ex)== Avalanche, Valgrind
