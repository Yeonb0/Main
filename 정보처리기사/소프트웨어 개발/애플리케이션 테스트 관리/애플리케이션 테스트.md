### 기본 원리
- 완벽한 소프트웨어 테스팅 불가능
- 결합 집중 : 결합은 특정 모듈에 집중되어 있다.
- [[파레토 법칙]] : 애플리케이션 20%의 코드에서 전체 80% 결함 발견
- [[살충제 패러독스]] : 동일 [[테스트 케이스]]로 반복 시 결함 발견 불가능
  -> 테스트 케이스 보완 · 개선 필요
- 오류 - 부재의 궤변 : 결함이 없더라도 [[요구 사항|요구사항]] 불만족 시 품질 높은게 아님
- 테스트 - 위험 반비례
- 테스트 작은거 -> 큰거로 점점 확대. 개발자 관계 없는 별도 팀에서 실행.
