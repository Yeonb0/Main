- 기능 테스트, 각 기능 완전 작동 입증 테스트
- 구조 고려 X, 요구 · 명세 기초
- [[소프트웨어]] [[인터페이스]]에서 실시, 테스트 과정 후반부

### 종류
1. 동치 분할 검사 (Equivalence Partitioning Testing)
	- 동치 클래스 분해, 동등 분할 기법
	- 입력 자료 초점 맞춰 [[테스트 케이스]] 만들고 검사
	- 타당 O / 타당 X 입력 [[테스트 케이스]] -> 결과 검사
2. 경계값 분석 (Boundary Value Analysis)
	- 동치 분할 기법 보완
	- 입력 조건 경계값을 [[테스트 케이스]]로 선정해 검사
3. 원인 - 효과 그래프 검사 (Cause-Effect Graphing Test)
	- 입·출력 상황 체계적 분석 후 효용성 높은 [[테스트 케이스]] 선정해 검사
4. 오류 예측 검사 (Error Guessing)
	- 과거 경험 · 확인자 감각으로 테스트
	- 보충적 검사 기법. 데이터 확인 검사
5. 비교 검사 (Comparision Testing)
	- 여러 버전 동일 테스트 -> 동일 결과?
