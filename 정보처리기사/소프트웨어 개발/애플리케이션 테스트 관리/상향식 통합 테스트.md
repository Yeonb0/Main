- 하위 [[모듈]] -> 상위 모듈 순서 [[통합 테스트]]
- [[스텁]] 필요 X
- [[클러스터]] (Cluster) : 주요 모듈 관련 종속 모듈 그룹

### 단계
1. 하위 모듈 클러스터로 결합
2. 더미 모듈 [[드라이버]] 작성 -> 상위 모듈 [[데이터]] 입 · 출력 확인
3. 통합된 클러스터 단위로 테스트
4. 테스트 완료 -> 클러스터 상위 이동 후 결합, 드라이버 실제 모듈로 대체
