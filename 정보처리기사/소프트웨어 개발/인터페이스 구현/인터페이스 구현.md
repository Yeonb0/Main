- 송 · 수신 시스템 간 [[데이터]] 교환 · 처리 실현 작업
- [[인터페이스 데이터 표준]] 기반 수행

### 종류
1. 데이터 통신 이용 [[인터페이스]] 구현
	- App 에서 형식 맞춘 데이터 포멧 전송 -> 수신 측에서 파싱해 해석
	- [[JSON]], [[XML]] 형식 사용
2. 인터페이스 엔티티 이용 인터페이스 구현
	- 인터페이스 필요 시스템 사이 별도 [[인터페이스 엔티티]] 두어 상호 연계

### 관련
- 구현 구간 취약점 제거 -> [[인터페이스 보안]]
- 구현 결과 확인 -> [[인터페이스 구현 검증 도구]]
