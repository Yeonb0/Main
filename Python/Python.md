### [[Python]] 생성자
- `__init__` : [[클래스]] 초기화 방법 정의
- [[메소드]]의 첫 번째 인수 -> 자신의 [[인스턴스]] 나타내는 `self` 명시적으로 작성 필수
```python
class Man:
	def __init__(self, name):
		self.name = name
		print("Initilized!")
```
