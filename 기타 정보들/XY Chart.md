- 막대(bar)와 꺾은선(line) 그리는 ==수치 [[데이터]] 차트==
- 선언 키워드 `xychart-beta`, 아직 beta 문법

### 형태
- 축 정의
	- `x-axis [항목1, 항목2, ...]` 또는 `x-axis "라벨" 최소 --> 최대`
	- `y-axis "라벨" 최소 --> 최대`
- 데이터 : `bar [값, 값, ...]` / `line [값, 값, ...]`
	- 두 줄 함께 사용 -> 하나의 차트에 겹쳐 렌더링

### 조건
- 값 개수와 x축 항목 개수 ==반드시 일치==

### 예시
```mermaid
xychart-beta
    title "월별 평균 API 응답 시간"
    x-axis [1월, 2월, 3월, 4월, 5월, 6월]
    y-axis "응답 시간 (ms)" 0 --> 400
    bar [320, 305, 285, 250, 210, 180]
    line [320, 305, 285, 250, 210, 180]
```

### 활용
- 성능 최적화 전후 지표 변화 PR 첨부
- 벤치마크 결과(정렬 알고리즘별 실행 시간 등) 학습 노트 기록
- 주간 · 월간 트래픽 추이 문서 공유
