- 사용자가 서비스 이용하며 겪는 단계와 ==각 단계의 만족도== 함께 표현
- 선언 키워드 `journey`

### 형태
- `작업명: 점수: 행위자1, 행위자2`
	- 점수 ==1~5==, 낮을수록 불만족 -> 낮은 구간이 개선 포인트
	- 행위자는 콤마로 여러 명 지정 O
- `section` 으로 여정의 큰 단계 구분

### 예시
```mermaid
journey
    title 신규 사용자 온보딩 여정

    section 가입
      랜딩 페이지 방문: 5: 방문자
      회원가입 폼 작성: 3: 방문자
      이메일 인증 대기: 2: 방문자

    section 첫 사용
      튜토리얼 진행: 4: 사용자
      첫 프로젝트 생성: 5: 사용자

    section 정착
      팀원 초대: 3: 사용자, 팀장
      결제 플랜 선택: 2: 팀장
```

### 활용
- [[UX]] 개선 과제에서 이탈 발생 지점 팀 공유
- 기획 문서에 사용자 시나리오 정량 첨부
- 기존 플로우와 개선 플로우의 만족도 변화 비교
