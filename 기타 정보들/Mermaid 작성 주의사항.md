- 문법 · 렌더러 차이로 자주 겪는 파싱 실패 지점

### 조건
- 특수문자 : [[뉴런|노드]] 라벨에 `()`, `[]`, `{}`, `-`, `:` 포함 -> 파싱 깨짐, 큰따옴표로 감싸기
	- ==ex)== `A["함수 foo(): void"]`
	- 그래도 실패 시 HTML 엔티티 사용 (`#quot;`, `#35;`)
- 줄바꿈 : 라벨 안에서 `\n` X -> `<br/>` 사용
- 예약어 [[Collision|충돌]] : `end`, `graph`, `o`, `x` 를 노드 ID 로 사용 -> [[Error|오류]], 대문자 또는 다른 ID
- 레이아웃 제어 불가 : 노드 위치 직접 지정 X -> 한 다이어그램당 ==노드 10~15개 이내== 분할 권장
- [[마크다운]] 표 안의 `|` : [[ER Diagram]] 카디널리티 기호처럼 `|` 포함 -> 표 구분자와 충돌, `\|` 로 이스케이프
- 렌더러 버전 차이 : GitHub · Obsidian · Notion 각각 다른 [[Mermaid]] 버전 -> beta 문법은 환경마다 동작 상이
