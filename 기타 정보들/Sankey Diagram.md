- 흐름의 ==양(volume)== 을 선 굵기로 표현하는 [[다이어그램]]
- 선언 키워드 `sankey-beta`, beta 문법
- 단계별 이탈량 한눈에 파악 -> 최대 강점

### 형태
- [[데이터]]는 ==CSV 형식== : `출발노드,도착노드,값` 한 줄에 하나씩
- 선언 줄 바로 다음에 ==빈 줄 필요==
- 값에 콤마 · 공백 포함 시 큰따옴표로 감싸기

### 예시
```mermaid
sankey-beta

방문자,회원가입,3200
방문자,이탈,6800
회원가입,첫 결제,900
회원가입,미결제,2300
첫 결제,재구매,400
첫 결제,단발성,500
```

### 활용
- [[퍼널 분석]] 에서 단계별 전환율 · 이탈량 시각화
- 예산 · 리소스 배분처 표시
- [[컴퓨터 네트워크|네트워크]] 트래픽의 서비스 간 흐름 설명
