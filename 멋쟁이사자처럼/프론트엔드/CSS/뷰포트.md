- 웹 브라우저에서 실제로 화면에 표시되는 영역

## 종류
- `vw` = viewport [[width]]
- `vh` = viewport [[height]]

cf) [[font]] size 또한 vw, vh 로 설정 가능

- `svh` : short viewport [[height]] (주소창/툴바가 '보이는 상태' 기준 높이)
- `lvh` : long viewport [[height]] (주소창/툴바가 '보이지 않는 상태' 기준 높이)
- `dvh` : dynamic viewport [[height]] (short/ long 이 현재 상태 따라 자동으로 변함)
