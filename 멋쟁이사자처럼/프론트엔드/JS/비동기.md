- 코드가 동시에 수행되는 것
- 특정 작업이 끝날 때까지 기다리지 않고, 다른 작업을 병렬적으로 수행
	- 프로그램 흐름이 멈추거나 지연되는 현상 방지

![[Pasted image 20260703103653.png]]

```js
console.log("첫 번째 작업");

setTimeout(() => {
    console.log("두 번째 작업 (비동기)");
}, 2000);

console.log("세 번째 작업");

// 실행 결과
// 첫 번째 작업
// 세 번째 작업
// 두 번째 작업 (비동기)
```

> [!note]- `setTimeout()`
> 일정 시간이 지난 후에 특정 함수를 실행하도록 예약하는 [[함수]]
> - `setTimeout(func, delay, ...args)`
> 	- `func` : 지연 시간 후 실행할 함수
> 	- `delay` : 지연 시간
> 	- `...args` : 실행할 함수에 전달될 인수 (선택)
