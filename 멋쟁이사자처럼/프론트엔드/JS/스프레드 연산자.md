- [[배열]]이나 [[객체]]를 개별 요소로 분리하는데 사용하는 분법
- 요소를 하나씩 펼쳐서 복사 or 병합 할때 사용
- `...배열이름` / `...객체이름` 
- 스프레드 연산자 이후 추가로 같은 배열 / 객체의 요소 나열 불가능
- 원본 데이터 변경 X 새로운 복사본 생성

### 배열 
```js
const a = [1, 2];
const b = [3, 4];

const merged = [...a, ...b];

console.log(merged); // [1, 2, 3, 4]
```
- 원본과는 다른 새로운 [[배열]]

```js
const colors = ["빨강", "초록"];

const moreColors = [...colors, "파랑", "노랑"];

console.log(moreColors); 
// ["빨강", "초록", "파랑", "노랑"]
```

### 객체
```js
const original = { name: "Alice", age: 30 };

// 객체를 복사하고 새 속성 추가
const copied = { ...original, city: "Seoul" };

console.log(copied);
// { name: "Alice", age: 30, city: "Seoul" }
```
- 원본과는 독립된 별개의 [[객체]]

#### 객체 프로퍼티 수정
```js
const person = { name: "민수", age: 25 };

// 스프레드를 이용한 프로퍼티 수정
const updatedPerson = { ...person, age: 26 };

console.log(updatedPerson);
// { name: "민수", age: 26 }
```
- [[프로퍼티]]가 이미 존재하면 덮어쓰기
```js
const obj1 = { a: 1, b: 2 };
const obj2 = { b: 3, c: 4 };

// 같은 프로퍼티가 있으면, 뒤에 있는 객체의 값이 덮어씁니다.
const combined = { ...obj1, ...obj2 };

console.log(combined);
// { a: 1, b: 3, c: 4 }
```
- 병합하는 두 객체에 같은 프로퍼티 -> 뒤에 있는 값으로 덮어씀
