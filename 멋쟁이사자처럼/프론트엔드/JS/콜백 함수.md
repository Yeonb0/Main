- 다른 [[함수]]의 [[매개 변수]]로 전달되는 함수
- [[콜백 함수]]를 [[매개 변수]]로 갖는 함수에 의해 호출

```js
function hello(x) {
	x();
}

function niceToMeetU() {
	console.log("Nice to meet you");
}

hello(niceToMeetU); //콜백함수 niceToMeetU
```

> [!note]- 왜 [[매개 변수]]로 `niceToMeetU()` 가 아니라 `niceToMeetU` 를 전달하는가?
> 만약 `()`를 붙인다면, `miceToMeetU$` 함수다 바로 호출이 되어버림. 
> -> 함수를 전달하는 것이 아니라 `return` 값을 전달하게 된다.

> [!note]- 더 간단하게 쓰기 
> 화살표 함수를 사용하면 더 간단하게 만들 수 있다!
> ```js
> hello(() => {
> 	console.log("Nice to meet you");
> })
> ```
