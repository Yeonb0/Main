aliases:
  - Destructing Assignment
---
- 배열, 객체 같은 자료구조의 값을 꺼내서 개별적인 변수에 할당시키는 문법
- 필요한 값만 간단히 추출해서 사용

## 배열
```js
const numbers = [10, 20, 30, 40];

// 일반적인 방법
const a = numbers[0];
const b = numbers[1];
const c = numbers[2];
const d = numbers[3];

// 구조 분해 할당
const [x, y, z, w] = numbers;
// x, y, z, w를 각각 a, b, c, d와 똑같이 사용 가능~!
// 더 간결해짐!
```

### 배열의 일부분만 추출하기
```js
const colors = ["빨강", "초록", "파랑"];
const [, second, third] = colors;

console.log(second); // "초록"
console.log(third);  // "파랑"
```

- `third` 도 제외하고 싶을 때
```js
const [, second] = colors;
```

### 기본값 설정
```js
const [first, second, third = "파랑"] = colors;

console.log(first); // "빨강"
console.log(second); // "초록"
console.log(third); // 기본값인 "파랑"
```

## 객체
```js
const person = { name: "Yena", age: 22 };

// 일반적인 방법
const name = person.name;
const age = person.age;

// 구조 분해 할당
const { name, age } = person;

```

- 주의 : 상수에 재할당 문제 발생 가능
```js
const person1 = { name: "Yena", age: 22 };
const person2 = { name: "James", age: 28 };

// 일반적인 방법
const name = person1.name;
const age = person1.age;

// 구조 분해 할당
const { name, age } = person1;
const { name, age } = person2:
// ❌ 상수에 값의 재할당이 발생함
```

### [[프로퍼티]] 이름과 다른 이름으로 변수 할당 가능
```js
const person1 = { name: "Yena", age: 22 };
const person2 = { name: "James", age: 28 };

// 구조 분해 할당
const { name: user1Name, age: user1Age } = person1;
const { name: user2Name, age: user2Age } = person2;

console.log(user1Name); // Yena
console.log(user1Age);  // 22
```

### 기본값 설정
```js
const person = { name: "Yena" };

// age는 존재하지 않음 → 기본값 22 사용
const { name, age = 22 } = person;

console.log(name); // Yena
console.log(age);  // 22 (기본값)
```

### 중첩된 객체 내부의 값 추출하기
```js
const student = {
  name: "Yena",
  address: {
    city: "서울",
    zip: 12345,
  },
};

// 중첩된 객체에서 city만 추출
const {
  address: { city },
} = student;

console.log(city); // 서울
```
