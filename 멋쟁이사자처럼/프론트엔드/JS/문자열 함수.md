### `includes(searchString, position)`
- `searchString` : 검색할 문자열
- `position` : 검색을 시작할 위치 (index) -> 생략 가능
- `return` : [[boolean]] 값 (true / false)

```js
const text = "Hello, JavaScript!";

console.log(text.includes("Java")); // true
console.log(text.includes("java")); // false (대소문자 구별됨)
```

### `split(separator, limits)`
- `separator` : 문자열 나누는 기준 
- `limits` : 몇 개까지만 자를지 정하기 (생략 가능)

```js
const str = "a,b,c,d";

str.split(",");
// ["a", "b", "c", "d"]

str.split(",", 2);
// ["a", "b"]
// 2개까지만 잘라서 반환
```

### `substring(start, end)`
- `start` ~ `end-1` 까지 잘라서 **새로운 문자열** 반환 -> 원본 변경 X
- `end` 생략 시 `start`부터 끝까지 반환
```js
const text = "Hello, World!";

const result = text.substring(0, 5); // 0부터 5미만까지 추출

console.log(result); // "Hello"

```

### `replace(pattern, replacement)`
- `pattern` : 찾을 문자열
- `replacement` : 대체할 문자열
- [[문자열]]에서 특정 문자열을 찾아 다른 문자열로 바꾼 **새로운 문자열** 반환 -> 원본 변경 X
- 첫 번째로 발견된 문자만 변경
```js
const text = "hello world";

const replaced = text.replace("hello", "Hi"); // 'hello'를 'Hi'로 변경

console.log(replaced); // "Hi world"
```

### `toUppercase()` / `toLowercase()`
- [[매개 변수]] X
- [[문자열]]의 모든 문자를 대문자 / 소문자로 변환한 **새로운 문자열** 반환 -> 원본 변경 X
```js
const text = "Hello World";

console.log(text.toUpperCase()); // "HELLO WORLD"
console.log(text.toLowerCase()); // "hello world"
```
