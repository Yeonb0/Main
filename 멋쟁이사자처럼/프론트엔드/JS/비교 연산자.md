- 두 값의 동등 여부 or 대소 관계 비교해 [[boolean]] 값 반환
- 논리 흐름 제어하는 것에 사용

| 비교 연산자 | 설명 (의미)        | 예시          | 결과      |
| ------ | -------------- | ----------- | ------- |
| `==`   | **동등**(느슨한 동등) | `5 == "5"`  | `true`  |
| `===`  | **동등**(엄격한 동등) | `5 === "5"` | `false` |
| `!=`   | **부등**(느슨한 부등) | `5 != "5"`  | `false` |
| `!==`  | **부등**(엄격한 부등) | `5 !== "5"` | `true`  |
| `>`    | **보다 큼**       | `7 > 3`     | `true`  |
| `<`    | **보다 작음**      | `7 < 3`     | `false` |
| `>=`   | **크거나 같음**     | `5 >= 5`    | `true`  |
| `<=`   | **작거나 같음**     | `4 <= 2`    | `false` |
- 느슨한 동등 `==` / 부등 `≠` : **값** 자체만 비교. 비교 전 필요 시 [[coercion]] 함
	- 타입이 달라도 값이 같으면 `true`
- 엄격한 동등 `===` / 부등 `!==` : **값** + **타입** 모두 비교. 암묵적 변환 X 타입 다르면 바로 `false`
