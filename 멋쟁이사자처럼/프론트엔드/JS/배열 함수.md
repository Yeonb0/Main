### `forEach(func)`
- 각 [[배열]] 요소에 대해 제공된 함수 한 번씩 실행
- `return` : X

```js
const arr = [1, 2, 3];
arr.forEach((num) => {
	console.log(num * 2);
});

// 출력 : 2, 4, 6
```

### `map(func)`
- 각 [[배열]] 요소에 대해 제공된 함수 한 번씩 실행해 **새로운 배열** 로 반환
- `return` : array

```js
const nums = [1, 2, 3];
const doubled = nums.map((num) => num*2);

console.log(doubled); // [2, 4, 6]
```

### `filter(func)`
- [[함수]]의 조건에 만족하는 요소만 모아서 **새로운 배열** 로 반환
- `return` : array

```js
const nums = [1, 2, 3, 4, 5];
const evenNums = nums.filter((num) => num % 2 === 0);

console.log(evenNums); // [2, 4];
```
### `find(func)`
- [[배열]]에서 특정 요소를 찾을 때 사용
- `return` : 찾은 값 (value) / 찾는데 실패하면 `undefined`
```js
const users = [{ id: 1 }, { id: 2 }, { id: 3 }];
const user = users.find((user) => user.id === 2);

console.log(user); // { id: 2 }
```

### `findIndex(func)`
- [[배열]]에서 특정 조건을 만족하는 요소의 인덱스를 찾을 때 사용
- `return` : 찾은 값의 인덱스 (index) / 찾는데 실패하면 `-1`
```js
const nums = [10, 20, 30];
const idx = nums.findIndex((num) => num === 20);

console.log(idx); // 1
```

### `includes(func)`
- [[배열]]에 요소가 있는지 여부 판단
- `return`: boolean 값 (true / false)
```js
const fruits = ["사과", "배"];
console.log(fruits.includes("배")); // true
console.log(fruits.includes("복숭아")); // false
```
### `push(element)` / `pop()`
- `push(element)` : 배열의 끝에 요소 추가
- `pop()` : 배열의 마지막 원소 제거 & `return`

```js
const arr = [1, 2];
arr.push(3); // [1, 2, 3]

const last = arr.pop();

console.log(arr); // [1, 2] 
console.log(last); // 3
```

### `reduce(func)`
- [[배열]]의 요소들을 누적해 하나의 값으로 만듬
- `return` : number
```js
const nums = [1, 2, 3, 4]l
const sum = nums.reduce((acc, curr) => acc + curr, 0);

console.log(sum); // 10
```
- acc (accumulator) : 누적 합
- curr (currentValue) : 현재 값
- 0 (initialValue) : 누적 값의 시작 값 (생략 가능)

### `slice(start, end)`
- `start` : 시작 인덱스
- `end` : 끝 인덱스 (생략 가능)
- [[배열]]의 일부 복사 -> 원본은 유지
```js
const arr = [1, 2, 3, 4];
const sliced = arr.slice(1, 3);

console.log(sliced); // [2, 3]
console.log(arr); // 원본 유지됨 [1,2,3,4]
```

### `splice(start, deleteCount, item1, item2, ...)`
- `start` : 변경을 시작할 인덱스
- `deleteCount` : 삭제할 요소의 개수 (선택)
- `item1, item2, ...` : 삭제한 위치에 새로 추가할 요소들 (선택)
- [[배열]] 요소를 추가 / 삭제 / 번경 -> **원본**을 수정

- `deleteCount` 생략 시 -> `start` 부터 모두 제거
- `deleteCount` = 0 일시 -> 삭제 X 추가만

```js
const arr = [1, 2, 3, 4, 5];

arr.splice(1, 2);
// [2, 3] 삭제됨
// arr → [1, 4, 5]

arr.splice(1, 0, 100);
// 삭제 없이 1번 인덱스에 100 추가
// arr → [1, 100, 4, 5]

arr.splice(1, 2, 9, 9);
// 2개 삭제 후 9, 9로 대체
// arr → [1, 9, 9, 5]
```
