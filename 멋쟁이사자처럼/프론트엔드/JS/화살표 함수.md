- [[함수 표현식]]을 간단하게 표현하는 방법

```js
const hello = () => {
	console.log("hello");
}

const hello = () => console.log("hello");

hello();
```

- `function` 키워드 없이 함수 선언
- [[익명 함수]]의 일종 -> [[변수]] 이름 통해서 함수 호출
- [[함수 표현식]]과 마찬가지로 [[호이스팅]] X

- 화살표 함수에서 `return` 부분이 한 줄이면 중괄호 + `return` 키워드 없앨 수 있음
```js
const calculator = (a,b,c) => {
	return a * b * c;  // return O
} 

const calculator = (a, b, c) => a * b * c;
```
