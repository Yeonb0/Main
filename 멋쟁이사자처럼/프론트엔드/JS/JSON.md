- [[JavaScript]] Object Notation
- [[데이터]]를 저장하고 전송하기 위한 가벼운 데이터 형식
- 개방형 표준 포맷

- [[key]]-[[value]] 쌍으로 이루어진 구조

```js
{
  "name": "Alice",
  "age": 25,
  "isStudent": false,
  "skills": ["JavaScript", "Python", "C++"],
  "address": {
    "city": "Seoul",
    "zipCode": "12345"
  }
}
// JSON은 보통 객체 {} 또는 배열 [] 형태로 표현
```
