= 이벤트 핸들러(handler)

- 특정 [[Event|이벤트]]가 발생하기를 기다리고 있다가, [[Event|이벤트]]가 발생하면 등록된 이벤트 리스너 [[함수]] 사용

### `addEventListener`
```js
요소노드.addEventListner("이벤트명", func);
```
- "이벤트명" : `"click"`, `"keydown"` 등
- func : [[Event|이벤트]] 발생 시 호출할 [[콜백 함수]] 설정

```js
const btn = document.querySelector('button');
btn.addEventListener('click', function(event) {
    console.log('버튼이 클릭되었습니다!');
});
```

- 한 요소에 여러 개의 함수 등록 가능
