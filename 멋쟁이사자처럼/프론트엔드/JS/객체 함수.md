### `Object.keys(obj)`
- [[객체]]의 [[key]] 배열을 반환
```js
const student = { name: "Yena", age: 22 };
console.log(Object.keys(student)); // ["name", "age"]
```

### `Object.values(obj)`
- [[객체]]의 [[value]] 배열을 반환
```js
console.log(Object.values(student)); // ["Yena", 22]
```

### `Object.entries(obj)`
- [[객체]]의 [[key]]-[[value]] 배열을 반환
```js
console.log(Object.entries(student));
// [["name", "Yena"], ["age", 22]]
```
