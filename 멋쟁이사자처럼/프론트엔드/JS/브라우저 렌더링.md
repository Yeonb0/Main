## Critical Rendering Path
- 모든 [[브라우저]]는 [[HTML]]과 [[CSS]]로 작성한 웹 페이지를 화면에 [[렌더링]]
- 브라우저가 보이는 과정 -> Critical Randering Path
![[Pasted image 20260703100209.png]]


1. [[DOM]] / [[CSSOM]] 생성
	- 브라우저가 [[HTML]]과 [[CSS]]를 자신이 이해하기 쉬운 형태로 변환
2. [[Render Tree]] 생성 
3. Layout : 각 요소의 위치, 크기 계산
4. Painting : 화면에 실제로 그림

## Update
- [[이벤트]] 발생 시 화면이 실시간으로 변경되는 과정
- [[JavaScript|JS]]가 [[DOM]]을 수정하면서 발생

1. [[JavaScript|JS]]로 [[DOM]] 변경
2. [[브라우저]]가 변경 감지
3. 다시 [[렌더링]] 진행
	1. [[Render Tree]] 재생성
	2. Layout 재계산
	3. Painting 다시 수행

> [!warning] 주의할 점
> Layout & Painting -> 성능 비용이 크기 때문에 재[[렌더링]] 횟수 줄여야 함
> 

- 최적화 방법
	1. [[DOM]] 수정 횟수 최소화
	2. 여러 변경 사항을 한 번에 처리!
