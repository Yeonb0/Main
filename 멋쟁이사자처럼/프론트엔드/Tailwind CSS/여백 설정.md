- `p` -> [[padding]] (`p-숫자` 형식)
- `m` -> [[margin]] (`m-숫자` 형식)

- `p-3` -> 요소 전체 방향에 `0.75rem` 간격 [[padding]] 추가
	- `px-3` -> 가로 축에 추가
	- `py-3` -> 세로 축에 추가

### 방향 정리
|방향|padding|margin|
|---|---|---|
|전체 방향|p-3|m-3|

|세로축 방향|py-3|my-3|
|오른쪽|pr-3|mr-3|
