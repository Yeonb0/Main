- [[텍스트]] [[color]] : `text-{color name}-number`
- [[배경]] [[color]] : `bg-{color name}-number`

```html
<div className="w-full h-10 bg-red-400 text-blue-200">text</div>
```

### custom color 설정
- `theme` 안의 `extend` 안에 작성
```ts
// tailwind.config.js
theme: {
  	// extend 안에 작성하면 기본 색상 옵션도 사용 가능
    extend: {
      colors: {
        white: "#FFFFFF", // bg-white
      	black: {
          DEFAULT: "#000000",
          overlay: "rgba(0, 0, 0, 0.70)",
      	},
        gray: {
          100: "#F8FAFB", // text-gray-100
          200: "#EBEBEB",
        },
      },
    }
```
