- [[미디어 쿼리]]를 이용해 웹 페이지 [[레이아웃]] 동적 조정

> `sm` => `@media (min-width: 640px) { ... }`  
> `md` => `@media (min-width: 768px) { ... }`  
>	`lg` => `@media (min-width: 1024px) { ... }`  
>	`xl` => `@media (min-width: 1280px) { ... }`  
>	`2xl` => `@media (min-width: 1536px) { ... }`


```html
<div className="sm:hidden md:flex lg:inline-block"></div>
```
- `sm` 에선 숨김. `md` 에서는 `flex` 레이아웃 적용 `lg` 이상에서는 `inline-block` 으로 디스플레이

```html
<img className="w-16 md:w-32 lg:w-48" src="..." />
```
- 보통은 `w-16` 너비, `md` 에서는 `w-32`, `lg` 에서는 `w-48`
