- [[HTML5]] 에서 제공하는 저장 공간.
- [[로컬]]에 [[도메인]] 별로 지속되는 storage
	-> 같은 [[도메인]]에서만 접근 가능

- 시간 제한 X, [[브라우저]]가 꺼져도 데이터 유지 (<-> [[세션 스토리지]])
- [[쿠키]]보다 저장 용량의 제한이 적음
- [[문자열]]과 [[JavaScript|JS]] [[객체]]를 데이터로 저장 가능

```js
localStorage.setItem("key","value");     // 데이터 저장
const data=localStorage.getItem("key");  // 데이터 불러오기
console.log(data); // "value"
```

- 개발자 도구의 Application 탭에서 확인 가능
