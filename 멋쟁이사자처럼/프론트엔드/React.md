- Meta(Facebook) 이 개발한 [[오픈소스]] [[JavaScript]] [[라이브러리]]
- 대규모 웹 서비스의 [[UI|사용자 인터페이스]]를 편하게 개발하기 위해 만들어진 기술
- 인터랙티브 UI 에 강점

## 특징
1. [[컴포넌트]] 기반 [[아키텍쳐]]
	- 재사용 가능 -> 중복 코드 감소
	- 각 [[컴포넌트]] 는 자체적으로 [[state]] 가질 수 있음
	  -> [[state]] 변화 시 자동 화면 [[업데이트]]하므로 UI 관리 용이
	- [[컴포넌트]]간 부모-자식 구조 -> 계층적 설계 가능

2. 단방향 데이터 흐름
	- 데이터는 반드시 부모 [[컴포넌트]] -> 자식 [[컴포넌트]]로 전달
	- 이때 전달되는 데이터는 [[Props]] 라고 함

3. 쉬운 화면 [[업데이트]] 구현
	- [[React]]는 [[선언형 프로그래밍]] 방식 사용
	- [[업데이트]] 구현이 쉽고, 더 적은 코드로 효율적 작업 가능

4. 효율적 화면 [[업데이트]] 처리
	- 각 [[컴포넌트]]의 [[state]] 를 변경함을 통해 화면 업데이트 가능
	- [[React]]는 [[Virtual DOM]] 을 사용해 [[DOM]] 변경 사항 효율적 관리
