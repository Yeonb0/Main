- 외부 사계와의 상호작용을 총해 발생하는, 예측이 어려운 결과

|사이드 이펙트 종류|예시|
|---|---|
|✅ 데이터 요청|`fetch`, `axios` 등으로 API 호출|
|✅ 이벤트 등록|`window.addEventListener`, 키보드 입력 감지|
|✅ 타이머 설정|`setTimeout`, `setInterval`|
|✅ DOM 조작|`document.querySelector()` 로 요소 직접 수정|
|✅ 외부 라이브러리 사용|애니메이션, 캔버스, 차트 등 초기화|
|✅ 로컬 스토리지 접근|`localStorage.setItem()`, `getItem()` 등|
|✅ 콘솔 출력|`console.log()` 도 사이드 이펙트로 분류됨|
```jsx
function User(props) {
  fetch("https://api.com/user");            // API 호출 ← 사이드 이펙트!
  localStorage.setItem("name", props.name); // 저장소 접근 ← 사이드 이펙트!
  return <h1>{props.name}</h1>;
}
```
