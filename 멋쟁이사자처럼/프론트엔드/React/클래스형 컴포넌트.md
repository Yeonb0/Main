- [[ES6]]의 `class` 문법으로 정의
- [[React]]의 `Component`를 상속받아 구현하며, `render()` 함수가 필수
- **상태 관리**: `this.state`로 상태를 관리하고, `this.setState`로 상태를 업데이트.
- **생명주기 메서드**: `componentDidMount`, `componentDidUpdate`, `componentWillUnmount` 등 생명주기 메서드 제공.
- **구조 복잡**: 클래스 문법과 `this` 바인딩이 필요해 상대적으로 코드가 복잡

```jsx
import React, { Component } from "react";

class Counter extends Component {
  constructor(props) {
    super(props);
    this.state = { count: 0 }; // 상태 정의
  }

  increase = () => {
    this.setState({ count: this.state.count + 1 }); // 상태 업데이트
  };

  render() {
    return (
      <div>
        <p>Count: {this.state.count}</p>
        <button onClick={this.increase}>Increase</button>
      </div>
    );
  }
}

export default Counter;
```
