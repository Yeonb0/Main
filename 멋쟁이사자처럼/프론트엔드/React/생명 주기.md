- [[컴포넌트]]가 화면에 나타나고, [[업데이트]] 되고, 사라지는 과정

### Mount
- [[컴포넌트]]가 처음으로 화면에 나타나는 단계 (눈에 보이는 단계)
- 컴포넌트 함수가 실행 -> JSX 가 [[DOM]] 으로 변환되어 [[브라우저]]에 나타남

### Update
- [[컴포넌트]]의 [[state]]나 [[Props|props]] 값이 변경되어 [[리렌더링]]
- 변경된 값 기반으로 [[DOM]] 업데이트

### Unmount
- [[컴포넌트]]가 화면에서 사라질 때
- 조건부 렌더링 ([[삼항 연산자]] / [[boolean]]) 에서 더 이상 렌더링되지 않게 될 때
