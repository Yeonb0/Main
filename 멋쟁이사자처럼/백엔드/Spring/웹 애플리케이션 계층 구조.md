## 구성 요소
1. Controller (컨트롤러) -> [[클라이언트]]의 요청을 받아 ==서비스==에 전달
	`@RestController` / `@Controller` [[어노테이션]] 사용
2. Service (서비스) -> 비즈니스 로직 처리
   `@Service` [[어노테이션]] 사용
	- 여러 ==Repository== 혹은 외부 [[API]] 와 상호작용해 ==Controller== 에 데이터 반환
3. Repository (리포지토리) -> [[데이터베이스]]와 직접 통신하는 계층
   `@Repository` [[어노테이션]] 사용
	- [[JPA]], [[MyBatis]] 등의 [[ORM]] [[프레임워크]] 활용
4. Domain (도메인) -> 주요 [[엔티티]] 및 [[데이터 모델]] 관리 계층
   `@Entity` [[어노테이션]] 사용
5. [[데이터베이스|Database]] (데이터베이스) -> 데이터 저장 공간
	- [[MySQL]], [[PostgreSQL]], [[H2 Database]] 등의 [[RDBMS]] 또는 [[MongoDB]] 같은 [[NoSQL]] 사용
