- 데이터의 직접적 접근을 막음
- `getter`, `setter` [[메소드]]를 통해 데이터의 값을 꺼내오거나 수정
	- `getter` : 외부에서 [[객체]]의 데이터를 읽을 때 사용 -> `return` 값 필요
	- `setter` : 외두에서 [[객체]]의 데이터를 수정할 때 사용 -> [[매개 변수]] 필요

### 장점
- 데이터의 [[무결성]] 보존
	- 데이터 접근 & 생성 시 한 번 검증하로 처리
- [[정보 은닉]] 가능
	- [[필드]]를 `private` 으로 두어 [[캡슐화]]

### [[어노테이션]]
```java
@Getter
@Setter
```
-> 해당 클래스의 모든 [[필드]]에 대해 [[getter & setter]] [[메소드]] 자동 구현
