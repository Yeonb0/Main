- 참조된 memory 주변 · 자신이 다시 참조되는 경향
- [[캐시 메모리]] 가 효율적인 이유

### 종류
- Temporal Locality : 한 번 참조된 memory 가 다시 참조될 가능성 ↑

![[Cache-Memory-05.png]]

- Spatial Locality : 참조된 memory 근처 memory 가 참조될 가능성 ↑

![[Cache-Memory-06.png]]

- 다수 프로그램이 자연스럽게 두 성질 보유 -> cache 저장 시 다음 접근에서 load 속도 ↑

### 예시
![[Cache-Memory-07.png]]

| 대상 | Temporal | Spatial |
| --- | --- | --- |
| Data | `sum` [[변수]] 반복 참조 | `a[]` 요소 순차 참조 |
| Instruction (code) | `+=` [[연산]]이 loop 안에서 반복 실행 | 명령어 순차 참조 |
