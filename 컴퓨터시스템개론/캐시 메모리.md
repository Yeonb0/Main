- [[CPU]] - [[메모리|main memory]] 사이의 중간 storage
- data · code 저장 -> [[CPU]] 가 [[메모리]] 보다 훨씬 빠르게 접근 O
- `cash` 처럼 들려 `$` 로 표기하기도 함

### 넓은 의미
- 두 시스템 사이의 중간 저장소 전반
- ==ex)== Web browser cache

### 특징
- 하드웨어 레벨에서 자동 관리 -> [[어셈블리 코드]] 로 직접 control X (transparent)
- [[메모리|main memory]] 대비 크기 ↓, access time ↑
- main memory 의 자주 접근되는 subset 만 보관 -> block 단위 (최소 단위)
- [[지역성]] 성립 -> [[캐시 히트와 미스|hit]] 비율 ↑
