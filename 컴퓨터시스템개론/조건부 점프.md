- [[플래그 레지스터]] [[state|상태]]에 따라 실행 흐름 분기하는 [[어셈블리 코드]] 명령어
- 고급 언어의 [[조건문]] · [[반복문]] 이 기계 수준에서 구현되는 형태

### 절차
1. 어떤 operation 실행 (`sub`, `cmp`, `and`, `test` 등) -> 실행 결과에 따라 [[플래그 레지스터]] update
2. flag register 상태에 따라 jump instruction 실행 (`je`, `jne`, `j__`)

### 종류
| 명령어 | 조건 |
| --- | --- |
| `jmp` | 항상 |
| `je` (or `jz`) | zero flag 1 (zero) |
| `jne` (or `jnz`) | zero flag 0 (zero X) |
| `js` | sign flag 1 (음수) |
| `jns` | sign flag 0 (음수 X) |
| `jg` | greater |
| `jge` | greater or equal |
| `jl` | less |
| `jle` | less or equal |
| `ja` | above (unsigned) |
| `jae` | above or equal (unsigned) |
| `jb` | below (unsigned) |
| `jbe` | below or equal (unsigned) |

- `g` · `l` 계열 -> signed 비교, `a` · `b` 계열 -> unsigned 비교

### 0 · 부호 검사
- `and` / `test` 로 자기 자신 검사 -> flag 만 갱신
``` nasm
and %rax, %rax  ; 자기 자신과 and -> 자기 자신
js  0x100       ; rax < 0 이면 jump

cmp $0, %rax    ; 0 ?= %rax 0이면 1, 아니면 0
and %rax, %rax  ; 자기 자신과 and -> 자기 자신
je  0x100       ; rax == 0 이면 jump
```

### destination 갱신 여부
| 명령어 | destination register | flag register |
| --- | --- | --- |
| `sub` & `and` | update O | update O |
| `cmp` & `test` | update X | update O |
