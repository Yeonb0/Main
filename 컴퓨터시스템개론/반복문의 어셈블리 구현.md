- [[반복문]] 을 조건 검사 + [[GOTO|goto]] 조합으로 변환한 기계 수준 형태
- [[for]] -> [[while]] -> [[if]] & goto 순 단계적 변환
- 조건 검사에 [[조건부 점프]] 사용

### while 변환
``` c
while (test) {
	Body
}
```
- if & goto 로 나타내기 -> 하단 조건 검사, 진입 시 test 로 jump
``` c
	goto test;
loop:
	Body
test:
	if (Test)
		goto loop;
```
- another version -> 진입 시 조건 불만족 검사 후 하단 반복 검사
``` c
	if (!Test)
		goto done;
loop:
	Body
	if (Test)
		goto loop;
done:
```

### for 변환
``` c
for (Init; test; Updata) {
	Body
}
```
``` c
Init;
while (Test) {
	Body;
	Update;
}
```
- -> if & goto

``` nasm
0x0000000000401156 <+12>:    add %rax,%rdx    ; result += i
0x0000000000401159 <+15>:    add $0x1,%rax    ; i++

0x000000000040115d <+19>:    cmp %rdi,%rax    ; n, i 비교
0x0000000000401160 <+22>:    jle 0x401156 <whatAmI+12> ; i <= n 이면 jump

0x0000000000401162 <+24>:    mov %rdx,%rax    ; rax = result
0x0000000000401165 <+27>:    ret
```
- -> C 언어로
``` c
long sum(long n) {
	long result = 0;
	for (int i = 1; i <= n; i++) {
		result += i;
	}
	return result;
}
```
