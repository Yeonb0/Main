- 컴퓨터 내부 동작(under the hood) 을 [[프로그래머 관점]]에서 다루는 시스템 개론 과목
- [[추상화]] 의 반대 방향 -> 내부 구조(Internals) 직접 관찰

### 목표
- `hello` 프로그램의 실체 파악
- 컴퓨터가 실행 파일을 [[저수준|low-level]] 로 실행하는 방식 파악
	- [[저수준|low-level]] : 하드웨어 · 물리적 기계와 가까움

### [[추상화]] 예시
- 내부 구현(Internal Implementation) 모르는 [[state|상태]]로 interacting
- ==ex)==

```powershell
$ vim hello.c
$ gcc hello.c -o hello
$ ./hello
>> Hello world!
```

```c
#include <stdio.h>

int main() P
	printf("Hello world!\n");
	return 0:
}
```

- `printf()` [[함수]]의 내부 코드 모르는 채로 사용
- `gcc` 의 내부 기능 모르는 채로 사용
- [[컴파일]] 이후 `hello` (executable or binary) 의 내부 모습 · 실행 방법 모르는 채로 사용

### 내부 구조를 배우는 이유
- correct + efficient 한 코드 작성 -> 좋은 프로그래머
- [[추상화]] 의 한계 : bug 존재
- 저수준 디테일 파악 -> bug 수정 O, 프로그램 성능 향상 O
- CS 복잡한 개념의 기초 ==ex)== LLM
