- [[메모리 정렬]] 규칙을 구조체 단위로 적용한 것
- 각 [[필드]] -> 자기 크기의 배수 위치 -> 사이에 padding 삽입
- 구조체 전체 길이 -> 내부 최대 [[필드]] 크기의 배수로 맞춤

```c
struct S1 {
	char c;    // 1
	int i[2];  // 4
	double d;  // 8
	short s;   // 2
};
```

![[Assembly-Array-and-Struct-09.png]]

### 규칙
| 타입 | 시작 위치 |
| --- | --- |
| `int` | 4의 배수 |
| `double` | 8의 배수 |
| `short` | 2의 배수 |

- ==ex)== `S1` 최대 크기 `double` -> 전체 길이 8 byte 배수

### 공간 절약
- [[필드]] 선언 순서 -> padding 양 결정
- 정렬 고려한 순서 [[배치 처리|배치]] -> padding↓ -> [[메모리]] 공간 절약
