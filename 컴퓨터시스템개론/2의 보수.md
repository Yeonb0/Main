- 첫 bit 를 부호로 쓰는 음수 표현 방식 -> Most Significant Bit, [[MSB]]
- [[하드웨어]] 에서 더 효율적 -> 덧셈 회로 그대로 [[재사용(Reuse)|재사용]]

### 음수 표현법
1. 첫 번째 bit 를 부호 표현에 사용
	- 0 -> 양수 / 1 -> 음수
	- 산술 [[연산]] 복잡 -> 직관적이지만 사용 X
2. Two's Complement (2의 보수)
	- 첫 bit -> 부호 표현 ([[MSB]])
	- 하드웨어에서 더 효율적

### 부호 반전
- $-x$ 구하기 -> bit-flip & +1
- 성립 이유
	- `~x + x == 1111..1111 == -1`
	- `1 + x + x == 0`
	- `(~x + 1) + x == 0`
	- `~x + 1 == -x`
- SMin ($-2^{w-1}$) 의 Negation -> [[오버플로]] 되어 똑같은 값 반환

### 뺄셈
- 컴퓨터는 빼기를 양수 + 음수로 구현
	- x + BFI(y)
	- BFI = Bit-Flip and Increment
- $x - y = x + (-y)$
- Unsigned & Signed 연산 동일
	- 단, Unsigned 에선 underflow 발생 가능
