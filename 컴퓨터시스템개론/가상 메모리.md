- 프로그램마다 독립된 주소 공간 제공하는 [[메모리]] 관리 기법
- [[운영체제|OS]] 가 관리 -> [[컨텍스트 스위칭]] 중 주소 [[Collision|충돌]] 방지

### 종류
| 구분 | 내용 |
| --- | --- |
| virtual address | 프로그램에서 사용하는 주소 |
| physical address | 실제 [[메모리]] 에서의 [[MAC Address\|물리적 주소]] |

### 기능
- virtual address -> 각 프로그램이 [[CPU]] 를 온전히 점유한다는 착각 유발
