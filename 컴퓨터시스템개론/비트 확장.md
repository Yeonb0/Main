- x bit 정수를 (x+k) bit 로 늘리는 [[연산]]
- 위쪽에 k bit 새로 추가

### 종류
1. Zero Extension
	- Unsigned integer 대상
	- 위쪽에 새로 추가된 k bit 를 0 으로 채우기

![[Data-Representation-15.png]]

2. Sign Extension
	- Signed integer 대상
	- 위쪽에 새로 추가된 k bit 를 [[MSB]] 로 채우기

![[Data-Representation-16.png]]

### 관련 명령어
- [[x86-64]] -> [[movz & movs]] 로 수행
	- `movz` : Zero Extension
	- `movs` : Sign Extension
