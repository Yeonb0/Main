- [[캐시 메모리]] 를 이루는 set · line · block 의 계층 구성

![[Cache-Memory-10.png]]

### 구조
- cache = S 개의 set
	- set = E 개의 line
		- line = 1 valid bit + t tag bit + B 개의 block

### 크기
- 총 cache data size = $B \times E \times S$
	- valid bit · tag bit 는 제외
