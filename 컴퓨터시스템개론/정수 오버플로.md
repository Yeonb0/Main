- `int` 타입의 표현 범위 초과 -> 값이 wrap around, 부호까지 뒤바뀜
- `int` 는 실제 수학의 정수 아님 -> 유한 비트 표현에서 기인

### 예시
- $x^2 ≥ 0$ 이 모든 정수 $x$ 에 대해 참인가?
	- 실제 수학 : Yes
	- C 언어 `int` type
		- ==40000 * 40000 = 1600000000== -> 정상
		- ==50000 * 50000 = -1794967296== -> 오버플로
- 컴퓨터의 [[데이터]] 표현 방식 이해 필요
