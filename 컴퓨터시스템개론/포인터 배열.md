### 메모리 배치
![[Assembly-Array-and-Struct-06.png]]

- 같은 배열 내부 -> 연속
- 배열 전체 -> 연속 X
- 각 요소 -> [[포인터]] -> 8 byte

### 요소 접근
- `*(*(arr + 8 × ptr_idx) + 4 × int_idx)`
```c
int get_elem(int *arr[],
						 int ptr_idx,
						 int int_idx)
{
	return arr[ptr_idx][int_idx];
}
```
```nasm
movslq  %esi, %rsi
mov    (%rdi, %rsi, 8), %rax   ; %rax = arr[ptr_idx(8)]
movslq  %edx, %rdx
mov    (%rax, %rdx, 4), %eax   ; return %rax[int_idx]
ret
```
- [[mov]] 2회 -> [[Pointer|포인터]] load 후 값 load

### 2차원 배열과 비교
| 구분 | 요소 접근식 |
| --- | --- |
| 2차원 [[배열]] | `*(arr+(20×row_idx)+(4×col_idx))` |
| 포인터 배열 | `*(*(arr+(8×ptr_idx))+4×int_idx)` |

- C 코드 상 유사, low level 에서는 상이

### 주의점
```c
char strs[4][64]; // 2D array
char* ptrs[4];    // Array of char*

strcpy(strs[1], "ABC");  // (1)
strcpy(ptrs[1], "ABC");  // (2)
strs[2] = "DEF";         // (3)
ptrs[2] = "DEF";         // (4)
```
1. correct
2. segment fault -> `ptrs[1]` 초기화 X -> 쓰레기 주소 접근
	- 할당 후 사용
```c
ptrs[1] = (char*) malloc(4);
strcpy(ptrs[1], "ABC");
```
3. compile error -> 대입은 [[포인터]] O / [[배열]] X
	- `strs[2]` 자체가 `char[64]` -> `strcpy` 필요
4. correct
