- 수를 표현하는 기수 체계
- $r$ -> radix / base / 기수 / 진법

$$

(a_{n-1} a_{n-2} \cdots a_1 a_0)_r
= a_{n-1} r^{\,n-1} + a_{n-2} r^{\,n-2} + \cdots + a_1 r + a_0
\\
\text{(where } 0 \le a_i < r \text{)}

$$

### 종류
- 10진수 : $r$ = 10 -> decimal
- 2진수 : $r$ = 2 -> binary
- 16진수 : $r$ = 16 -> hexadecimal
	- A 10, B 11, C 12, D 13, E14, F15
