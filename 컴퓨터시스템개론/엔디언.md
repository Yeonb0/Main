- Multi-byte data 를 [[메모리]] 에 [[배치 처리|배치]]하는 byte 순서

### 종류
- Big Endian : MSB (Most Significant Byte) 를 앞쪽으로 (가장 낮은 주소로)
- Little Endian : MSB (Most Significant Byte) 를 뒤쪽으로 (가장 높은 주소로)
	- x86 -> Little Endian 사용

![[Data-Representation-19.png]]

### 확인 방법
- byte 값을 나타내주는 [[함수]]

```c
void show_bytes(unsigned char* start, size_t len) {
	size_t i;
	for (i = 0; i < len; i++) {
		printf("%p: 0x%.2x\n", start + i, start[i]);
	}
}
```

#### integer
- byte 의 sequence 출력

```c
int a = 303030;
show_bytes((unsigned char*) &a, sizeof(int));
```

![[Data-Representation-20.png]]

- 결과 -> 실행마다 다를 수 있음 (memory 저장 위치)

#### pointer
- [[CPU]] 의 관점에서 [[포인터]] 는 integer 와 차이 X
- pointer -> 메모리 주소를 나타내는 integer

```c
int *p = &a;
show_bytes((unsigned char*) &p, sizeof(int*));
```

![[Data-Representation-21.png]]

#### string
- [[C]] 에서 [[문자열|String]] 은 char 의 [[배열]] 표현
	- 각 char 는 [[ASCII]] (1 byte) 로 인코딩
	- `null` 로 종료 필수
- Big & Little endian system 모두 순서 동일 -> 읽는 순서로

```c
char s[6] = "AB123";
show_bytes((unsigned char*) s, sizeof(s));
```
