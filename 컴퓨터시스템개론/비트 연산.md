- [[Boolean Algebra]] 를 bit vector 단위로 적용하는 [[연산]]
- [[C]] 의 연산자 : `&`, `|`, `~`, `^`

### 특징
- 다양한 [[데이터 타입]]에 적용 O
- 피연산자 -> bit vector 처럼 취급
- bit-wise 로 연산자 적용

![[Data-Representation-04.png]]

### 집합 표현
- Bit 로 Set 표현 O
- 원소가 n 개 -> bit n 개 사용해 on, off 표현
- `&` : 교집합
- `|` : 합집합
- `~` : 여집합
