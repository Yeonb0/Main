- flag 조건 만족 여부에 따라 분기 없이 값 이동 · 설정하는 명령어
- `cmov_` : conditional move
- `set_` : 조건 만족 -> destination 1, 불만족 -> 0 set
- 양쪽 경로 미리 계산 -> jump 제거 -> [[성능 최적화]] 이점

### 예시
- ==ex)== `absdiff` : 두 값 차의 절댓값
``` c
long absdiff (long x, long y) {
	long result;
	if (x > y) 
		result = x - y;
	else 
		result = y - x;
	return result;
}
```

| Register | Use |
| --- | --- |
| `%rdi` | x (첫 번째 argument) |
| `%rsi` | y (두 번째 argument) |
| `%rax` | return |

``` nasm
absdiff:
		mov    %rdi, %rdx  ; rdx = x
		mov    %rsi, %rax  ; rax = y
		sub    %rsi, %rdx  ; rdx = x - y
		sub    %rdi, %rax  ; rax = y - x
		cmp    %rsi, %rdi  ; if (x > y)
		cmovg  %rdx, %rax  ; rax = rdx (x - y)
		ret
```
- 두 뺄셈 모두 수행 -> `cmovg` 로 결과 선택
