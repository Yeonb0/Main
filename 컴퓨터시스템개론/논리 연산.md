- [[C]] 의 `&&`, `||`, `!` -> [[비트 연산]] 과 유사
- 0 -> false / 0이 아닌 값 -> true

### Early termination
- 조기 종료 : 앞 피연산자만으로 결과 확정 -> 뒤 평가 X
- `&&` 에서 앞이 false -> 바로 false
- `||` 에서 앞이 true -> 바로 true
- ==ex)== `if(p && *p == 1)` 사용 -> NULL [[포인터]] 사용 방지 O
