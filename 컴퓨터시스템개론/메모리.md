### 프로그램 메모리 영역
![[Buffer-Overflow-03.png]]

- [[stack|Stack]] : [[함수]] 실행 중의 [[스택 프레임]]
- [[Heap]] : `malloc()` · `new()` 로 할당되는 dynamic memory block
- Data : 프로그램의 global [[변수]]
- Code (text) : Instruction

### 휘발성
- Main Memory (RAM) : 컴퓨터 종료 시 소멸
- [[보조기억장치]] (SSD) : 컴퓨터 종료해도 유지

### 주소 공간
- [[로더]] : executable 파일을 memory 공간으로 load
- [[가상 메모리]] -> 프로그램마다 독립 주소 공간 제공
