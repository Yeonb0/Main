- 주소 $x$ 접근 -> m bit 를 t / s / b 로 분할해 [[캐시 라인|set · line · block]] 선택

![[Cache-Memory-11.png]]

### 구조
| [[필드]] | 내용 |
| --- | --- |
| m | 주소 길이 bit |
| t (tag) | line 선택 시 비교용 |
| s (set index) | 몇 번째 set 사용할지 결정 |
| b (block offset) | 몇 번째 block 사용할지 결정 |

### 예시
![[Cache-Memory-12.png]]

- b -> ==6 bits==
	- $2^6$ -> block 기준 ==64 byte==

![[Cache-Memory-13.png]]

- s = 11 -> 11 번 set 사용
- b = 24 -> 24 번째 block 사용 (`0xAC0` ~ `0xB00`)
- t = `0 0 0 0 1` -> line 선택 시 사용

### 연습
![[Cache-Memory-14.png]]

1. i 가 포함된 block 의 address 범위
	- B = 8 -> 8 byte 단위
	- i 는 4 byte + [[엔디언|little endian]] -> `0x66204C` 는 4 ~ 7
	- 총 범위 `0x662048` ~ `0x662050`
2. 이 block 이 저장된 set 번호
	- $m = t + s + b$ -> 32 = 22 + 7 + 3
	- `0x66204C` = `......000001001100`
	- s = `0001001` ⇒ 9 번 set
3. block 의 4 ~ 7 offset 값
	- [[엔디언|little endian]] 방식 ⇒ `4241` 저장
