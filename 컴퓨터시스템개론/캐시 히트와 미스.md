- [[캐시 메모리]] 접근 결과의 두 가지 [[state|상태]]

### 종류
- Cache hit : [[CPU]] 가 필요한 data 가 cache 에 존재 O
- Cache miss : [[CPU]] 가 필요한 data 가 cache 에 존재 X
	- [[메모리|main memory]] 접근 -> 기존 block replace ([[캐시 교체 정책|replacement policy]])

### 조건
- set 내 [[캐시 라인|line]] 이 1개 -> miss 시 set 전체가 새 block 으로 교체
