- [[CPU]] 가 가장 효율적으로 다룰 수 있는 data 단위
- 요즘 대부분의 CPU -> 64 bit (8 byte) word size

### 의미
1. size of register ([[CPU]])
	- 요즘 [[레지스터]] 는 8 byte
	- CPU 와 [[메모리]] 사이 주고 받을 수 있는 최대 [[데이터]] 크기
2. size of memory address
	- [[포인터]] [[변수]]의 size
	- ==ex)== `sizeof(int*)` = 8
	- memory address 의 가능한 범위 결정 : $0 \sim 2^{64} -1$
