- [[캐시 미스]] 시 set 내 어느 line 을 내보낼지 결정하는 규칙
- set 의 line 이 모두 사용 중일 때 필요 -> [[집합 연관 캐시]] / [[완전 연관 캐시]] 대상

### 종류
- [[LRU]] (Least Recently Used) : 가장 오래 참조되지 않은 line 교체

### 절차
- 각 line 마다 Age 설정
	1. 선택된 line -> ==0== 으로 초기화
	2. 나머지 line -> ==+1==
- Age 최대인 line 이 교체 대상
