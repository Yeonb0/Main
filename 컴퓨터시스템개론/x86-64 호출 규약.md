- [[함수]] 의 인수 · 결과 값을 담는 [[x86-64 레지스터]] 약속

| 용도 | register |
| --- | --- |
| 첫 번째 인수 | `%rdi` |
| 두 번째 인수 | `%rsi` |
| 세 번째 인수 | `%rdx` |
| 결과 값 | `%rax` |

### ==ex)== [[C]] code
```c
int sum(long x, long y, long *dst) {
	*dst = x + y;
	return 1;
}
```

### ==ex)== [[어셈블리 코드]]
```nasm
sum:
	add   %rsi, %rdi
	mov   %rdi, (%rdx)
	mov   $0x1, %eax
	ret
```

### 인수 전달 순서
- argument 최대 ==6개== register 전달

1. `%rdi`
2. `%rsi`
3. `%rdx`
4. `%rcx`
5. `%r8`
6. `%r9`

- return value -> `%rax`

### 저장 책임
| 구분 | register | 내용 |
| --- | --- | --- |
| [[caller-saved]] | `%rdi` `%rsi` `%rdx` `%rcx` `%r8` ~ `%r11` | callee 가 자유롭게 사용 O, [[stack]] 저장 X |
| [[callee-saved]] | `%rbx` `%r12` ~ `%r14` | callee 가 복원, [[함수]] 종료 후에도 사용할 값 |

- [[Caller와 Callee]] 구분은 상대적
