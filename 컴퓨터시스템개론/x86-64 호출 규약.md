- [[함수]] 의 인수 · 결과 값을 담는 [[x86-64 레지스터]] 약속

| 용도 | register |
| --- | --- |
| 첫 번째 인수 | `%rdi` |
| 두 번째 인수 | `%rsi` |
| 세 번째 인수 | `%rdx` |
| 결과 값 | `%rax` |

### ==ex)== [[C]] code
```c
int sum(long x, long y, long *dst) {
	*dst = x + y;
	return 1;
}
```

### ==ex)== [[어셈블리 코드]]
```nasm
sum:
	add   %rsi, %rdi
	mov   %rdi, (%rdx)
	mov   $0x1, %eax
	ret
```
