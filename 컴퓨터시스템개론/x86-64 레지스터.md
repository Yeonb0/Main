### 특수 목적
| register | 역할 |
| --- | --- |
| `%rip` | instruction pointer, [[프로그램 카운터]] |
| `%rsp` | [[stack]] pointer |

### 부분 이름
![[Assembly-Introduction-07.png]]

- 끝 4 byte -> `%e__`
- 끝 2 byte -> 앞에 r 빼고 `%__`
	- 앞 1 byte -> 앞에 r 빼고 `%_h`
	- 뒤 1 byte -> 앞에 r 빼고 `%_l`

-> 호환성 위해 옛 register [[이름]] 유지
