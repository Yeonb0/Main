- 여러 execution 이 서로 interleaving 되며 [[CPU]] 점유 교체
- [[컨텍스트]] 저장 · 복원 -> 실행 주체 전환
- 다수 프로그램 ==동시== 실행처럼 체감

### 형태
- ==ex)== [[서버]]에 다수 사용자 동시 접속 -> 각자 프로그램 실행

```
Time ──────────────────────────────────────────────►
A's program :  ████      ████      ████
B's program :      ████      ████      ████
C's program :          ████      ████      ████

```

- 실행 흐름은 [[어셈블리 코드]] 명령어 단위로 교차

```nasm
  mov %rax, %rcx
  ...
  add $0x10, %rdi
  ...
```

### 조건
- [[메모리]] 주소 [[Collision|충돌]] 문제 -> [[가상 메모리]] 로 해소
