- [[메모리]] operand 의 주소를 계산해 지정하는 형식

![[Assembly-Introduction-10.png]]

### 직접 지정
- ==ex)== `movl $0x4142, (%rax)`
	- `(%rax)` 메모리 주소에서 4 byte 만큼 [[상수]] `0x41`, `0x42` 지시 ([[엔디언|little endian]])
	- 접미사 `l` 생략 X -> 4 byte 만 update 명시
	- 다른 suffix 사용 O

### 변위 · 인덱스 · scale
- ==ex)== `mov 0x20(%rbx, %rcx, 4), %rax`
	- `%rax` = `0x20` + `%rbx` + `(%rcx * 4)`
	- `4` = scale factor (1, 2, 4, 8 가능)
	- [[배열]] access 시 유용
	- 요소 생략 O
