- 1 byte = 8 [[비트|bit]]
- CS 에서 사용하는 [[데이터]] 단위

### 표현 범위
- 2진수 : 00000000 ~ 11111111
- 10진수 : 0 ~ 255
- 16진수 : 0 ~ FF
	- [[C]] 에서 `0x` 를 prefix 로 사용해 16진수 표기 O

### 자릿수
- 1 byte = 2진수 8 digit = 16진수 2 digit
- 2진수 ↔ 16진수 변환 : binary 4 bit 씩 묶어서 hexadecimal 로 표시
