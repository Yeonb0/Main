- 똑같은 bit 를 다른 [[정수]] 타입으로 다시 해석하는 [[형 변환]]
- [[Unsigned vs. Signed]] 사이 재해석

### Explicit type conversion
- 프로그래머가 직접적으로 type 명시 -> [[캐스팅]]

```c
int si = -10;
unsigned int ui = (unsigned int) si;
```

- unsigned -> bit -> signed 변환
- signed -> bit -> unsigned 변환

### Implicit conversion
- 명시 없이 [[C]] 에서 자동으로 수행하는 형 변환
- 기본적으로 C 에서 int 생성 -> signed int
	- unsigned integer 생성 -> 접미사 `U` 필요
- signed + unsigned [[연산]] 혼합 -> unsigned 로 자동 casting
- ==ex)==

| C 표현식 | Evaluation | Result |
| --- | --- | --- |
| `0 == 0U` | Unsigned | true |
| `-1 < 0` | Signed | ture |
| `-1 < 0U` | Unsigned | false |

- 마지막 경우 -1 이 unsigned 로 바뀌면서 429496729U 로 자동 형변환
