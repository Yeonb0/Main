- `E > 1 && S > 1` 인 [[캐시 메모리]] 사상 방식
- set 여러 개 & line 여러 줄

![[Cache-Memory-18.png]]

### 절차
1. set index (s) 로 set 선택
2. 선택된 set 의 line 전수 검사
	- valid bit ==1== && tag bit 일치 -> [[캐시 히트]]
	- valid bit ==0== || tag bit 불일치 -> [[캐시 미스]]

### 특징
- [[직접 사상 캐시]] 와 [[완전 연관 캐시]] 의 절충 (장단점 모두 중간 성격)
- set 당 line 수 ↑ -> [[스래싱]] ↓
- line 여러 줄 -> [[캐시 교체 정책]] 필요
