- 구조체 크기 × 요소 개수만큼 연속 [[배치 처리|배치]]
- 요소 하나의 크기 -> [[구조체 정렬]] 적용 후 크기

```c
struct S2 {
	short i;
	int j;
	short k;
};

struct S2 a[8];
```

- ==ex)== `S2` -> padding 포함 12 byte

### 요소 접근
- 주소 = base + idx × struct_size + [[필드|field]] offset
```c
short get_k (struct S2 arr[], int idx) {
	return arr[idx].k;
}
```
```nasm
movslq  %esi, %rsi
lea    (%rsi, %rsi, 2), %rax     ; %rax = idx * 3
movzwl  0x8(%rdi, %rax, 4), %eax ; %rax = arr[] + idx * 12 + 8
ret
```
- `idx × 3` 후 scale `4` 결합 -> `idx × 12`
- `0x8` -> `k` 의 offset
