- bit sequence 를 좌 / 우로 밀어내는 [[연산]]

### Left Shifting
- `x << y` : x 를 y 만큼 왼쪽으로 옮김
- 왼쪽에 튀어나오는 bit 버림, 오른쪽은 0 으로 채움
- $x \times 2^y$ 와 같음 -> [[오버플로]] 발생 가능
- ==ex)== `10100010 << 3` = `00010000`

### Right Shifting
- `x >> y` : x 를 y 만큼 오른쪽으로 옮김
- 오른쪽에 튀어나오는 bit 버림
- $x \times \frac{1}{2^y}$ 와 같음
- 종류
	- Logical : 왼쪽을 0 으로 채움
	- Arithmetic : 왼쪽을 x 의 [[MSB]] 로 채움
- 대부분의 언어 -> Unsigned 는 Logcal shift, Signed 는 Arithmetic shift 실행
- ==ex)==
	- Logical shift : `10100011 >> 2` = `00101000`
	- Arithmetic shift : `10100011 >> 2` = `11101000`
