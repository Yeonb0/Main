- 다음 실행할 명령어를 저장하는 [[레지스터]]
- [[x86-64 레지스터]] 중 `%rip` 에 대응

### 동작
- 명령어 fetch -> 해당 주소 저장
- 실행 후 자동으로 다음 명령어 지시 -> [[명령어 실행 사이클]] 유지

### 함수 복귀
- [[ret]] = `pop %rip`
	- [[stack]] 의 [[반환 주소]] [[pop]] -> `%rip` 적재 -> 호출 지점 복귀
