- [[CPU]] 가 [[메모리]] 에서 명령어 가져와 실행하는 동작의 반복
- instruction 과 data 모두 [[메모리]] 에 저장
	- instruction = 약속된 의미 지닌 bit sequence

### 절차
1. [[메모리]] 로부터 명령어 fetch
	- 가져온 명령어의 주소 -> [[프로그램 카운터]] 에 저장
2. 저장된 명령어가 [[CPU]] 의 할 일 지시
	- [[기계어]] / [[어셈블리 코드]] 형태
3. 실행 후 [[프로그램 카운터]] 자동으로 다음 명령어 지시

-> 1 ~ 3 반복 수행
