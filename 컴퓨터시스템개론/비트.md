- 0 or 1 값 가지는 binary digit
- 컴퓨터의 모든 것 (정보, [[데이터]], 실행 파일) 을 구성하는 최소 단위
- 컴퓨터는 모든 것을 bit 의 sequence 로 저장

### 컴퓨터 내부 실행
![[Data-Representation-01.png]]
- [[CPU]] : 데이터 process
	- [[메모리]] 에 저장된 데이터 read
	- [[레지스터]] : CPU 안에 있는 작은 저장 공간
		- 계산의 피연산자 제공 -> bit 형식으로 저장
- [[메모리]] : CPU 가 계산한 데이터 store
