- [[연산]] 결과 [[state|상태]]를 1비트로 저장하는 특별한 목적의 [[레지스터]]
	- 1 : 켜짐
	- 0 : 꺼짐
- 가장 최근 연산 결과에 대한 flag 저장

![[Assembly-Control-Instruction-01.png]]

### 종류
| flag | 내용 |
| --- | --- |
| `%ZF` | Zero Flag, 값 0 인지 확인 |
| `%SF` | Sign Flag, [[MSB]] 와 동일 |
| `%CF` | Unsigned overflow flag |
| `%OF` | Signed overflow flag |

- `%CF` · `%OF` -> [[오버플로]] 감지, [[Unsigned vs. Signed]] 에 따라 참조 flag 상이

### 갱신 조건
- arithmetic & logical 연산 -> update O
- `mov` & `lea` -> update X
