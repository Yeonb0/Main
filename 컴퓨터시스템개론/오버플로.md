- [[연산]] 결과가 w bit 표현 범위 벗어나 다른 값으로 wrap around 되는 현상
- 범위 넘는 상위 bit 버림 -> 실제 값과 다른 결과

### 발생 상황
| 상황 | 내용 |
| --- | --- |
| [[Unsigned Addition]] | w + 1 bit 버림 -> $0 \sim 2^w$ 로 mapping |
| [[Signed Addition]] overflow | 음수 + 음수 = 양수 |
| [[Signed Addition]] underflow | 양수 + 양수 = 음수 |
| SMin 부호 반전 | $-2^{w-1}$ 의 negation -> 똑같은 값 |
| [[시프트 연산]] Left Shifting | $x \times 2^y$ -> 왼쪽 튀어나온 bit 버림 |
| 뺄셈 | Unsigned 에서 underflow 발생 O |
