- `T A[N]` 선언 -> `N × sizeof(T)` 만큼 [[메모리]] 연속 할당
- 배열 [[이름]] `A` -> 첫 요소 가리키는 [[포인터]] 로도 사용 O
- 요소 접근 -> base + index × element_size 계산 -> [[메모리 주소 지정 방식]] 그대로 활용

### 1차원 배열
- `T` : type / `A` : 이름 / `N` : 원소 개수

### 2차원 배열
- `T A[N][M]` -> `N` row, `M` column
- size : `N × M × sizeof(T)`
- row-major ordering -> table 형태의 2차원 구조
- array of array -> 각 행이 1차원 [[배열]], [[메모리]] 상에는 linear 저장

![[Assembly-Array-and-Struct-03.png]]

- `arr[i]` 시작 주소 -> 앞선 행의 요소 개수만큼 이동
	- ==ex)== `arr[4][5]` -> 행당 5 요소 단위

![[Assembly-Array-and-Struct-04.png]]

### 행 주소 접근
- 주소 계산만 -> [[lea]]
```c
int* get_row(int arr[][5], int row_idx) {
	return arr[row_idx];
}
```
```nasm
movslq  %esi, %rsi
lea    (%rsi, %rsi, 4), %rax ; 5 × row_idx
lea    (%rdi, %rax, 4), %rax ; arr + 20 × row_idx
ret
```

### 요소 접근
- 실제 값 load -> [[mov]]
```c
int get_elem(int arr[][5],
						 int row_idx,
						 int col_idx)
{
	return arr[row_idx][col_idx];
}
```
```nasm
movslq  %esi, %rsi
lea    (%rsi, %rsi, 4), %rax  ; 5 × row_idx
lea    (%rdi, %rax, 4), %rax  ; arr + 20 × row_idx
movslq  %edx, %rdx            ; col_idx
mov    (%rax, %rdx, 4), %eax  ; memory load
```
- 주소식 -> `*(arr+(20×row_idx)+(4×col_idx))`
