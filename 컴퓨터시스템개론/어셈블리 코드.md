- CPU 가 직접 이해 가능한 언어
- C 언어 프로그램 실행 -> 먼저 어셈블리 코드로 [[컴파일]](translate) 필요
- [[기계어]] 를 사람이 읽을 수 있도록 한 것 -> 내용 동일, 이해 주체만 상이
	- ==ex)== `add $rax $rbx`

### 특징
- 대부분의 경우 직접 작성 X
- 몇몇 CS 주제에서는 필수 지식
	- ==ex)== [[소프트웨어 보안]], [[성능 최적화]], [[운영체제]]
- 학습 이유 -> 컴퓨터 내부 동작 방식 파악, [[명령어 실행 사이클]] 이해
